# 欢迎使用 NoteBoard

把想法写下来，把关系画出来。

这是一份可以直接编辑的示例。试着改一段文字、点开公式，或者把它导出成 PDF。按 **Ctrl+S**，就能把自己的版本保存到本地。

> [!TIP]
> 不知道从哪里开始？先选中这句话，试试加粗、下划线和荧光笔。荧光笔记得你上次选的颜色，停留片刻即可展开色板。

## 写作，不必来回切换工具

普通段落、**重点**、*强调*、~~删改~~、<u>下划线</u>，以及 <mark data-color="#fef08a">值得回看的句子</mark>，都能放在同一份 Markdown 中。你可以直接编辑排好的正文，也可以切换到源码，精确控制每一个标记。

- 用标题整理长文，右侧大纲帮助你快速跳转。
- 文件保存在自己的目录里，左侧资源管理器负责浏览和定位。
- 打开多个标签页，继续写作时不必反复寻找文件。

### 一份小小的写作清单

- [x] 留下一个值得研究的问题
- [x] 把关键假设写清楚
- [ ] 补上数据与参考资料
- [ ] 导出一份适合分享的版本

## 公式，留在论述中

行内公式可以像文字一样参与叙述：若 $a^2+b^2=c^2$，三条边组成一个直角三角形。点击公式可以修改它的 LaTeX 源码。

独立公式适合承载完整推导：

\[
\mathcal{L}(\theta)=\frac{1}{n}\sum_{i=1}^{n}\left(y_i-f_{\theta}(x_i)\right)^2+\lambda\lVert\theta\rVert_2^2
\]

矩阵也可以保留自己的行距：

\[
A=\begin{pmatrix}
1 & 2 \\[2pt]
3 & 4
\end{pmatrix},\qquad \det A=-2
\]

支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`。公式有语法错误时，源码会保留下来，方便继续修正。

## 把信息摆在一起

| 记录方式 | 适合的内容 | 可以试试 |
| :--- | :--- | :--- |
| Markdown | 笔记、文章、研究记录 | 标题、公式、提示块 |
| 代码与纯文本 | 配置、片段、日志 | 语法高亮与查找替换 |
| 自由画板 | 草图、讨论、想法之间的联系 | 手绘图形与连线 |
| 思维导图 | 提纲、知识结构 | 大纲与脑图切换 |
| 多维表格 | 项目、资料与结构化记录 | 表格与看板 |

表格的列宽可以拖动调整。导出 PDF 时，超宽表格和公式可以单独调整排版，其他内容保持原样。

## 提示块，让重点有层次

> [!TIP]
> 在引用块开头输入 `[!`，用上下方向键选择类型，再按 Enter 或 Tab，便可直接开始写正文。

## 代码与图示

```python
def summarize(values):
    count = len(values)
    return {"count": count, "mean": sum(values) / count if count else 0}

print(summarize([2, 3, 5, 8]))
```

## 保存、导出，然后分享

按 **Ctrl+O** 打开文件或文件夹，也可以直接粘贴路径。刷新目录时，已经展开的文件夹会保持展开。

按 **Ctrl+P** 进入 PDF 排版预览，调整纸张、页边距、字号和页码。生成过程中会显示当前阶段；导出完成后，文件会出现在资源管理器里，可以交给系统默认程序打开。

需要 Word、HTML 或 LaTeX 时，在导出窗口切换格式。这些转换使用本机 Pandoc，可在设置的“导出”页查看检测到的路径或手动指定。

### 几个顺手的快捷键

| 按键 | 操作 |
| :--- | :--- |
| Ctrl+S | 保存 |
| Ctrl+O | 打开文件或文件夹 |
| Ctrl+Shift+O | 浏览文件夹 |
| Ctrl+1 … Ctrl+6 | 一级至六级标题 |
| Ctrl+0 | 恢复普通段落 |
| Ctrl+B / Ctrl+I / Ctrl+U | 加粗 / 斜体 / 下划线 |
| Ctrl+Z | 撤销 |
| Ctrl+F | 查找 |
| Ctrl+P | PDF 排版预览 |
