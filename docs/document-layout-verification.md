## 最终设计

- 大纲保留原有舞台内 `top: 56px`。顶部靠左排列收起按钮与“大纲”，头部 30px、列表间隔 4px；取消整圈描边，减弱阴影，使用主题底色及单层 8px 静态局部模糊。列表独立滚动，头部保持位置。

- 正文宽度包含两侧留白的补偿；居中图片、可容纳的居中表格及公式共用可阅读区域中轴，计算排除纵向滚动条占位。

详细规则见 [编辑交互架构](architecture/editor-interactions.md)。没有增加窗口轮询、JS 动画、常驻计时器、编辑器实例或文档序列化路径。
