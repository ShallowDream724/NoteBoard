# 声明式源码会话

NB 文档和 Markdown 文档都通过左下角模式按钮或 `Ctrl+/` 在可视化与源码之间切换。NB 的普通源码采用声明式文本；原始 `#!noteboard 1` 记录仍由错误块的修复入口打开。模式切换复用已有 CodeMirror 和 TipTap 实例，源码首开仅加载共享 schema，首次进入可视化时才挂载 TipTap。

## 存储边界

NB 磁盘格式继续使用 v1 记录帧。`AuthoringSourceSession` 在 CodeMirror 视图边界维护声明式文本与记录帧的对应关系。保存、统一历史、图片提交、书签捕获和读取快照都通过 `readSourceDocument` 取得持久化表示；程序化替换使用 `replaceSourceDocument`。调用方不能把 `view.state.doc.toString()` 当作 NB 文件内容。

输入监听只捕获不可变 CodeMirror `Text` 与会话的物化函数。新历史组、防抖、保存或切换模式时才执行解析和帧序列化。物化失败保留待处理快照。未编辑的源码会话返回原有帧文本，切换模式不会因重新排版记录产生脏态。视图销毁前先物化快照，再释放 adapter 和光标书签。

编辑过的声明式源码保存在 v1 帧头的可选 `authoring` 元数据中。只改注释、别名或空白也会进入文件历史，保存后重开能恢复这些文本。读取时使用共享解析器，并以帧模型和当前文档目录校验投影；未知版本、失配或无法解析的元数据使用帧重新生成源码。普通可视化修改沿结构路径尽可能局部更新已保存的源码。图片暂存引用转为已保存的文件路径时，应用丢弃旧投影并从更新后的帧重建，以避免保存旧路径或重复嵌入图片数据。独立导出使用正文模型生成目标文件。

## 位置和辅助输入

声明式解析器与序列化器产生结构路径 span；位置映射按子节点路径及文本偏移工作。重复正文、嵌套表格、代码和折叠容器不会依赖全文关键词搜索。转义文本通过 span 的 `offsets` 映射到 UTF-16 源码坐标。文档和可视化选区未改变时，返程恢复精确源码位置，包括语法参数、转义字符与块间空白。

公式内部的 `Ctrl+/` 在编辑器宿主捕获，能穿过公式局部快捷键暂停边界。两个选区端点同在一个 TeX 载荷内时，可视化入口恢复公式控件内的选区。横跨正文或多个公式时，沿用文档选区。Markdown 公式也通过映射后的公式范围恢复内部偏移。

源码命令补全消费 `declarative/registry.ts` 的同一语言目录。CodeMirror 基础扩展负责括号配对，补全插入来自 registry 的示例及参数名。

源码色盘、下划线和高亮共用语义格式适配器，写出 `\color[颜色]{内容}`、`\u{内容}`、`\bg[颜色]{内容}`。仅在打开色盘和执行命令时解析，工具栏渲染读取与不可变 `Text` 身份绑定的缓存。结构路径 span 区分正文、参数、链接地址、代码和公式；无法应用的范围不产生更改。清除视觉格式保留 `note`、`blur` 和链接语义。旧 HTML 与私有样式 footer 继续兼容读取；旧 footer 追踪独立生成兼容元数据，保留源码正文及样式范围。
