# 异步图片插入所有权

粘贴、拖入和本地文件选择器都先捕获插入租约，再读取图片或等待系统对话框。租约绑定文档会话代际、目录、编辑器能力对象、实际可视化/源码实例、活动标签及视图模式。切走、关闭请求、窗口关闭、迁移、目录变化或实例销毁会使旧任务作废；切回同一路径不会重新授权旧任务。

可视化模式保存 ProseMirror selection bookmark 并随后续事务映射；源码模式映射原 CodeMirror selection range。等待期间移动光标不会改变图片的原目标，删除目标则取消。拖入位置可以由调用方将 `posAtCoords` 结果作为 `handlePastedImageFile` 第四参传入。选择器从打开之前即持有租约，返回后不会重新查询并插入另一份活动文档。

每个异步读写阶段后重新核验租约；提交前最后核验与正文插入之间没有 await。隐藏或 inert 编辑区不得获得迟到插入和焦点。新插入仍由既有编辑器事务更新正文、版本和历史，关闭/暂存使用其统一版本证明。

受管图片写入纳入 `enqueueDocumentWrite`。迁移的写队列 drain 会等待已发出的图片写入完成；进入迁移/关闭后旧排队任务不再开始写旧路径。目录必须位于文档目录内；未保存文档的粘贴使用 Data URL，不再将资源树根目录当作文档目录。

文件使用每次操作独立的随机名称，避免时间戳和原文件名碰撞。但当前 `save_binary_file` 没有原子创建者收据，随机名称不等于可删除证明。因此已经发出的原生写入若在取消后才返回，保留已写文件并提示原路径，不按路径删除，不触碰用户已有文件或其他文档的共享图片。自动清理需要后续独立的原生创建收据及引用证明；本流程不伪造该权限。

租约的 store/transaction 订阅随操作完成清理，源码位置追踪器每个实际 CM 实例最多一个，实例销毁时取消剩余目标。定向 deferred 契约覆盖读盘期间会话换代、写盘期间迁移、选择器期间切走再切回，以及两个内核的原目标映射：`test/editor-md/imageInsertionLease.test.ts`。
