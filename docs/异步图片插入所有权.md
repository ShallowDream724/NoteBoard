# 异步图片插入所有权

粘贴、拖入和本地文件选择器都先捕获插入租约，再读取图片或等待系统对话框。租约绑定文档会话代际、目录、编辑器能力对象、实际可视化/源码实例、活动标签及视图模式。切走、关闭请求、窗口关闭、迁移、目录变化或实例销毁会使旧任务作废；切回同一路径不会重新授权旧任务。

可视化模式保存 ProseMirror selection bookmark 并随后续事务映射；源码模式映射原 CodeMirror selection range。等待期间移动光标不会改变图片的原目标，删除目标则取消。原生拖拽经过物理/CSS 坐标转换与实际编辑区命中后捕获租约；图片粘贴捕获当时鼠标命中的槽，鼠标不在槽内时捕获文字光标。槽边界独立随事务映射，防止删除空槽后漂移到相邻槽。选择器从打开之前即持有租约，返回后不会重新查询并插入另一份活动文档。

每个异步读写阶段后重新核验租约；提交前最后核验与正文插入之间没有 await。隐藏或 inert 编辑区不得获得迟到插入和焦点。新插入仍由既有编辑器事务更新正文、版本和历史，关闭/暂存使用其统一版本证明。

受管图片写入纳入 `enqueueDocumentWrite`。迁移的写队列 drain 会等待已发出的图片写入完成；进入迁移/关闭后旧排队任务不再开始写旧路径。已保存文档使用受管相对资产路径；未保存文档先写入持久恢复资产目录，不使用 Data URL 或资源树根目录代替文档目录。

资产名称由现有 `imageAssetStorage` 内容寻址流程管理。已经发出的原生写入若在取消后才返回，保留已写文件并提示原路径，不按路径删除，不触碰用户已有文件或其他文档的共享图片。自动清理需要独立的原生创建收据及引用证明。

租约的 store/transaction 订阅随操作完成清理，源码位置追踪器每个实际 CM 实例最多一个，实例销毁时取消剩余目标。定向 deferred 契约覆盖读盘期间会话换代、写盘期间迁移、选择器期间切走再切回，以及两个内核的原目标映射：`test/editor-md/imageInsertionLease.test.ts`。

正文拖图只使用完整内容块的前后边界，按块上下半区选择；不会使用换行后的视觉行或行内字符位置。第一层折叠块内部仍可在其子块间插入；列表、表格、代码和更深的折叠块保持整体。解析只沿命中位置的祖先路径运行。宫格/轮播槽仍优先于块边界。

定点拖入或悬停槽粘贴不触发旧光标的滚动。普通图片粘贴及空段图片插入选中图片，并仅在图片起点离开舒适视区时显露起点一次，不随异步解码后的高度持续追赶图片底部。轮播没有图注或原图注已清空时，悬停均显示添加提示，已有空段直接继续输入。
