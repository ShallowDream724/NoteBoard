# 声明语法的正文输入与斜杠菜单

正文输入、完整粘贴与源码使用同一份声明语法解析器。`src/features/declarative/registry.ts` 定义语言命令与参数，`authoringInput.ts` 只负责识别当前输入范围、调用解析器、把结果放入现有文档。斜杠菜单仍是交互插入入口，不占用源码切换快捷键。

## 正文输入

输入完整闭合且参数有效的行内声明后立即渲染，例如 `\blur{答案}`、`\color[red]{重点}`、`\u{下划线}`。嵌套声明等待最外层闭合，未完成或无效的声明保留输入文字。`C++`、`a++` 和普通加号不触发下划线。

转换只检查光标所在段落中最多 4096 字符的输入窗口，不重新解析整篇文档。输入法组合期间、代码和公式节点、代码或链接标记中的内容不触发转换；源码形式中完整的行内代码和公式范围也受到保护。已有说明锚点中不再建立交互说明。

行内转换先保存完整原始输入，再提交独立转换事务。一次撤销恢复带闭合符的原文和输入位置，一次重做恢复渲染结果。应用历史通过 `noteboard-before-selection` 事务元数据保存输入位置；使用原生历史的嵌入视图也能撤销该转换。

在独立段落输入块起始行后按 Enter，可建立空容器或模板并继续编辑，例如：

```md
::: note
::: fold "详情"
::: table 2*3
::: pic 1*2
::: center
```

输入时无需先写结束围栏。`fold` 必须提供标题，`annotation` 必须提供名称，参数错误时保留文字。`::: explain` 绑定当前段落的前一个同级内容块并打开说明编辑面板；没有目标或目标已有说明时保留文字。`::: annotation 名称` 建立该名称的空说明并打开编辑面板。新建行内说明会合并进文档的说明存储；引用已有名称时复用其 ID，不复制说明正文。

## 斜杠菜单

原有中文、拼音与常用短词搜索保持可用。`/pic`、`/grid` 搜索拼图，`/slide`、`/carousel` 搜索轮播，`/fold`、`/details` 搜索折叠，`/table`、`/tbl` 搜索表格。无参数 `/img` 保留本地选图行为。

支持带参数的快速插入，如 `/table 2*3`、`/pic 1*2`、`/img 1*2`、`/carousel print-cols=2`、`/details "详情"`。这些入口把人用别名映射为语言的规范命令后调用共同解析器；`/img 1*2` 创建图片槽位，不打开本地文件选择器。参数无效时不显示可执行项。一次撤销撤销整次查询及插入，菜单不吞 Ctrl、Alt、Meta 修饰的组合键。
