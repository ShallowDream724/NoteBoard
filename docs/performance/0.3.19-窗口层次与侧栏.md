# 0.3.19 窗口层次与侧栏

## 取舍

资源管理器标题行与编辑工具栏的内容密度不同，保持各自高度，不强求底线对齐。两条主线各自终止于所属面板，路径栏次级线减淡，中间仅保留一条 3px 可见分隔条。面板库继续提供 10px 鼠标/20px 触摸命中区与键盘调整。

标题栏底色、文字与悬停色在 AppShell 派生。活动标签采用 10px 上圆角、12px 底部反向圆弧，均与侧边相切；底部直接融入工作区，不额外绘制横线。`tabShape.ts` 集中定义固定比例的矢量端部与可伸缩中段；平直处重叠 1px 防止分数缩放产生接缝。轮廓比例参考 [Chromium TabStyle](https://github.com/chromium/chromium/blob/main/chrome/browser/ui/tabs/tab_style.cc)，保持标签和工具栏高度。弧角宽度与边缘收口使用同一常量。

文件树的原生滚动条虽然透明，仍占 10px 布局槽。改为共享 `VerticalScrollArea` 包装 Radix ScrollArea：原生内容滚动、覆盖式滑块、无端部箭头，选中行背景铺到右边。外观 CSS 与文件数据/目录监听分离，文件名保留省略行为。

## 开销与验证范围

- 标签弧角/对比度由 CSS 绘制，共享遮罩仅在模块初始化时生成，无逐标签路径运算、额外监听或 React 状态；边缘查找仍 O(log n)，缓存 O(n)。
- 滚动位置由原生容器维护，滑块更新只读取固定数量容器度量并写 transform；不遍历文件行，不把滚动位置写入文件树或文档 store。
- 目录内容尺寸和视口由固定数量 ResizeObserver 观察。文件树现有递归 DOM 结构未虚拟化，本次没有声称解决超大目录的全部渲染开销。
- 文件栏不再使用原生滚动条的继承颜色动画；覆盖滑块只过渡自身 opacity，避免鼠标进出时把颜色变化传播到文件树后代。
- 复用库提供的滑块长度下限，不以 CSS 覆盖其算法尺寸，避免长内容时底端伸出轨道。

独立 Edge 渲染使用真实标题栏、Explorer、树节点、ScrollArea、分隔条和工具栏容器；原生 IPC/文件系统与工具栏命令内容使用桩。检查 260px 文件栏的可见宽度、内容宽度和外框宽度均为 260px，选中背景到右边缘；无原生滚动条按钮，滑块到最底部和 Home 键正常。另以 300000px 内容高度触发最短滑块，确认底端不越轨。检查分隔线外侧的命中、拖动与键盘调整，以及晨光/琥珀/墨夜、窄窗口和标签边缘收口。三套主题的非活动标签文字与栏底对比度分别为 5.39、6.52、5.27。100%、125%、150%、200% 显示缩放下检查了轮廓与工作区连接，未见端部遮罩接缝；关闭按钮的圆形悬停反馈保留。4 项已有标签边界检查通过。安装与构建结果见本机 outputs 安装记录；未重复运行 Markdown 文档压测。
