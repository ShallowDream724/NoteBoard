# 0.3.18 窗口恢复修复

## 证据与范围

本机旧 `.window-state.json` 的 `nb-main` 为 288×35、位置 (-32000,-32000)。旧插件将该尺寸直接恢复到启动窗口，覆盖配置的 1200×800 / 最小 680×480 逻辑尺寸。标题栏 CSS 不调用原生窗口尺寸 API。

Windows 几何持久化独立到 `src-tauri/src/window/geometry.rs`。保存 `GetWindowPlacement.rcNormalPosition`；在 `window_shell_ready` 显示前校验并恢复，旧异常记录回退正常默认尺寸。合法旧记录保持旧插件的物理内部尺寸/屏幕坐标解释；新记录保留 Win32 工作区坐标，配对使用 `SetWindowPlacement`。导出窗口、文档会话和正文不参与此状态。

恢复过程中的事件不写入缓存，成功后才标记就绪；失败仍允许下一次重试。唤醒已有窗口只对最小化窗口调用 `SW_RESTORE`，避免解除最大化。

## 开销与边界

- 移动/缩放：固定数量原生查询和哈希表操作，平均 O(1) 时间；不写磁盘、不通知文档编辑器。
- 启动恢复：O(w + m)，w 为保存的窗口数、m 为显示器数；退出序列化与原子写入为 O(w)。进程缓存为 O(w)。
- 互斥锁只用于快照，持锁期间不调用窗口 API。
- 新格式使用 `window-layout.json`，首次兼容旧文件；旧文件不覆盖。Windows 的最小化外框不再作为正常窗口尺寸。
- 非 Windows 保留原插件，限定为尺寸、位置和最大化状态；本轮未在非 Windows 系统运行。

## 本轮验证

4 项 Rust 定向检查通过：微小最小化尺寸、旧记录 DPI 下限、哨兵/溢出/负坐标、最小化时保留正常矩形及最大化意图。

独立原生窗口实测：正常矩形为 (200,180,1200,800)；最小化的外框为 (0,1870,314,50)，`rcNormalPosition` 仍为 (200,180,1200,800)。配对恢复后矩形相同。最大化后隐藏窗口，`showCmd` 仍为 3，正常还原矩形不变。测试使用无焦点、透明的临时原生窗口，结束销毁；未操作用户文档窗口。

TypeScript、生产前端和 Tauri NSIS 构建通过。只做本次缺陷相关验证，没有重跑 Markdown 全链路压测。安装状态以外部 `outputs/NoteBoard-installation.json` 为准。
