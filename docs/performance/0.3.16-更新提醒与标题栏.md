# 0.3.16 更新提醒与标题栏

本轮范围是标题栏位置、视觉反馈、提示边界与自动更新提醒，不修改 Markdown 排版内核。

## 结构与成本

- 标题栏按钮共用 CSS 尺寸、圆角与焦点规则，移除窗口控制和设置按钮重复的鼠标事件写样式；悬停不更新 React 状态。
- 新建按钮位于标签滚动视口外，共用 flex 布局随标签尾部移动；标签溢出只压缩视口。圆形反馈、标签反向弧角均由 CSS 绘制。
- Tooltip 实际测量一次浮层尺寸，四边翻转/限制计算为 O(1)；指针移动按动画帧合并。禁用提示时保持触发节点身份。
- 检查更新每窗口一个可清理 timeout，复用在途 Promise。成功间隔 30 分钟，失败退避、离线恢复和服务端限流共同控制重试。元数据与安装包下载超时分开，检查总上限 12 秒。
- 更新气泡不抢焦点，只在出现可提醒版本时挂载；定位观察器随浮层释放。进程内关闭记录与持久设置分开，跨窗口订阅先于读取，快照合并避免丢失关闭事件。永久忽略版本复用原设置事务，没有额外存储文件。

## 定向验证

类型检查和生产构建检查全部修改。状态测试覆盖手动加入自动请求、失败保留已知版本、30 分钟及退避间隔、离线恢复、限流、跨窗口关闭与启动快照竞态、异步监听晚到清理、设置失败回滚及提示边界。

隔离 Edge 中加载真实 TitleBar、Tooltip、UpdateNotice、AboutPanel、UpdateModal；本机服务使用测试替身。检查 1/3/18 个标签、680/900/1400px 窗口；9 个顶部按钮提示均位于窗口内；菜单开启时触发节点保持不变；更新详情位于 inert 根节点外且可聚焦和关闭。模拟同次会话关闭、重启后再次提醒、忽略当前版本和后续版本恢复提醒，页面无异常。

这不等于实际请求 GitHub、下载或安装远端更新；本轮没有创建 Release 或触发远端安装。安装回执和软件版本仍以 outputs/NoteBoard-installation.json 为准。未重复执行 Markdown 全文压力回归。
