# 画板物化与大文件确认

日期：2026-09-27。目标是降低画板交互中的全文分配，并让现有大文件设置在读取前生效。本记录不把分配次数减少等同于常驻内存减少 100 MiB。

## 画板

原实现每次真实变化都构造整个元素版本签名、序列化完整 JSON，再更新历史补丁；300/800 ms 防抖只延后镜像和磁盘写入，因此拖动时图片 data URL 也反复进入新字符串。

现在由每个画板实例的 `BoardSceneMaterializer` 保留最新场景引用，手势结束、300 ms 空闲、保存/暂存/迁移/卸载捕获，以及撤销/重做物化屏障共享一份快照。指针仍按住时，空闲和自动保存定时器不产生中间 JSON；释放指针会重新安排最终自动保存。释放事件延迟一个事件轮次封闭历史组，覆盖 Excalidraw 在 `onPointerUp` 后发布的最后一帧。保存进行中的显式捕获仍能物化当前帧，后续帧继续并入同一手势组。

Excalidraw 0.18 会原地修改元素对象，元素数组引用不保证变化，公开 API 也没有场景 revision。为保持即时脏态与关闭保护，每帧仍执行一次 **O(N) 标量版本扫描**，但不再创建整场景签名字符串或 JSON；不能宣称热路径已变成 O(1)。真实内容变化立即推进文档 revision；选择、滚动与缩放不推进。完整签名仅在物化边界生成。

验证覆盖 10,000 图元、1 MiB 图片资源和 240 帧原地拖动：初始化之外只产生 **1 次签名和 1 次序列化**；图片资源逐字保留。组件集成测试覆盖延迟镜像期间立即标脏、长按拖动不自动保存中间帧、手势末帧保存、单步撤销/重做、空闲前 flush、viewport 捕获和可回收条件。

## 大文件确认

此前 `largeFileConfirmMb` 只有设置项，`shouldConfirmBeforeOpen` 只有定义和单元测试，实际打开流程未调用，所以图片与文本均不会触发该确认。

现在 `prepare_document` 接收 `maxReadBytes`。归属查询仍在读取前；已打开文档直接聚焦。未打开文件在 metadata 后、文本探测和正文读取前检查大小，返回 `confirmation-required` 时释放自己的在途预约，不创建文档或标签。前端读取设置阈值，取消返回 `cancelled`，确认后只批准此次观察到的大小；文件变大时再次确认。图片继续以路径资源解码，确认机制不会把图片二进制放进正文 store。

`core/files/largeFilePolicy.ts` 为文件打开和图片导入提供同一设置判定与确认提示。等于阈值不提示，大于阈值提示；默认 50 × 1024 × 1024 字节。原生分类测试覆盖图片/文本在大小边界前后返回值，前端覆盖取消不注册不建标签、文件增长后二次确认、自定义阈值和图片正文为 null。

## 原生内存采样

`scripts/perf/native-memory-sample.py` 接收隔离启动记录及输出路径，以 PID 和可执行文件路径验证进程归属，只汇总该进程及其子进程；分别记录 private commit、private working set、RSS，保存 5 次采样与中位数，并记录可执行文件 SHA-256。配套 `native-memory-probe.mjs` 用只读 CDP 获取 JS heap、DOM、图片/画布计数、窗口尺寸和 DPR，不强制 GC。

复现命令：

```sh
D:/anaconda/envs/aider/python.exe .tmp/rc5-launch.py
D:/anaconda/envs/aider/python.exe scripts/perf/native-memory-sample.py .tmp/rc5-launch.json .tmp/rc5-memory-before.json
```

`.tmp/rc5-launch.py` 使用新建临时目录下的 APPDATA/WebView 用户目录，不复制或修改用户真实配置。A/B 应使用归档 rc5 与新构建、同一隔离配置、相同样本、相同窗口尺寸、同一等待时长，分别保留冷/暖结果。

本次尝试启动基线时检测到已有 NoteBoard 实例并安全退出，没有关闭或操作用户实例；因此尚无可报告的原生 A/B 内存差值。
