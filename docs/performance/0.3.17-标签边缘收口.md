# 0.3.17 标签边缘收口

问题：标签滚动区域的渐隐不能消除只露出几像素的下一标签，图标或活动标签弧角会留下残片，新建按钮前也出现多余间隔。

实现边界和复杂度见 architecture/settings-and-updates.md 的标签段。几何规则独立于 React/DOM；hook 只负责读取缓存节点、提交边缘属性和清理监听。遮罩与新建按钮位移共享计算结果，布局尺寸保持不变。

定向验证：

- 四项规则测试覆盖残片、肩角、48px 阈值、不同标签宽度、中间滚动位置、唯一可见项及末尾；百万项的候选定位不超过 22 次读取。
- 隔离 Edge 加载实际标题栏组件，本机服务使用替身；检查候选露出 -6/1/8/20/47/48/80px，包括活动标签肩角先进入视口的情况。
- 确认收口后新建按钮紧随完整标签、重复帧不反复改变边界；多次横滚的 scrollLeft/clientWidth/scrollWidth 保持预期。
- 键盘聚焦恢复隐藏标签；拖动中解除收口，结束后恢复；滚至最后、关闭到不再溢出时清理隐藏和位移；页面无异常。

本轮不修改正文排版、不重复跑 Markdown 压力回归。构建和安装状态以安装记录为准。
