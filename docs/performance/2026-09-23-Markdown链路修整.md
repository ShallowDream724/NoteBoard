# Markdown 链路修整（2026-09-23）

> 0.3.9 历史记录。后续已修复 Worker 导入、滚动布局及初始化问题，现状与更精确的复杂度见《0.3.10-滚动与打开》。本页的全局标题几何重建和取消语义不再代表当前实现。

范围是本次二次开发涉及的 Markdown 编辑、保存、资源、导出及相关界面。以源码审查、确定反例和算法边界为依据；不以旧版隔离编辑器的帧率数据代表当前完整应用。

## 输入、历史与位置

- 文档历史适配器属于文档会话，源码首开不依赖隐藏的可视化内核。程序化同步有独立事务标记，不会留下延迟快照覆盖撤销分支。
- 空字符串是合法保存基线。重新挂载脏文档时使用已保存基线，不能把未保存正文设为基线。
- 双向切换使用和 CodeMirror 选区相同的 LF 坐标；文件保存的换行格式仍由文档元数据负责。已识别的块只对端点所在块做字符映射，不再逐块序列化整份前缀。0.3.10 后每个活编辑器仅保留当前不可变文档的一份定位索引，Markdown 管理器使用独立 Marked 实例，详见《0.3.10-源码切换》。
- 视图检查点保存实际滚动容器的纵向和横向位置。延迟定位可取消，并检查当前文档及模式。
- 已经处于相同 dirty 状态时不重新发布标签数组；纯高亮装饰事务不刷新格式工具栏。编辑器宿主保留输入未变的编辑器元素。

## 滚动与后台工作

- 公式、代码高亮各自使用有容量限制的共享 Worker 调度器。任务有消费者、取消、过期结果检查、缓存上限和空闲释放；页面离开后不能把旧结果写回新节点。
- 可见内容优先于预加载。公式准备数量、单帧插入量以及单公式展开规模都有明确上限；详见《公式渲染预算》。超过边界时保留源码，显示原因，不静默截断。
- 编辑区长公式保留整体横向滚动，不增加公式内部的第二套滚动条；打印按纸张正文宽度处理。
- 矩阵只挂载邻近视口的单元格，初始化宽度使用有限采样，随后按实际尺寸细化。不会同步测量所有单元格文字。
- 大纲更新映射标题位置并检查修改范围，不再每次输入遍历全文。标题几何按实际纵向位置排序，兼容表格内的标题。只有真实布局尺寸及文档结构变动使几何失效；矩阵内部虚拟绘制不会触发整篇大纲测量。
- 表格行高拖动与悬停使用一个编辑器所属的辅助线；拖动只更新当前行，结束时提交一次文档事务。

## 保存、暂存与路径

- 暂存写入、正常保存后的暂存清理和明确丢弃共用串行队列。同路径的新写入不会和旧清理交错。自动暂存最多一个执行中任务及一个合并后的等待任务。
- 清理必须有内容相等的证据，空正文不例外。删除失败保留清理记录以便重试。无法捕获权威正文时保留原恢复副本。
- “暂存并关闭”在写入完成及调用方最后一个等待结束后核对版本和正文；期间新增输入会阻止关闭。
- 文件、目录重命名和另存为使用统一身份交接。等待旧路径写入结束后，在旧会话代际仍有效时物化最后输入，再同步迁移历史、基线、修订、暂存和视图。重命名不会强制保存用户正文。
- 身份迁移前恢复仍由撤销历史持有的受管图片，避免目录变化后旧回收凭据失效。这些已恢复的文件会保留在图片目录中。
- 图片插入绑定会话、路径、实例和插入位置，异步完成时重新核验。已开始的图片文件写入纳入文档写队列；失去插入所有权后不会写入其它文档。
- 图片回收按同次保存批处理引用检查。未知正文、无法解码的引用、过期捕获以及其它窗口未确认的引用均保留图片；恢复图片是保存前的屏障，与当前编辑模式无关。

## 语法、设置与导出

- 图表围栏、彩色高亮、文字中的公式／高亮分隔符、表格管道符及复杂单元格使用共享的持久化语法。合并表的可见占位被源码编辑后，旧合并元数据不再覆盖新增文字。
- 设置采用服务端串行字段 patch 与单调版本，前端把待确认 patch 叠加在最新确认快照上。失败会回滚该 patch 并显示错误；不同窗口的不同字段不会被整包覆盖。
- 已有数学、Mermaid、块手柄和源码缩进设置接入实际行为；关闭预览保留可编辑语法。设置弹窗隔离背景快捷键和焦点。
- PDF 读取器完成交接后才释放旧版本。允许裁切的确认绑定会话及版本。PDF 与 Pandoc 都先写目标目录临时文件，同步成功后原子替换，失败保留原目标。
- 资源地址只在 Worker 持有的图片元素上回填；主线程不重新解析整份导出 DOM，也不改写正文里看似占位符的文字。
- 普通长词可换行，仍未容纳的内容有明确定位和提示。矩阵采样只估算分片，每个实际分片单独检查可读性和渲染预算。
- Pandoc HTML 保留高亮颜色；当前 Pandoc 的 DOCX／LaTeX 路径不能保留高亮底色时会明确提示。这是已知格式能力边界。

## 复杂度边界

设正文长度为 N，标题数为 H，输出页数为 P。模式映射为 O(N) 的一次词法分析及有限端点映射；标题位置映射最坏仍为 O(H)，结构编辑还包含被修改子树；几何失效后的重建为 O(H log H)，稳定布局滚动使用二分查找。不能把这些过程写成无条件 O(1)。

公式／代码缓存、等待队列、预览画布和矩阵可见 DOM 有独立上限。完整的原文、文档模型、文件解析和最终导出仍至少随输入／输出规模线性增长。PDF 预览按可见页绘制；正文排版改变可能影响后续分页，系统打印引擎仍要生成完整 PDF，不能承诺任意局部修改在任意页数下都是常数时间。页码样式修改复用已有正文 PDF。

本轮进行了源码独立复审、确定反例的定向合同检查及编译检查，没有复用旧版实机性能结果为新版作速度保证。
