# 0.3.15 标签外观

未选中标签改为透明无框，悬停显示圆角底色，标签之间保留小间隙与轻分隔。关闭按钮常显；长标题淡出，短标题完整；滚动区只在有隐藏内容的一侧淡出。

标题栏下方工作区采用统一的左右上圆角，窗口底色随主题轻微着色。边界由窗口布局层的 CSS 管理，各个内容面板保持原结构，演示模式取消该边界。没有新增计时器或布局测量。

外观使用 CSS。滚动边界只观察两个元素并合并到动画帧，检查成本不随标签数量增长，不在滚动中遍历或重新渲染标签。原有标签 DOM 和排序模型仍随标签数增长；此改动不声称标签列表虚拟化。

生产组件在隔离 Edge 页面中检查：18 个标签的空闲、悬停和关闭按钮；滚动到起点、中部、终点的边缘状态；删除标签后取消多余渐隐；短文件名不受渐隐影响；右键菜单不受 mask 裁剪，600×260 窗口缩放后留在边界内。无页面异常。原生服务用桩替代，这不是安装版端到端验证。TypeScript 和生产构建检查接口，无全文档回归。

同一页面复用工作区 CSS，核对左右 12px 圆角的裁剪和实际命中区域，演示模式圆角为 0；外观截图已人工检查。
