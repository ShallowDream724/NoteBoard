## 交互变化

- 八个步骤均由真实操作触发，取消“继续”和结束确认页。悬停或点击问号展开说明后自动进入选中文字；末步展开折叠内容后退出引导。
- 删除长箭头和浮层障碍重排逻辑，复用 Radix 的非模态就近浮层与小尖角。展开悬停说明时，当前提示直接撤下，不跳到另一侧。
- 保存判断读取正文中的说明实体，空格或空段落也可完成；草稿取消不算保存，可重新选择文字打开草稿。
