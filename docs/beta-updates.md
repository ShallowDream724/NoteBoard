# 内测覆盖安装与更新通道

安装身份保持 `NoteBoard` / `com.crazyfigure.noteboard` / `currentUser`。NSIS 使用原安装注册信息和目录，覆盖程序，不重置用户文档、暂存及配置。本轮文档存储格式不变。

历史线上 `v1.0.0-rc.1` 标签的包内部误写成 `1.0.0`。该版本的用户需要手动覆盖正确标记的 RC 包，安装器允许此版本方向；旧版的版本比较无法自行判断一个 `1.0.0-rc.*` 比错误标记的 `1.0.0` 更新。

更新源为 `ShallowDream724/NoteBoard` 的公开 GitHub Releases。当前版本有 SemVer 预发布部分时读取最近 100 个发布记录，忽略草稿与无效标签，按 SemVer 优先级选择最新版本；正式版仍使用正式发布接口，不自动进入 RC。RC 能升级到后续 RC，也能升级到同版本号的最终正式版。构建元数据不决定升级优先级。

每次供用户更新的发布必须递增版本号，保证 Git 标签、package.json、Cargo 与 Tauri 配置一致，并附可访问的 Windows 安装包。同版本的本地重新打包支持手动覆盖，但不会被识别为更高版本。仅生成或分发本地安装包不等于已经发布到更新源；更新检查不依赖开发机器。

当前使用自定义 GitHub 下载/安装流程，而非 Tauri updater manifest 流程。版本查询与安装是不同步骤：自动检查只提示更新，用户确认后下载安装器。网络超时、限流继续按已有错误处理与代理回退逻辑呈现。

验证包括 Rust 版本/通道单测、实际公开 API 查询，以及构建版 `check_for_updates` 命令；未来尚未发布的版本无法提前做端到端下载安装验证。
