# Markdown 代码块控件

代码块顶部左侧为实心折叠三角和语言选择，右侧为自动换行、批注及复制操作；语言下拉保留空心箭头，以区分菜单与内容折叠。自动换行默认开启，按钮使用固定的“自动换行”名称，通过选中状态表示开关。行号按源代码逻辑行显示，换行后的续行不重复编号；语言选择仍使用现有懒加载语法高亮。代码内容继续由同一个 TipTap `NodeViewContent` 编辑，不为每个代码块创建独立编辑器。

Python 的缩进代码段，以及 JavaScript、TypeScript、JSON、CSS、C/C++、C#、Java、Go、Rust、PHP、Swift、Kotlin、Scala 等语言的多行花括号/方括号范围，提供行号旁的折叠按钮和行内省略按钮。结构扫描跳过字符串及注释；它是保守的展示辅助，不是完整语言解析器。其他语言保留行号、整块折叠和换行。

折叠和换行仅属于当前编辑视图，不写入 Markdown、文档 JSON 或历史记录。复制按钮始终读取完整 `node.textContent`，保存与导出也保留完整源代码。打开其他视图或重新挂载代码块会重置这些展示状态。

折叠正在编辑的代码段时，光标先停在可见的段首行末。键盘导航、搜索或程序化选择进入隐藏范围时立即展开；代码内容变化时立即撤销该块的局部折叠，再按最新源代码计算控件，避免隐藏刚输入的内容。整块折叠也会在新的选择进入其范围时展开。

`codeBlockStructure.ts` 负责纯源代码行偏移与可折叠区间；`codeBlockControls.ts` 通过 ProseMirror decorations 提供行号、隐藏范围和按钮；`codeBlockView.tsx` 管理顶部交互。行号 widget 挂在真实的逻辑行起点，因此无需测量每一行，也能和自动换行、高亮 span 对齐。widget 保留完整的 `1.5em` 行盒，避免 Chromium 将仅含零高度 widget 的空逻辑行压缩；编号与折叠按钮在行盒内居中。代码高亮插件独立维护其 decorations。

控件仅在共享可视区观察器判定代码块临近视口后建立，延迟 40 ms 合并短暂变动；离开视口时移除行号，已折叠范围保留其高度，避免滚动跳动。仅扫描对应代码块，不遍历或重新解析整个文档；每次更新只替换受影响块的 decorations。超过 128,000 个 UTF-16 单元或 2,000 行的代码块暂不建立行号与局部折叠控件，仍可编辑、整块折叠、换行、复制和导出。

回归验证：`test/editor-md/codeBlockStructure.test.ts` 覆盖源偏移、嵌套结构、字符串/注释及大小边界；`test/editor-md/codeBlockControls.test.tsx` 覆盖折叠复制完整性、源码不变、光标揭示、编辑失效、离屏折叠高度与嵌套状态；原有高亮挂载回归继续运行。
