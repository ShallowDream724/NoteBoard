# 空行输入引导定位验收

2026-10-05。修复示例教程第六步的目标框：原实现从段落左侧硬移 28px，仍使用整段宽度，导致光标位于框外。现在使用真实 ProseMirror 插入位置和行高，只标出附近的短输入区域。关闭命令菜单后的第七步回退提示复用同一逻辑。

## 行为与边界

- 空行提示宽度为 5em，受段落可用宽度限制；外围保留 4px 提示边距。居中或居右段落也包含真实插入点，不使用伪造的横向偏移。
- 优先使用当前光标所在的合格顶层空行或纯文本斜杠查询。没有当前合格行时提示第一个合格位置；嵌套段落和包含行内原子节点的查询不会被误认。
- 实际 Enter 创建另一条空行后，提示跟随新光标。关闭命令菜单后保持教程步骤，提示回到当前查询；菜单恢复后可以正常插入 Note。
- 不移动焦点、修改选区或替用户编辑。段落元素仍用于滚动和尺寸观察，目标框不拦截鼠标。没有新增轮询、定时器、监听器或文档副本；有效当前光标直接定位，查找默认空行找到即停止。
