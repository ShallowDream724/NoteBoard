# 正文布局与交互状态

资源管理器宽度属于窗口布局。`AppShell` 使用面板库 `onLayoutChanged` 的 `isUserInteraction` 标记，仅在拖动结束或键盘调宽时将实际容器宽度换算成像素并更新 `layoutStore`。初始挂载、恢复布局、窗口约束变化不反写用户偏好。关闭快照直接读取该 store；收起再展开不再依赖 AppShell 卸载。

正文首行顶部留白为 3.2em，窄编辑区为 2.8em，接近默认打印页边距相对字号的比例。打印页边距仍由导出设置管理。可视化编辑器使用 ProseMirror 的滚动阈值及边距，在底部保留约四行常用字号的输入空间；不添加高频滚动监听或全文测量。

空段插入菜单的异步对话框保留原段落的映射租约。`showTransientDialog` 自己建立 React root，必须包含自身所需的 `TooltipProvider`，不能假定能够继承 AppShell 上下文。回归覆盖独立链接弹窗的打开和关闭，以及实际浏览器中的输入、提交、插入。
