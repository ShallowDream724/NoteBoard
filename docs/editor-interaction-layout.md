# 正文布局与交互状态

资源管理器宽度属于窗口布局。`AppShell` 使用面板库 `onLayoutChanged` 的 `isUserInteraction` 标记，仅在拖动结束或键盘调宽时将实际容器宽度换算成像素并更新 `layoutStore`。初始挂载、恢复布局、窗口约束变化不反写用户偏好。关闭快照直接读取该 store；收起再展开不再依赖 AppShell 卸载。

窗口大小改变时侧栏保持像素宽度。会话异步恢复后由 `useRememberedPanelSize` 等到面板 `onResize` 首次有效测量，再应用保存值；ref 出现不代表布局注册完成，禁止提前调用 `getSize`。隐藏、卸载会取消待执行的帧，窗口约束解除后恢复偏好宽度。保存百分比换算以面板实际总宽度为基数，排除分隔线。用户调宽另保存轻量本地偏好作为无文档 Home 窗口的启动默认值；窗口自己的会话快照仍可覆盖它。

正文首行顶部留白为 3.2em，窄编辑区为 2.8em，接近默认打印页边距相对字号的比例。打印页边距仍由导出设置管理。正文底部 padding 按四行实际行高保留空间，配合 ProseMirror 输入滚动阈值；显式插入和导航由 `editorViewport.ts` 一次性滚动所属容器。详见 `scroll-ownership.md`，不添加高频滚动监听或全文测量。

空段插入菜单的异步对话框保留原段落的映射租约。`showTransientDialog` 自己建立 React root，必须包含自身所需的 `TooltipProvider`，不能假定能够继承 AppShell 上下文。回归覆盖独立链接弹窗的打开和关闭，以及实际浏览器中的输入、提交、插入。

表边行列选择把手和文字、表格浮动工具栏统一挂载到所属文档的 `body`，由 `editorOverlayLayers.css` 管理层级：表边把手为 900，工具栏为 1000，工具栏子菜单沿用更高的菜单层。重叠时工具栏同时取得绘制与指针命中优先级；把手保留相邻表边的选择和拖动区域，不通过逐帧遮挡检测或扩大层级值处理冲突。
