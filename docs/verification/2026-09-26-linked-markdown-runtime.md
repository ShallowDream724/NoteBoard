# MD / NB 真实安装版验收

2026-09-26，在 Windows 安装版 NoteBoard 1.0.0 上操作。转换定位修复为 `919739e`，目录监听修复为 `cefcb89`，关联编辑器同步修复为 `982dd3a`。后续操作通过 Playwright CDP 连接安装版 WebView2，使用真实界面命令、编辑器输入、Tauri 后端与磁盘文件，没有替换 IPC。

测试文件仅位于 `.tmp/manual-md-nb-20260926`。不修改已有用户文档。

## 实测结果

- MD 转 NB：同目录产生同名 NB，文件树以 NB 为主体、关联 MD 为缩进子项；磁盘没有额外套目录。
- 打开关联 MD 改字并保存、从磁盘直接改 MD：NB 自动收到更新；文字颜色和高亮保留。
- NB 与 MD 分别改不同段落：可合并，NB 尚未保存的修改保留。
- 双方改同一段落：出现冲突提示，普通保存没有覆盖任一磁盘文件；明确选择保留 NB 后才更新 MD。
- NB 连续两次保存：已打开的 MD 源码同步更新，与磁盘一致；再次从 MD 改字返回 NB，颜色和高亮仍保留。
- NB 转 MD 降级：颜色、高亮、模糊、缩进和对齐效果移除，文字与加粗保留；折叠块展开并保留标题及全部正文；说明按编号附到文末。MD 不包含 NB 帧记录或私有样式数据。NB 自身仍保留原效果。

## 本轮发现并修复

1. 安装版 console 实际报 `directoryWatcher ... forbidden path`。watch 命令权限存在但路径 scope 缺失，已在统一订阅入口先授予具体目录的非递归 scope。
2. 成对保存只更新 MD store 与磁盘基线，已挂载的源码编辑器仍保留旧文本。后续 flush 会误标为未保存。已同步源码与可视化编辑器，并保留写盘期间的新输入及输入法合成。
3. 未保存 MD 被误归为文件不可读，导致显示解除关联动作。已归为 busy。

## 已确认限制

当 NB 含折叠块、说明等会改变 Markdown 块数量的结构时，MD 再改普通正文也会进入结构冲突保护，当前不能自动回传。实测普通保存没有覆盖外部 MD，明确保留 NB 可以完成成对保存。需要投影来源映射才能扩展自动合并范围。
