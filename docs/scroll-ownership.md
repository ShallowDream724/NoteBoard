# 编辑区滚动所有权

正文滚动由 `data-editor-scroll` 容器拥有。大纲跳转先提交选区，再用 ProseMirror 的无滚动聚焦同步 DOM 选区，最后由 `revealEditorBlock` 一次定位目标标题；不叠加 TipTap 延迟 focus 滚动和浏览器祖先 `scrollIntoView`。到达文档末尾时，浏览器可能限制标题顶部对齐，因此点击项保持当前状态，直到用户继续滚动或修改正文。大纲列表只调整自身 scrollTop，不滚动正文或外层布局。

空段落菜单的异步租约直接保存原段落位置和映射 bookmark，打开对话框不改动正文选区。提交时先替换该段落，再聚焦并仅在插入块离开可视范围时进行一次有界定位；能放入视口的表格同时显示完整表格和底部四行空间，超高块只显示前缘，不通过光标定位把视口拖到块底部。图片继续使用已有的一次性图片前缘定位。链接弹窗由调用方恢复编辑器焦点；其他临时弹窗恢复原焦点时使用 `preventScroll`，焦点返回与滚动导航分开。

正文底部空间由 CSS 提供，随正文字号和行高保留四行高度。这段留白属于编辑布局，不生成空段落，也不进入保存或导出数据。

顶部工具栏与斜杠命令通过 `insertDocumentTable` 复用同一可视区策略。表格与斜杠查询删除在一个离散事务中提交，撤销一次即可恢复原段落；提交后光标位于首个单元格。插入不再叠加 TipTap 表格命令的光标滚动或延迟 focus 滚动。小表格完整显示并保留底部四行空间；超过可视区的大表格定位前缘，便于立即编辑首行。
