# 图片复制与粘贴目标

2026-09-27：NB/MD 可视编辑共用 `imageInsertionTransaction`。文件图片与富剪贴板中的纯图片切片都通过该入口插入；代码或混合文本仍走各自的粘贴语义。

- 右键图片首先建立该图片的 NodeSelection，避免复制之前停留的文字选区。
- 鼠标停在空的图片槽时，Ctrl+V 以该槽为目标；停在已有图片/图注时不抢走别处光标的粘贴。
- 在宫格或轮播内粘贴图片，按顺序填充空槽，保留已有图片和图注；空槽不足时追加槽位。禁止让通用切片拟合器把图片挤出容器。
- 异步粘贴跟踪原始槽位，目标失效则放弃；混合文字使用原始文字选区，不能因为经过空槽而改变文字落点。
- 同次图片插入及尾段补齐属于一次事务，撤销恢复整个动作。
- 正文、补充说明草稿与图片地址输入共用同一插入事务。空段落直接替换为块级图片；最后一张图片后复用或补齐正文段落，光标落在该段开头。正文与图片不会写入同一行。
- 独立图片以 `caption/captionContent` 保存图注；宫格与轮播的每个槽以唯一 `paragraph` 保存图注。插入、剪贴板导入和旧文档归一化会迁移图片属性中的富文本图注，并清空重复属性；HTML `figure/figcaption` 保留粗体、链接和颜色等格式。
- 选中槽内图片复制时同时携带图注，剪切时整体移走图片、图注和关联说明，原图片资产保持可用以供后续粘贴。剪切不触发删除偏好。
- `MediaEditing` 在正文和补充说明编辑器间共享键盘规则：段尾 ↓ 选中下一张图片或整个图片组合，再按 ↓ 到后续正文；↑ 对称返回。选中图片按 Enter 在下方继续输入；终端媒体按 ↓ 时可补齐正文。图片组合中的图注不会形成隐藏的纵向光标停靠点。其他表格、公式、提示块和代码的键盘逻辑仍由自身处理。
- 删除图片的内容偏好 `file.imageCaptionDeletionPolicy`（询问/一并移除/保留）独立于原图文件回收偏好。保留时图注变为段落，图片补充说明的锚点随之保留；取消不修改文档。原图资产回收继续在保存后的既有流程中处理。
- 本地图片文件和剪贴板位图在读取字节前共用大文件确认阈值；多张图片先确认整批，再依次读取与保存。

新建空白 NB/MD 显式请求一次焦点，初始化完成且仍为活动文档时执行；会话恢复、后台挂载和已有文档打开不会请求该焦点。

图注入口样式由 `captionAddControl.css` 统一提供。独立图片、图片集合、表格保留相同的悬停/键盘反馈和点击区域，不覆盖图片边缘或正文。

图片编辑和资源预算见 [图片编辑与内存边界](image-editing-plan.md)。
