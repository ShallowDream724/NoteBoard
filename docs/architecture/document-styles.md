# 文档样式与 Markdown 正文

## 边界

`features/document-style` 管理文字颜色、高亮、段落对齐/缩进和单元格对齐。表格结构、尺寸与底色继续由 `markdownTable` 的局部元数据负责，二者共用颜色校验和编辑 schema。文字 mark 与格子 background 是不同层，允许叠加。

Markdown 正文保持普通语法。新增样式不靠插入行内 `<span>` 或 `<mark>` 保存，而在文件末尾独立写入 `<!-- noteboard-styles {...} -->`。支持 HTML 的预览器通常忽略注释；禁用 HTML 的预览器可能显示注释文字。该限制已作为单文件方案的兼容边界确认，不能宣称所有 Markdown 软件都保持相同显示。已有 `<mark>` 仍可读，可视化保存时迁移到新格式。

## 模型与命令

- `documentStyles.ts` 定义 `textColor` mark、段落 `textAlign`/`indent` 和单元格 `verticalAlign`；单元格水平对齐复用原有 `align`，不建立第二份状态。
- `colors.ts` 只接受六位十六进制颜色，统一文字与背景色板。透明背景、默认文字色使用 null，不将任意 CSS 写入 HTML。
- 行内公式和文字共用 marks；行间公式使用节点 `textColor` / `background` 属性。共同命令同时处理两种表示，行间公式不会挂载不合法的行内 marks。公式原子范围覆盖完整 TeX，源码增删沿用增量区间树；恢复 marks 时不再跳过行内公式。只在点击公式正文时进入编辑，块选中与菜单悬停不启动公式编辑。
- `stylePreference.ts` 保存上次使用的前景/背景组合，独立于当前文档选区。主按钮一次事务应用两种颜色；色板中的单项只改变对应层。
- `HighlightControl` 是顶部工具栏和文字选区共用的控件。A 与箭头共享外形，各自有操作区域；与其他工具栏菜单共用 `useHoverMenu`：悬停 180ms 开始旋转，再过 90ms 打开面板，离开有 300ms 缓冲。配色仅箭头触发悬停，A 直接应用记忆组合。键盘、触摸点击和 reduced-motion 均有独立路径，悬停不移动编辑器焦点。
- `AlignmentMenu` 共用对齐入口。文字选区操作段落，格子选区操作单元格；表格批量操作由 `TablePresentationStep` 完成，文本内容与位置不变。

## 持久化

`presentationMetadata.ts` 在 MarkdownManager 上安装一次编解码器。编辑器初始化与无视图的 `documentParser()` 都使用它，Worker、源码格式命令和导出不会另建一套语法。

序列化先提取样式，正文通过既有 Markdown serializer 输出。每个有样式的顶层块记录索引、内容/结构 guard，以及块内子节点路径；文字范围按 UTF-16 偏移记录。颜色和高亮分别保存，可在同一段文字重叠。段落/格子的属性只从对应节点提取，其他扩展的属性不受影响。

guard 包括规范化后去除样式的结构与内容长度、两个独立 32 位摘要。整个文档未改时按索引恢复重复段落的各自样式；外部改动后，只恢复唯一、完全匹配的块。无法确定对应关系时舍弃样式，优先保留正文，不做模糊文字匹配。摘要是误用防护，不是安全签名。

只识别末尾、独立成段且被词法器判断为顶层 HTML 的注释；代码围栏与引用里的示例不会被吞掉。支持 LF/CRLF。版本、路径深度、范围边界、颜色与属性都受校验；过大输入不解析样式。写出限制为 2,000,000 字符、20,000 块/记录及单记录最多 20,000 范围，超出时明确报错，不能静默丢弃样式后保存。

Markdown 源码不再主动创建私有颜色/高亮 footer；`applySourceTextStyle` 拒绝新增，源码高亮快捷键只允许清除已有 HTML mark。增强样式经格式能力确认转换为 NB 后在可视化编辑器应用。已有 Markdown 注释与 HTML 仍可读取、随正文编辑保留。NB 源码直接编辑原生记录，不挂载这套 Markdown 样式 tracking。

### 应用内源码编辑

`sourceStyleTracking` 是 CodeMirror StateField，进入源码时将样式转换为源码区间；文字前景/高亮（含行内公式）、段落、单元格、行间公式分别维护四层。`styleSpanTree` 用持久化 AVL 树保存片段长度，后缀偏移由子树长度隐式计算。一次编辑分割边界并连接新片段，单个修改的附加成本为 O(log R)，其中 R 是该层的片段数；删除整段不遍历被删子树。中间插字继承左侧样式，范围删除收缩样式，应用历史恢复会重建对应快照。键入不解析 Markdown、不遍历全部样式、不重写 footer。

保存、切模式、历史组物化和导出复用同一个读取边界：端点四趟 radix 排序，源码/文档位置一次映射，随后一次遍历重建样式。新增区间映射为 O(N + R)，仍在原有全文序列化边界执行；不承诺第三方 Markdown parser 本身的复杂度。缓存按不可变文本对象弱持有，不保存编辑器引用。

这只保证 NoteBoard 内可观察的源码编辑。外部软件修改后仍使用上述 guard 规则，不能凭摘要推断插字位置。用户直接编辑 footer 时以其源码为准，停止用旧的内存样式覆盖它。

## 导出与成本

HTML/PDF 由同一 schema 输出颜色、对齐及缩进，打印颜色设置 exact。Pandoc AST 携带前景、段落与格子样式；Word/LaTeX 不保证保留全部样式，原生导出提供明确提示。PDF 分页只改变展示，不修改原文档的逻辑行列身份。

提取和 guard 计算发生在序列化阶段，不在每次输入事件同步执行。恢复先按块建 guard 索引，范围按类型排序并线性扫描文字片段；缓存弱持有当前文档，不保留关闭的编辑器。正常保存仍需遍历正文，不能称为恒定时间。

## 回归

`documentStyles.test.ts` 覆盖重叠样式、重复块、外部编辑、旧高亮、嵌套表格/列表和通用 Markdown 预览；`sourceDocumentStyles.test.ts` 覆盖源码动作不新增私有 metadata、不同换行及已有注释读取保留。`sourceStyleTracking.test.ts` 覆盖中间增删、换段、历史快照、注释手动编辑、输入热路径和十万样式片段的路径共享。真实浏览器检查组合按钮、悬停、记忆配色、透明第一格及字号变化。
