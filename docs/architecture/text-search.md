# 文本查找、定位与替换

搜索栏经 `SearchCapabilities` 访问当前编辑器。普通文本查询保持同步返回；用户正则通过可终止 Worker 返回 Promise。`MatchStats` 可携带等待状态与错误，能力订阅用于正文修改后更新结果；搜索栏保留查询文本和可复制错误，并忽略旧请求的迟到结果。

## 查询索引与高亮

`editor-md/searchReplace.ts` 继承原扩展的命令与存储，仅替换装饰插件。`searchDecorations.ts` 只在正文、搜索词或大小写规则改变时收集连续文本段和匹配位置，跨 marks 的文本仍可匹配，非文本节点分隔文本段。导航复用同一结果索引，不重新遍历正文或执行匹配。

普通高亮与当前匹配采用独立装饰层。可视化编辑器根据实际 `[data-editor-scroll]` 可见区域取得文档位置，二分查找索引，仅生成附近窗口最多 2,000 条普通装饰及一条当前装饰；不为全部匹配创建 DOM。滚动与尺寸变化合并到动画帧，只更新窗口。没有匹配时不安装滚动监听或 ResizeObserver；清空、切标签、切模式和卸载会取消监听。未连接或隐藏的编辑器不计算屏幕位置。

`sourceSearchSnapshot.ts` 为每个 CodeMirror 视图保存一个按不可变 `Text` 身份和查询规则匹配的 `Uint32Array` 位置索引，替换文本变化不使它失效。全文计数只在正文或查询变化时重新执行，导航用二分定位当前序号。普通文本高亮继续使用 CodeMirror 的可见范围装饰；正则由 `regexHighlights.ts` 读取 Worker 索引，普通窗口和当前结果同样分层，最多 2,000 条窗口装饰及一条当前装饰。

索引空间按匹配数增长，不与页数或字符数相乘。ProseMirror 普通查询保留与原扩展兼容的 Range 数组，CodeMirror 与正则使用每处 8 字节的紧凑位置。导航只新建当前装饰；ProseMirror 构造装饰树及编辑器自身选择/滚动仍有框架成本，并非常数时间或零布局承诺。

## 正则会话与替换

`regexSearchSession.ts` 按实际编辑器对象持有最新文档/查询快照。正则不传给 CodeMirror 原生 `regexp` 查询，也不进入可视化编辑器的同步匹配器。Worker 的匹配语义、硬预算和实际终止验证见[正则搜索的计算边界](../performance/regex-search-worker.md)。

- 文档修改后清空旧装饰、取消旧任务并基于新不可变文档重新查询。查询变化、清空、关闭、切标签/模式和编辑器销毁均结束旧会话；退订捕获旧目标，不用切换后的动态目标清理。
- 结果落地前核验取消信号、会话和文档身份。搜索栏同时核验请求序号；过期结果不能覆盖新查询计数或修改正文。
- 导航复用索引。替换时才向 Worker 请求替换展开，提交前再次核验会话、正文、替换文本和只读状态。失败或超限返回空计划，不进行部分替换。
- CodeMirror 保留原生捕获替换与语言整词边界；可视化模式保持字面替换和既有文本段边界。长文本匹配和替换仍是全量任务，Worker 负责隔离表达式回溯，不能消除生成索引、提交正文和撤销记录的必要成本。

## 工作量合同

`test/search/searchDecorations.test.ts` 使用 5,000 段、50,000 个匹配的真实 ProseMirror 文档状态，验证下一处导航复用全部索引与普通装饰、正文遍历为零、仅生成一条当前装饰。窗口刷新不重搜且普通装饰不超过 2,000 条。另一合同验证无查询滚动零 `posAtCoords`、零事务，查询仅改变时启用观察，关闭后恢复为零。

`sourceSearchSnapshot.test.ts` 验证选择及替换文本变化复用相同索引，真实文本修改使缓存失效。`regexSearchSession.test.ts` 覆盖两种实际编辑器的匹配/替换接入、导航复用、取消迟到响应、文本修改后的刷新、只读双重检查和旧目标清理。Worker 的超时/终止由独立 Worker 合同验证，不把测试替身的响应时间当作浏览器性能。
