# HTML 文件与源码编辑

`.html` 与 `.htm` 使用共享扩展名映射归类为 `code` / `html`。Rust 和前端使用同一映射，语言枚举同步；状态栏显示 HTML，标签页和资源树使用带源码符号的橙色浏览器图标。

HTML 标签默认显示阅读预览，顶部可切换到 CodeMirror 源码编辑器；预览使用无授权的 sandbox iframe，页面脚本无法执行或调用桌面 API。导出的独立 HTML 在内部预览时隐藏依赖脚本的打印/副本按钮，外部浏览器中仍可使用。切换回预览时从当前 CodeMirror 内容取快照，因此未保存修改也能检查。源码编辑沿用手动保存策略、撤销历史、搜索替换、换行与行号设置。HTML 语言包按需加载，直接声明现有 Markdown 依赖树中的 `@codemirror/lang-html`，支持 HTML 及内嵌 CSS/JavaScript。HTML 工具栏隐藏 JSON 和 XML 格式化工具，不对网页源码进行猜测式格式化。

工具栏提供保存、复制当前源码、另存为、浏览器打开与资源管理器定位。保存和另存为复用既有文档事务与输入屏障，复制源码读取当前编辑器快照。浏览器动作通过系统默认应用打开磁盘上已保存的文件；预览中的未保存修改须保存后才会出现在外部浏览器中。另存为默认使用 HTML 文件过滤器。

导出 HTML 成功后，`presentExportedFile` 报告文件大小和警告、刷新所在工作区，并在应用内打开 HTML 标签。用户可直接阅读预览，也可通过工具栏用默认浏览器打开或在资源管理器中定位，以便分享文件。标签打开失败仍保留导出成功提示并说明保存位置。其他导出格式沿用相同的完成展示。
