# HTML 文件与源码编辑

`.html` 与 `.htm` 使用共享扩展名映射归类为 `code` / `html`。Rust 和前端使用同一映射，语言枚举同步；状态栏显示 HTML，标签页和资源树使用带源码符号的橙色浏览器图标。

HTML 沿用 CodeMirror 源码编辑器、手动保存策略、撤销历史、搜索替换、换行与行号设置。HTML 语言包按需加载，直接声明现有 Markdown 依赖树中的 `@codemirror/lang-html`，支持 HTML 及内嵌 CSS/JavaScript。HTML 工具栏隐藏 JSON 和 XML 格式化工具，不对网页源码进行猜测式格式化。

工具栏提供保存、复制当前源码、另存为、系统默认应用打开与资源管理器定位。保存和另存为复用既有文档事务与输入屏障，复制源码读取当前编辑器快照。默认应用打开的是磁盘上已保存的文件；未保存修改仍留在源码标签，用户可先保存后打开。另存为默认使用 HTML 文件过滤器。

导出 HTML 成功后，`presentExportedFile` 继续报告文件大小和警告、刷新所在工作区，再调用既有 `open_with_default_app` 命令；不自动建立源码标签。系统关联通常为浏览器，启动失败保留导出成功提示并说明可到保存位置打开。用户主动在 NoteBoard 打开 HTML 时才进入上述源码编辑流程。其他导出格式沿用原有完成展示。
