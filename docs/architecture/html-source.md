# HTML 文件与源码编辑

`.html` 与 `.htm` 使用共享扩展名映射归类为 `code` / `html`。Rust 和前端使用同一映射，语言枚举同步；状态栏显示 HTML，标签页和资源树使用带源码符号的橙色浏览器图标。

HTML 标签默认显示阅读预览。标签栏右侧的按钮在预览与源码之间切换，收起编辑工具栏后仍可使用。回到预览时读取当前修改，再次打开源码时恢复选区和滚动位置。普通 HTML 在禁脚本的 sandbox iframe 内读取，NoteBoard 独立导出页的增强与资源解析规则见[文档导出](document-export.md)。

源码编辑沿用手动保存、撤销、搜索替换、换行与行号设置。CodeMirror 按需加载 `@codemirror/lang-html`，支持 HTML 及内嵌 CSS/JavaScript。

工具栏提供保存、复制当前源码、另存为、浏览器打开与资源管理器定位。保存和另存为复用既有文档事务与输入屏障，复制源码读取当前编辑器快照。浏览器动作通过系统默认应用打开磁盘上已保存的文件；预览中的未保存修改须保存后才会出现在外部浏览器中。另存为默认使用 HTML 文件过滤器。

导出 HTML 成功后，`presentExportedFile` 报告文件大小和警告、刷新所在工作区，并在应用内打开 HTML 标签。用户可直接阅读预览，也可通过工具栏用默认浏览器打开或在资源管理器中定位，以便分享文件。标签打开失败仍保留导出成功提示并说明保存位置。其他导出格式沿用相同的完成展示。

桌面回归用 `scripts/launch-native-qa.py` 打开含相对路径图片的 HTML，再运行 `node scripts/check-html-preview-native.mjs <启动记录.json> <图片数> [标签名]`。检查会在 WebView2 的预览框内逐张解码图片，能检出宿主可读而预览却显示破图的情况。
