# 有序列表的接续、显示与操作范围

列表包装器保存十进制 `start`、可选 `numberStyle` 和 `numbering`。`continue` 表示接在同一父容器的上一段有序列表之后；普通段落、公式、图片、待办不消耗序号。`restart` 是用户明确设置的独立起点，不被自动合并吞掉。缺省属性保留普通 Markdown 和嵌套列表的原有表现。

`numbering/model.ts` 负责定位、接续组、结构分段和起点规范化。插入内容块、转换列表类型、还原正文复用这一层。删除或转换某些项后，其余项按保留下来的数量重排；拖入有序列表的有序片段采用目标位置的序号，保留内容、说明和其他显示属性。删除整个组首时，原组起点转交给仍存活的片段，不能接到前面的无关列表。

`ListNumbering` 只在结构事务后规范化。事务映射和存活条目身份识别 Enter、lift、移动造成的分段，不依赖全局编号 id。普通文字输入不遍历列表。操作结束即释放来源映射；没有常驻的全文编号缓存。`NumberingAttributesStep` 一次更新多个片段，共享未修改子节点、保持空位置映射，并一次复制祖先，避免每个片段保存一份中间文档根。

操作范围遵循用户的显式程度：插入光标或左侧单项 NodeSelection 改编号样式时作用于整个接续组；非空文字选区只处理与选区重叠的条目。嵌套列表独立。添加/取消列表只作用于目标条目；从指定数字重新编号则从当前项建立新起点，联动它后面的接续片段。Backspace 在最外层条目的首段开头移除当前标记，不把正文合并到上一行；嵌套项先退一级。

顶栏、左侧块菜单、多块菜单和窄窗口溢出入口共用 `NumberingControl` 与命令层。主图标立即切换有序列表，箭头打开三行选项。来源预览只显示已识别的前项和修改后的当前项，不滚动正文。样式菜单用真实列表示例展示九种样式，数字、圆圈、方框、中文优先。

起点输入每次打开显示 1，但不立即应用。合法输入在当前编辑器中预览，不发布到自动保存或文档时间线。菜单关闭或 Enter 将完整输入提交为一次操作；Escape 撤销预览。短期草稿只保留逆步骤和不可变根，提交、取消或销毁时释放。编辑器派发中间层在异步插图等外部内容事务执行前先结算草稿，保证传入事务的位置仍有效；外部操作独立撤销。应用历史捕获 `editor.state.doc`，包含附加规范化后的最终内容。

菜单草稿事务带通用 `EDITOR_MENU_PREVIEW_META`。侧边把手与选中反馈在预览期间保留菜单，通过事务映射和已恢复选区的祖先路径识别原条目，不因替换列表包装器而丢失目标。普通编辑、撤销、目标删除仍关闭菜单；该机制只保留当前目标，不建立全文缓存。

`styles.ts` 和 `styles.css` 为编辑器、HTML/PDF、命中测量与预览提供相同的格式规则。圆圈和方框不依赖有限的 Unicode 圈号字符。原生文档直接保存 schema 属性；Markdown 正文仍是十进制列表，额外显示与接续属性沿用受内容校验保护的样式元数据。相邻有序分段使用标准 HTML 注释 `<!-- noteboard-list-boundary -->` 保留边界，不生成空段落。外部源码改动使校验失效时会放弃无法确认归属的样式与接续链接，正文中的显式起点仍可读取。

编号使用正文首行的行高定位，圈号/方框在同一行内居中；长编号不增大高度而挤入相邻行。有序列表在 schema 的 HTML 渲染阶段派生 `data-numbering-layout="columns"`，以 CSS grid/subgrid 的固有宽度列在正文内部保留完整标记并右对齐；普通编号保持原有 1.8em 的正文缩进，长编号随固有宽度右移正文，左侧操作栏不被挤占。列宽由 CSS 跟随子项变动，无须外层 renderHTML 重新执行即可跨数字位数边界。嵌套列表独立重置原生 counter，不增加 NodeView、逐项缓存或观察器；派生布局不进入 Markdown/原生文档属性，编辑器与 HTML/PDF 共用。旧浏览器不支持 subgrid 时保留原生列表。九种菜单示例使用相同的行高、间距和标记栏。相邻列表类型或样式片段采用列表项间距，不额外加入段落间距，实际空项仍保留；Markdown 的空有序项在上游解析后补回 schema 必需的首段，防止保存重开后出现无正文节点的列表项。

输入起点支持 1–999,999,999；更大的值、零和非整数显示就地说明，取消已存在的有效预览，不能在关闭菜单时悄悄提交前一个数字。该边界兼顾 Markdown 九位起点和浏览器原生整数计数限制；实际接续生成的后续项允许超过九位。

业务回归覆盖：单项/批量转换与移动、媒体打断、整组首段删除、首行和空项 Enter、嵌套退格、显式范围与整组样式、实际输入预览及撤销、异步插入期间结算、Markdown/原生保存重开、批量属性逆操作、菜单焦点与浮层所有权。
