# 设置与更新边界

## 唯一设置界面

标题栏齿轮打开 `SettingsModal`。左上角只切换资源管理器。废弃的 `SettingsWindow` 没有调用方，旧建窗协议也已失效，现已移除。

标题栏按「侧栏、主页 | 文档标签、新建 | 导出、设置、右侧栏 | 窗口控制」排列。`NewDocumentMenu` 管理新建/打开入口，`TabBar` 只管理标签、排序与标签菜单。新建按钮随最后一个标签移动；标签溢出时只压缩标签滚动视口，按钮留在视口外。无标签时不挂载标签轨道，也不保留主页与标签间的分组留白，新建按钮与主页保持 4px 间距；新建菜单本身保持挂载，关闭最后一个标签不会重置其状态。保留固定操作与至少 32px 的拖拽空白区，不依赖猜测全窗口宽度的常量。保存仍由 Ctrl+S / Ctrl+Shift+S 和统一保存流程处理；标题栏不再放保存、快捷主题、检查更新按钮。

标签默认透明、无边框，悬停时显示圆角底色。活动标签轮廓由 `tabShape.ts` 定义：10px 上圆角、12px 底部反向圆弧，与竖边相切并融入工作区。固定比例的左右 SVG 遮罩与可伸缩中段在同一个 CSS 伪元素绘制，平直重叠区避免分数缩放接缝；遮罩只在模块初始化时生成，不为每个标签测量或创建 SVG 节点。弧角宽度和边缘收口共用 `TAB_EDGE_INSET`。关闭按钮常显，不因悬停改变标题宽度。文字末尾使用带尾部留白的 CSS mask：短标题保持完整，超长标题淡出，关闭按钮不参与文字遮罩。`AppShell` 统一派生标题栏底色、文字和悬停色，提高活动标签与背景的区分，三套主题共享语义。

标题栏操作共用 `titlebar-action`：28px 正方形点击区、6px 圆角、统一 focus-visible 描边。新建采用圆形；标签关闭为 20px 圆形。窗口控制独立分组，关闭悬停保留红色识别。只过渡颜色，不做缩放或逐次鼠标事件写样式，减少动态效果时禁用过渡。`SidebarToggle` 接受样式类，保留自身语义和其他位置的表现。

`useTabOverflow` 只观察滚动视口和内容轨道两个元素；scroll/resize 在一帧内合并，不驱动 React 标签树重渲染。标签集合变化时缓存 DOM 引用，滚动时按布局顺序二分读取右边缘候选，O(log n) 几何读取、O(1) 属性写入；缓存为 O(n)。只有存在隐藏内容的边缘才有渐隐。右键菜单 portal 到 body，复用 `useMenuBounds`，避免被滚动遮罩裁剪；卸载注销观察器、滚动/焦点监听和待执行帧。

右端标签只露出不足 48px 且前一个标签仍有可用宽度时，连同候选的弧角隐藏。可见边界落在前一个标签右侧 12px 肩角留白之后，移除该项尾部分隔线，新建按钮向左移动同量。只改变 opacity、clip/mask 与 transform，不修改视口宽度、scrollLeft、DOM 顺序或标签宽度，所以不会产生测量—收缩—再撑开的反馈循环。收口变量在 track 根处重置，不向每个标签后代传播。极窄视口保留唯一可见项。键盘聚焦时主动将目标标签滚入视野；拖动开始暂时解除收口，结束/取消后按当前顺序重算。

标题栏与工作区的分界由 `AppShell` / `appShell.css` 统一负责。工作区左上、右上采用同一个 `--workspace-corner-radius`，主题色窗口底色从圆角露出；边界用底色区分，不加横穿活动标签连接处的细线。侧栏、编辑器、首页无需各自加圆角。仅裁剪已有工作区容器，不增加遮罩图片、观察器或额外组件状态；演示模式隐藏标题栏时恢复直角全屏内容。面板内的标题行、编辑工具栏分隔线保留。

NB 与 Markdown 可视编辑共用 `nb-document-stage` 的正文边距：顶部默认 32px，编辑面板不宽于 720px 时为 24px。留白属于编辑内容的 padding，随正文滚动，不占固定工具栏高度，也不插入空段落；首块额外上边距归零，避免标题叠加一层空白。嵌入式编辑器和多维表格富文本不套用该规则。Markdown / NB 源码和 TXT / 代码编辑器保留各自已有的 16px 顶部 padding。导出使用独立文档样式与纸张页边距。

资源管理器标题行与正文工具栏保留各自高度，不为横向对齐增加留白或压缩按钮；两条主分隔线各止于所属面板，路径栏的次级分隔线更淡。`PanelResizeHandle` 统一管理左右面板分隔条外观：可见宽度 2px，面板不再叠加额外边框。指针和键盘调整仍由 `react-resizable-panels` 负责，鼠标最小命中范围为 10px、触摸为 20px；悬停/拖动/焦点用库的状态属性着色，不在鼠标事件中直接写样式。

文件树通过 `VerticalScrollArea` 使用 Radix ScrollArea 1.2.18：滚动内容保留原生 `scrollTop`，滚动条覆盖在内容上，没有左右占位槽或上下按钮，选中背景自然延伸到面板边缘。文件名仍在可用宽度内省略。滚动位置不进入业务 React 状态；观察视口和内容容器的尺寸，不扫描文件行，不重建 Markdown 编辑器。显隐由 CSS 处理：鼠标悬停、拖动中或内部 `:focus-visible` 时显示；普通鼠标点击留下的焦点不维持显示，避免移出后滑块常驻。不增加全局输入监听、定时器或业务状态。字号、展开目录或面板尺寸变化由同一容器测量响应。滑块尺寸由库的滚动映射统一计算，不用 CSS 最小高度覆盖；滑块右侧留白避开分隔条的扩展命中区。其他编辑器的滚动容器沿用既有行为。

`SettingsModal` 仅负责分类导航、滚动复位和关闭；导航按外观、工作方式、应用分组，外观、字体、编辑器、文件与保存、导出、快捷键、关于各有一个面板。`SettingsControls` 提供统一的面板标题、区块与设置行，用分隔和留白组织相关选项，不重复嵌套大卡片。面板统一调用 `settingsStore`；该 store 负责调用 Rust 持久化和接收设置广播。独立的文档窗口仍共享设置，这不等于存在另一套设置页面。

`settings.css` 管理设置壳、可收缩网格、可换行表单行和字号比例。字体网格按内容区宽度与 UI 字号自动分列；窄窗口将分类改为横向可滚动导航，内容区独立滚动，标题和关闭按钮保持可达。不能靠裁切横向内容掩盖控件最小宽度溢出。

排版页只提供一个“全部恢复默认”。`default_typography` 返回 Rust `TypographySettings::default()`，前端沿既有 `patch_settings` 队列一次提交完整 typography 分组，不动其他设置和已下载字体包。界面、正文、代码和文件树各自将即时预览放在对应控制项下方；字体选择、数值范围和设置字段保持独立。共享宽度与范围控件避免复制状态逻辑；宽度预设用 `aria-pressed` 表示选中，不在鼠标事件中写入动效样式。说明文字放在所属标题下，并明确 Ctrl+滚轮作用于代码编辑区。

`FontSelect` 用 Radix Popover portal 解决滚动卡片裁剪，由组件库负责边界翻转、Esc 和焦点返回。`fontCatalog` 首次打开时才枚举系统字体，共享在途请求与结果；关闭的选择器不订阅列表。筛选 O(n)，虚拟列表仅挂载可见项和少量预留项，字号变化使用实际行高测量。异步请求只发布数据，没有延迟聚焦回调。应用字体包变化合并进同一目录；读取失败保留重试入口。

`TooltipProvider` 以一个捕获阶段输入监听记录最近是否为 Tab/方向键导航，不驱动 React 更新。Tooltip 只为键盘导航触发的焦点显示提示；鼠标关闭或 Esc 后恢复按钮焦点不会重新弹出提示。焦点仍正常归还，后续悬停和 Tab 提示不受影响。跟随鼠标的 Tooltip 在按下时取消未完成的延迟和位置帧。

选区工具栏位置属于编辑器设置；Pandoc 程序路径属于导出设置。纸张、方向、边距、正文字号、段内行距、段后距及页码开关/位置/格式在导出预览中调整，并以 `export.pdf` 保存为下次打开的页面默认值，重启应用后仍保留。它们不写进正文或编辑器状态；单个对象的排版方式、超宽内容选择和「仍按预览导出」确认只属于当前导出会话。

外观面板使用 `ThemeCard` 与 `appearance.css`，预览色取自主题注册表。渐变、透明叠层和文档小样都是静态 CSS，不加载图片、不设动画循环。卡片采用原生按钮、选中语义和键盘焦点；窄面板自动改为单列。

Pandoc 路径留空表示自动查找。进入导出设置及已保存路径改变时，`usePandocStatus` 调用同一个原生检测入口，显示版本及 `resolvedPath`；该结果只存在于面板会话，不自动写回设置。路径改变、刷新或关闭后，旧请求不能覆盖当前结果。检测和实际导出共用 Rust `resolve_program`，前端不重复实现搜索目录。

图片删除确认框的“记住选择”和文件设置中的选择器都修改同一个 `imageDeletionPolicy`，业务行为由 `imageAssetLifecycle` 读取，不在 UI 中重复实现。

## 持久化与并发

Windows 窗口几何由 `window/geometry.rs` 独立管理，与文档会话和设置分离。移动/缩放只更新进程内快照；使用 `GetWindowPlacement` 的正常还原矩形，避免把最小化时的 288×35、(-32000,-32000) 保存为下次启动尺寸。最小化保留此前的最大化状态；窗口显示前才调用对应的 `SetWindowPlacement`，正常矩形的工作区坐标不会混用为屏幕坐标。完整退出时一次原子写入 `window-layout.json`，缩放事件不写磁盘，窗口 API 在互斥锁外执行。恢复成功后才开启该窗口的快照采集，失败允许重试。

首次从旧 `.window-state.json` 迁移时，按当前 DPI 校验逻辑最小尺寸、位置哨兵和整数边界；合法记录沿用旧插件的内部尺寸/屏幕坐标含义，不转换正文、会话或其他设置。无效记录使用正常默认尺寸并居中，默认尺寸受显示器工作区限制；旧文件保留，不覆盖。导出排版窗口不参与保存。非 Windows 保留原插件，仅恢复尺寸、位置和最大化状态，不持久化可见性。唤醒已有 Windows 窗口只在确实最小化时调用原生 `SW_RESTORE`，保持正常的最大化状态。

Rust 设置模型持有进程内唯一确认快照，互斥锁覆盖修改、原子写盘与确认。`patch_settings` 只提交实际改变的分组字段；不同窗口修改不同字段不会覆盖彼此。每次成功提交由原生分配严格递增的 revision，磁盘失败不推进 revision 或确认快照。旧 `save_settings` 全量接口保留 revision 比较并拒绝陈旧请求，不能覆盖更新的数据。启动时仍沿用缺字段默认值与损坏文件备份逻辑；设置文件不作为应用运行期间的外部编辑接口。

`imageEditor.tools` 由工具名、参数名逐层合并，禁止用窗口内的整份工具对象覆盖其他窗口的变更。`settings/image_editor.rs` 校验已知工具、适用字段、枚举、六位颜色和值域；旧设置缺少该分组时使用默认值。前端乐观副本采用相同字段级合并，`setImageEditor` 写入失败回滚且向调用方抛错。此分组仅存轻量工具偏好，不保存图片路径、像素、标注文本或位置。

`export.pdf` 在前端副本与 Rust 事务中按页面字段合并，保留其他窗口修改的页面字段与 Pandoc 路径。导出弹窗打开时读取一次默认值；打开期间的远端广播留待下一次会话，不重置当前选项或触发重新分页。只在选择框/复选框修改或数字框失焦、Enter 提交时写入实际改变的字段，挂载和未完成输入不写盘。`settings/pdf_preferences.rs` 拒绝未知字段、文档级数据、非法枚举和值域；加载旧设置时缺失或非法的页面字段各自回退默认，保留有效字段和其他设置。写入失败沿既有副本回滚并在弹窗报告，当前预览仍可继续调整。

前端状态由最新确认快照叠加尚未确认的字段修改得到。同一窗口按操作顺序发送 patch；ACK 只移除对应修改，旧 ACK 或乱序广播不覆盖较新确认，后续本地修改继续保留。失败只撤回对应修改，保留其他本地意图和其他窗口的确认值，并设置 `saveError`；下次明确修改才清除此错误。关闭窗口恢复选项成功持久化后才清除旧窗口记录，清理失败单独报告，不伪装成设置写入失败。

初始化先等待跨窗口监听注册，再读取设置，多个初始化调用复用同一 Promise；加载期间收到的新广播优先于旧读取结果。系统主题跟随监听随当前模式及亮暗主题配置重新绑定，远端修改和失败回滚使用同一条应用路径。字体服务仍独立初始化，不阻塞设置就绪。

## 应用更新归属

应用更新检查、安装包下载和“关于”链接指向 `ShallowDream724/NoteBoard`。Rust 更新服务只接受该仓库的 HTTPS Release 安装包地址，避免把上游版本覆盖到本地二开版本。

GitHub latest-release 返回 404 时表示当前发布源没有可用正式版本：返回空 `latestVersion`、无安装包、`updateAvailable=false`；界面显示“尚未发布正式版本”。其他网络错误仍报告错误，不伪装成无更新。

正式安装读取 GitHub 最新正式版；RC 安装读取最近 100 条发布记录，可升级到后续 RC 或正式版。版本判断使用编译进安装包的完整 Cargo 版本，由 `semver::Version::cmp_precedence` 比较优先级：`1.0.0-rc.2 < 1.0.0 < 1.0.1`，预发布序号按数字比较，构建元数据不构成更新。非法版本不提示升级；正式版不会降级到同号预发布版。GitHub 标签只额外允许一个 `v` / `V` 前缀。

`v1.0.0-rc.1` 的历史安装包误把内部版本写成了 `1.0.0`，且旧比较逻辑丢弃预发布后缀。这些旧客户端必须手动安装一次修正版，或等待大于 `1.0.0` 的正式版；仅修改远端标签无法改变旧程序逻辑。修正版从内部版本 `1.0.0-rc.2` 开始，可以接收同号 `1.0.0` 正式版提醒。

`updateStore` 在启动 3 秒后检查，成功后每 30 分钟检查一次；同一窗口的自动/手动检查共享在途请求，手动点击仍打开检查状态。失败间隔为 30/60/120/240/360 分钟；离线暂停请求，联网后重试，并遵守 GitHub 限流重置时间。关闭窗口注销定时器和网络监听。元数据请求每次上限 6 秒，总检查上限 12 秒；系统代理失败时最多降级直连一次，429 或限流 403 不立即重复请求。下载仍使用独立长超时。网络失败保留此前找到的版本；“关于”展示失败原因，自动失败不弹窗。

`UpdateNotice` 在设置按钮下显示非模态气泡，不夺取焦点；正文只有版本、查看更新、关闭和“此版本不再提醒”。暂时关闭由 `updater/notice.rs` 的进程内集合保存并广播给各窗口，新窗口先订阅再读取，合并快照与并发事件。此状态不写磁盘，完整退出应用后清空。永久忽略版本保存在 `settings.updates.ignoredVersion`，复用既有设置事务和广播；只影响该版本，后续版本仍提醒。已忽略版本仍可在“关于”手动查看或检查，设置图标的更新圆点保留。

更新详情通过 Radix Dialog portal 到 body，避免从设置中打开时进入 inert 的应用根节点；焦点、Escape、下载期间的关闭限制由同一对话框边界负责。提示框统一尊重 side，测量实际尺寸后翻转/限制在窗口内；跟随指针的位置更新按帧合并，禁用提示时不重建触发按钮。

版本号以 `package.json` 为源，经同步脚本将完整 SemVer（包括预发布后缀）写入 Tauri/Cargo 元数据。Release 工作流在构建前校验标签必须等于 `v<package.version>`，手动执行时也要选择对应标签，避免候选版被编译成正式版身份。Release 优先读取 `docs/releases/<版本>.md`，没有专门说明时才从 Git 提交生成；产物与发布标签对应同一提交。

字体包是单独的资源依赖，目前仍使用带校验的原字体发布资源；不能把它机械替换为没有相应资产的 fork 地址。正式发布时再决定迁移该资源，并验证下载与校验。

推荐字体的选择来源、保守迁移与安装后应用事务见 [推荐字体的安装与选择](fonts.md)。
