# 目录更新与导出交接

## 目录状态

`setRoot` 只用于真正切换目录；刷新不能调用它。`explorerActions` 统一目录读取、刷新与文件定位，手动刷新只访问根目录和已展开目录，最多四个并发请求，不递归发现闭合目录，不读取文件正文。体积为 1GB 的附件和 1KB 的附件都只是一个目录条目。

同目录读取共享在途请求。读取期间发生的新刷新会标记 dirty，在当前读取完成后再读一次，避免吞掉连续写入。完成或失败后删除在途记录，不形成第二套永久目录缓存。根目录切换后放弃旧结果；已有缓存分支被删除时，移除对应展开状态和后代缓存。树节点数量与已浏览的条目数量相关，不能承诺与目录项数量无关的常量内存。

`revealExplorerFile` 供标签跟随、定位按钮、打开文档及导出结果共用。当前根包含目标时保持根和其他展开目录，仅按祖先链展开；优先使用已有缓存，缺失才读取。跨根才切换目录。递增的定位代际及调用者有效性检查防止旧异步结果抢回用户刚切换的视图。

`refreshExplorerAfterWrite` 仍作为已确认文件写入的入口，按祖先链刷新，从而发现新建的资源目录。刷新错误不会将已经完成的写入重新执行。系统目录监听和手动刷新共用相同的隐藏文件设置。

## 导出成功

PDF/Pandoc 引擎只负责生成与保存。`ExportModal` 在保存确认后关闭，并交给 `presentExportedFile`：成功 toast → 刷新目标祖先目录 → 统一打开文档 → 共用定位动作。Pandoc 警告独立显示，已保存文件仍可打开；展示失败不能变成“导出失败”。

导出附件的 `exportNotice` 只属于当前标签生命周期。`UnsupportedView` 复用文件名、大小和默认程序/系统管理器/复制路径动作，带 receipt 时显示“导出成功”，不再发格式不支持的 toast。关闭标签即释放，不写入 Markdown、历史或设置。

## 路径与示例

Ctrl+O 的路径输入接受文件和目录，校验只判断存在性，随后统一交给 `prepare_document` 分派。Windows 原生文件和目录浏览保留各自选择器，放在同一个入口中。

功能示例为随包 Markdown，按需加载成未保存副本，主页可随时重新打开。首次空配置、空启动且没有恢复标签时显示一次；既有配置、显式打开和会话恢复不被示例替换。打开前再次检查空标签条件，避免异步模块加载覆盖用户操作。
