# 恢复描述符与文件载荷

`Document.loadState` 区分 `placeholder` 与 `loaded`。`upsertFromPayload` 默认表示已交付载荷；最近关闭窗口只建立轻量描述符时显式传入 `placeholder`。图片和外部程序接管的二进制文件合法地保留 `content: null`，不能以是否有文本作为所有文档的加载判定。文本编辑器仍须得到非 null 正文，空字符串属于合法文本。

`loadRestoredTab` 按文档会话代际共享在途 Promise。只有本会话得到载荷后才清除懒标记；关闭、身份迁移、同路径重开使旧请求失效。旧 Promise 的清理不能移除新代请求。打开链在准备、确认和注册的异步边界检查有效性，在确认本窗口归属后才发布图片载荷。所有同路径打开按顺序完成归属与交付；过期请求释放自己的未交付归属之后，新代才准备，不能仅以新占位 Tab 存在证明注册已被接管。其他路径继续并行，完成的队列键立即释放。注册失败不发布虚假就绪状态。恢复仅加载既有描述符，不重新激活标签、聚焦其他窗口或改资源管理器，避免旧请求抢走焦点。

保存、另存与迁移继续使用 `ensureWritableContent` 的正文屏障：资源载荷加载成功也不能制造空文本，不会把 null 写成空文件。实现只增加每文档一个状态字段和在途请求的代际引用；没有图片字节或正文副本，完成或失效后释放请求。

模型回归覆盖两张图片、外部接管文件、并发加载、注册竞争、准备/注册期间关闭、同路径重开及非文本写入保护。生产浏览器与隔离原生检查读取上次会话中的两张图片，并反复切换检查资源、DOM、监听器和保留堆。
