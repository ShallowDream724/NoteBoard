# 右键菜单边界

`components/useMenuBounds.ts` 统一管理自定义右键菜单和二级菜单的实际尺寸、窗口边界和内部滚动。Markdown、文件树、多维表格、甘特图、收藏文件夹共用它，不再各写一个猜测菜单高度的常量。

菜单四边至少保留 8 px；最大高度取 460 px 与窗口剩余高度的较小值。菜单内容变化或窗口调整时重新测量，菜单滚动不测量。`ResizeObserver` 仅在菜单打开时存活，关闭时注销。内容不可因 flex 收缩而塞进固定高度；长菜单内部滚动，并阻止滚动链传到编辑器。Markdown 主菜单滚动时收起已脱离锚点的二级菜单。

2026-09-22：400×260 浏览器窗口检查主菜单和高亮子菜单，边界均在 [8,392]×[8,252] 内，主菜单可滚动 247 px，无页面异常。
