# 右键菜单边界

`components/useMenuBounds.ts` 统一管理自定义右键菜单和二级菜单的实际尺寸、窗口边界和内部滚动。Markdown、文件树、多维表格、甘特图、收藏文件夹共用它，不再各写一个猜测菜单高度的常量。

标题栏新建菜单单独采用已有 Radix DropdownMenu，复用其键盘导航、碰撞避让和子菜单焦点管理；主菜单和子菜单均按可用高度滚动，边界保留 8px。仅打开期间订阅标题栏关闭事件并计入活动菜单，关闭或卸载时解除。不要将这套菜单再次包进自定义尺寸观察器。

`NewDocumentMenu` 的触发按钮跟随标签尾部，但不放在标签滚动遮罩中。Tooltip 禁用时保留相同 Radix Trigger 结构，避免菜单刚打开就因触发节点重建而丢失焦点。顶部提示优先向下，空间不足再翻转，窗口四边保留 8px。

标签页的自定义右键菜单也复用 `useMenuBounds`，但通过 portal 挂到 body，不能留在带 CSS mask 的标签滚动视口内。文字提示同样使用独立浮层。

菜单四边至少保留 8 px；最大高度取 460 px 与窗口剩余高度的较小值。菜单内容变化或窗口调整时重新测量，菜单滚动不测量。`ResizeObserver` 仅在菜单打开时存活，关闭时注销。内容不可因 flex 收缩而塞进固定高度；长菜单内部滚动，并阻止滚动链传到编辑器。

## 正文右键

`EditorContextMenu` 仅提供剪切、复制、粘贴、仅粘贴文本与全选；空选区不显示剪切/复制。排版操作由选区浮动工具栏、顶部工具栏和块菜单提供，不另建色板、标题/插入子菜单或格式命令分支。菜单复用主题色与块菜单的尺寸语言，通过 body portal 避免正文滚动容器裁切；打开时暂时隐藏选区工具栏。

菜单先同步恢复编辑器 DOM 选区，再触发原生 copy/cut 事件，仍由文档/表格剪贴板插件处理格式、说明实体和撤销。粘贴沿用 `systemClipboard.ts` 的异步目标租约。公式、代码等嵌入输入框保留自己的编辑菜单。方向键、Home/End 导航；Esc 返回正文；外部点击、外部滚动、窗口失焦或切换编辑器会关闭菜单。监听与尺寸观察仅在菜单打开期间存在。

## 编号菜单

`numbering/NumberingControl` 供顶部工具栏、单块侧边菜单和跨行选区菜单共用。主按钮直接切换有序列表，独立箭头悬停或点击展开「继续编号」「从 [1] 重新编号」「编号样式」三行；顶部按钮溢出后，插入菜单仍提供完整操作。侧边菜单只在当前起始值未接续上方列表时额外显示快捷「继续编号」。

跨行菜单的主动作显示结果：无序、正文或混合选区显示「改为有序列表」；所选条目全部为有序列表时显示「取消有序列表」，通过还原正文处理跨列表片段。可操作的文字入口沿用菜单正文色与字号，活跃编号使用选中色，不用浅色暗示禁用。

上下文仅在打开编号菜单时读取；侧边菜单用目标位置读取，不能因显示菜单而更改选区。非空文本选区与目标相交时保留原方向和范围，隐式单行使用 NodeSelection；跨行菜单保留其打开时的选区快照。命令层决定样式的连续编号组范围，UI 不自行扫描或重写列表。

起始值输入使用原生数字框，每次打开显示 1，打开和聚焦均不修改正文。首个合法输入创建草稿并实时预览，输入期间保持焦点；Enter、外部关闭、保存快捷键与卸载提交，Esc 恢复。一个输入会话由命令层归并为一次撤销。样式子菜单按固定顺序展示 3×3 九种标记；继续编号悬停 500ms 后以相邻条目的实际文字预览结果，不滚动正文。

所有编号菜单继承 `useHoverMenu` 的父子分支与 `EditorMenuScope` 的 portal 宿主，使用统一编辑器菜单层级；编号预览只存在于顶部及侧边入口。
