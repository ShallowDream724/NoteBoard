# 自定义快捷键

## 单一命令目录

`core/shortcutCatalog.json` 是命令 ID、名称、分组、作用区域与默认组合的共同来源。TypeScript 和 Rust 直接读取同一份 JSON。文件操作、Markdown、源码/代码编辑、搜索、文件树及图表历史都通过命令身份解析；不把按键本身当作命令身份。

`shortcutBindings` 负责规范化、默认值与覆盖值合成、作用区域冲突以及实时订阅。每个命令最多四个组合；空数组表示禁用，移除覆盖值表示恢复默认。普通字符、光标移动、Enter/Tab/Escape 与系统剪贴板等输入约定不列为可重绑定命令。浏览器/系统保留组合不允许录入。

## 分派

应用注册表适配旧调用点的默认组合并解析为命令 ID；TipTap 与 CodeMirror 各有上下文适配器。CodeMirror 用高优先级 DOM handler 分派到现有 keymap 的 scope handler，避免重新发送 DOM 键盘事件引起递归和重复触发。TipTap 使用原有编辑器命令执行格式操作。已被命令接管的键即使命令在边界处无操作也会被消费；被重绑定的旧默认键不再穿透到上游编辑器。

组合以物理按键识别，输入法组合期间不执行编辑命令。设置录制时暂停应用快捷键，防止录入 Ctrl+W 之类组合时关闭文档。提示组件通过命令绑定订阅显示当前组合。

`markdown.heading0` 的 Ctrl+0 负责解除文字结构，`markdown.clearStyles` 的 Ctrl+\\ 负责清除样式；两个命令独立重绑定，不以双击按键隐式切换含义。清样式在主文档、Markdown 源码、图注、多维表文本和说明草稿中生效。嵌入编辑器通过轻量 `textStyleShortcuts` 分派到已有事务，保留自己的历史所有权；源码通过同一命令身份调用增量语法树清理。消费过的事件、组合输入及被停用的旧默认键不穿透到其他编辑器动作。

## 设置交互

每个组合键本身是录入目标：点击即开始接收下一次按键，立即验证键形、系统保留键、同命令重复组合与作用区域冲突。有效组合经系统占用检测后自动保存，行内显示检查、保存成功或失败；不需要展开编辑器和再次点击保存。修改一个组合保留其他别名。添加、移除、单项恢复默认和全部恢复默认继续使用同一份覆盖值协议。

Esc 取消录入，Tab 返回正常焦点导航；录入中的 Esc 不关闭设置。按键被系统截获时可切换手动输入，Enter 确认且同样校验。切换录入目标或离开页面时，过期的异步检测结果不能提交。保存失败保留当前绑定并提供重试。按键测试固定在列表上方，系统检测详情与输入约定使用渐进展开。

## 冲突与原生检测

内部冲突按作用区域判断。应用命令与编辑器命令同场景相交，互斥编辑器的命令可复用组合。设置在保存前重新执行校验，原生持久化也使用共享目录校验最终合并结果。

Windows 探测在短寿命线程中调用 RegisterHotKey，成功后立即 UnregisterHotKey，不长期注册、不安装键盘 hook、不修改其他软件。1409 表示已被注册；其他失败保留 unknown 状态。批次最多 256 个组合、单项最多 64 字符，线程结束进一步释放资源。

“未发现系统注册冲突”只描述检测当时的结果。低级键盘 hook、输入法或之后启动的程序仍可能截获按键，不能保证任何环境下绝对可用。设置提供实际按键接收检查；用户可以修改组合。进入应用、切回窗口和绑定变化时触发检测，焦点检查节流，旧异步结果用代次过滤，重复占用提示在本次会话去重。

## 保存和多窗口

设置通过 `shortcuts.overrides.<commandId>` 叶子补丁更新。并发窗口修改不同命令可合并；单命令 reset 使用 null 删除覆盖。同步后的设置立即发布给运行中的绑定订阅者，不需要重启。Rust 的补丁入口和旧整份保存入口都校验目录、键形及冲突。

## 验证

前端回归验证目录有效性、作用区域冲突、应用绑定/禁用/恢复、TipTap 标题和下划线、CodeMirror 格式/历史、设置录制、系统占用阻止保存以及多窗口叶子合并。原生测试验证目录和补丁规则。检测机制不把其他程序的占用归因到某个未经系统提供的进程名。
