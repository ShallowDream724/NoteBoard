# 富文本剪贴板导入

`VisualKernel` 注册 `ClipboardImport`，在 ProseMirror 默认 HTML 解析前处理 DOM paste。右键菜单通过 `systemClipboard.ts` 读取剪贴板快照，再调用同一导入入口。读取菜单剪贴板、图片文件或等待解析期间，插入位置随事务映射；切换文档、关闭编辑器、删除目标或按 Esc 取消后，不会写入新的目标。

正文右键仅保留剪贴板与全选操作；有选区时同样提供“仅粘贴文本”。剪切/复制先同步恢复编辑器 DOM 选区，再进入既有原生剪贴板插件，不使用纯文本替代富文本片段，也不另写删除事务。

`createClipboardImportPlugin({docKey, ownerCurrent, stripAnnotations})` 是共享的 ProseMirror view 入口。主编辑器通过 TipTap 适配器保留原有注册实例校验；说明草稿通过自己的 view 事务映射书签、父文档身份和正文存在性校验控制有效期。草稿销毁会取消 Worker/资产读取后的插入，图片仍沿用父文档目录的受管理资产流程。说明内的原生片段在 Worker 中去掉递归说明实体与引用，小片段走同步等价路径；PM 原生拖拽的后备清理只遍历不可变节点，不执行 JSON 往返。

## 格式选择与内容

优先级为本应用表格片段 → 本应用文档片段 → 显式 Markdown MIME（`text/markdown`、`text/x-markdown`）→ HTML → 图片文件 → 文本。表格专用 MIME 保留行、列、整表剪切粘贴语义。HTML 与 PNG 同时存在时读取 HTML，不重复插入 PNG，也不会吞掉文字；仅当小片段 HTML 只有不可读取的图片且有可读取位图备选时，改用位图。鼠标当前位于图片槽且剪贴板有可读取图片文件时，明确的图片槽目标优先接收图片，仍保留本应用结构化片段优先级。Ctrl+Shift+V、“仅粘贴文本”以及代码块/行内代码目标绕过富文本、Markdown 与表格推断，按字面保留换行。

NB 与 MD 可视编辑共用 `clipboard/external.ts`，在主线程与 Worker 使用相同的外部格式判断。普通文本先检查明确语法信号，再由 `documentParser()` 的现有 Markdown 语法确认标题、列表、引用、围栏、表格、行内样式和公式等语义；未识别到语义的短文本仍交给 ProseMirror 原生粘贴以保留光标与当前样式。标题遵循 CommonMark，`# 标题` 可以识别，`###333` 不会擅自改写。源码编辑器附带的纯 div/span/pre/code 外壳在正文与纯文本一致时也可识别 Markdown；包含真实标题、列表、链接、表格、Office 段落或明确非 Markdown 代码语言的 HTML 保持 HTML 语义。显式纯文本粘贴不进行识别。Markdown 导入沿用 HTML 的外部链接/图片地址限制，不将不可读取图片静默丢弃。

普通 HTML 的加粗、斜体、下划线、删除线、链接、文字色、高亮、段落对齐、列表、表格和图片转换为已有节点/mark。Windows CF_HTML 传输头被剥离；有 StartFragment/EndFragment 标记时，仅导入选中正文并保留必要的祖先结构和 head 样式，普通浏览器 HTML 不进行裁剪。Office 适配支持简单标签/class 样式、条件注释中的 `mso-list` 编号、中英文嵌套混合列表、Excel 合并单元格、单元格底色/对齐/空格/换行；Excel 的公式、日期、数字格式按剪贴板提供的显示文本导入，不变成电子表格计算模型。粘贴富文本到已有单元格时，使用已规范化的节点，不再用纯文本后备覆盖样式。不运行外来脚本、不挂载外来页面测量样式，不将 CSS 或 HTML 存入文档。未知格式保留可读取正文；普通 IMG 与 VML 图片（含 Office 条件注释）不能读取时，保存带替代文字/来源的普通段落并提示实际导入结果。混合文字/表格内容不会被剪贴板截图替代。图片在正文中的先后顺序保持不变。

纯文本仅在表格上下文或规则明确的多行、等列 TSV 中推断单元格。单行/单列文本在普通正文中保持文本，在已有表格中可以填充对应单元格，尾部空列保留。以制表符缩进的代码和常见代码行不在正文中自动变表格。

本应用结构化片段携带其锚点引用的补充说明正文。文档片段和表格片段都在粘贴时一起重映射引用/正文 ID，并在同一事务中插入锚点与 metadata 区域的说明实体，避免共享可编辑正文或被孤儿清理提前删除。`clipboard/structured.ts` 为 DOM copy/cut 和程序化块复制提供纯数据帮助函数，没有反向依赖编辑器插件。

## 调度、取消与历史

MD 源码模式使用 CodeMirror 的文字粘贴，保留 Markdown 原文；切回可视模式先提交源码快照，再通过同一文档解析器渲染。源码粘贴不采用 HTML 备选格式，也不自动添加 Markdown 转义。NB 原生 JSON 源码不增加 Markdown 自动识别。

24,000 字符以内的片段走同步快路径。更大的 HTML 由独立 Worker 使用现有 `linkedom` 解析和规范化；较大的结构化文档/表格片段、Markdown、TSV 推断及纯文本同样在 Worker 转换，包含表格单元格内的粘贴。主线程按约 8ms 时间片自底向上构造 schema 节点，因此一个大表格内部也能让出事件循环。等待时只插入事务映射的状态装饰，不改变正文；最终插入为一次独立可撤销操作。

边界为每次 16,000,000 字符、250,000 个遍历节点、48 层嵌套、100,000 个表格单元格、2,048 条简单样式规则。10,000 行、4 列的常规 Excel 表格在这些边界内。超限明确提示分段粘贴，不截断正文，也不把所有体量宣称为毫秒级完成。

`clipboardImportTiming()` 提供响应、Worker 规范化、schema 构造、同步提交和总完成时间，响应时间与完成时间分别记录。最终一次事务的视图创建/布局仍由表格视图负责；Worker 不代表巨量 DOM 已消除。`.tmp/clipboard-measure` 的生产扩展浏览器基准可测同步提交、帧间隔和 Long Task，表格视图优化后需要重跑该基准，不能以只测 Worker 的数据替代。

## 图片

系统外部拖拽先由 `core/editor/fileDropTargets.ts` 向已注册的编辑器分派，窗口启动链路不导入富文本运行时。Tauri 物理坐标按 `devicePixelRatio` 转为 CSS 坐标，使用 `elementFromPoint` 确认真正命中的活动可编辑正文，纯图片拖拽显示局部插入线或槽高亮并插入当前文档。未命中、只读、源码、其他编辑器或混合文件拖拽保留原来的新标签页打开队列；离开、放下及实例销毁清除提示。同一次原生拖拽的 DOM drop 后备事件不会重复插入。

图片粘贴仅在鼠标当前仍位于该正文的图片槽时使用槽位置，九宫格与轮播都采用实际命中的槽；鼠标离开后立即恢复文字光标位置，不保留“最后选中过的槽”。粘贴时重新命中可见 DOM，遮挡浮层与嵌套图注/说明编辑器不会透传目标，纯文本粘贴始终遵循光标。异步读取开始后固定原始目标并随后续事务映射，删除/替换槽时取消，空槽不会因 `TextSelection.near()` 跳到外部而失去落点。

多个图片依次读取/保存，按剪贴板顺序在一次事务中填充命中槽及其后续空槽，容量不足时追加槽；已填充槽与原有图注保留，不覆盖已有图片。普通正文的批量图片同样只占一次撤销。

已有文档沿用受管理的相对图片路径；未保存文档/写文件失败的临时图像沿用现有图片资产流程。已开始的本地写入在取消时不按路径误删文件；如已经写入但未插入，提示保留路径。

## 验证

`clipboardExternal.test.ts` 对 NB/MD 两种格式覆盖外部 Markdown 实际节点与序列化、源码 HTML、普通 HTML、Word 条件列表与 CF_HTML、Excel 合并和显示值、单行/单列 TSV、代码字面内容、内部 MIME 优先级及 VML/位图后备，并比较浏览器与 Worker DOM 解析结果。`clipboardImport.test.ts` 覆盖 HTML+PNG 优先级、Word 中英文列表/class 样式、Excel 合并/空格/换行/底色、脚本/URL过滤、原生说明重映射、表格行语义、空槽批量填充、撤销重做、10,000 行和深度边界。`clipboardImportAsync.test.ts` 覆盖占位、编辑期间位置映射、Esc、跨文档取消、大段 Markdown 与代码目标。`imageDropRouting.test.ts` 覆盖物理/CSS 坐标、原生拖拽认领/打开后备、九宫格/轮播实时悬停粘贴、离开恢复光标及遮挡；`imageInsertionLease.test.ts` 覆盖异步读取时槽移动、删除、多图跳过已有图片和并发填槽。
