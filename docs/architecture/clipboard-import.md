# 富文本剪贴板导入

`VisualKernel` 注册 `ClipboardImport`，在 ProseMirror 默认 HTML 解析前处理 DOM paste。右键菜单通过 `systemClipboard.ts` 读取剪贴板快照，再调用同一导入入口。读取菜单剪贴板、图片文件或等待解析期间，插入位置随事务映射；切换文档、关闭编辑器、删除目标或按 Esc 取消后，不会写入新的目标。

正文右键仅保留剪贴板与全选操作；有选区时同样提供“仅粘贴文本”。剪切/复制先同步恢复编辑器 DOM 选区，再进入既有原生剪贴板插件，不使用纯文本替代富文本片段，也不另写删除事务。

`createClipboardImportPlugin({docKey, ownerCurrent, stripAnnotations})` 是共享的 ProseMirror view 入口。主编辑器通过 TipTap 适配器保留原有注册实例校验；说明草稿通过自己的 view 事务映射书签、父文档身份和正文存在性校验控制有效期。草稿销毁会取消 Worker/资产读取后的插入，图片仍沿用父文档目录的受管理资产流程。说明内的原生片段在 Worker 中去掉递归说明实体与引用，小片段走同步等价路径；PM 原生拖拽的后备清理只遍历不可变节点，不执行 JSON 往返。

## 格式选择与内容

优先级为本应用表格片段 → 本应用文档片段 → HTML → 图片文件 → 文本。表格专用 MIME 保留行、列、整表剪切粘贴语义。HTML 与 PNG 同时存在时读取 HTML，不重复插入 PNG，也不会吞掉文字。Ctrl+Shift+V 和“仅粘贴文本”绕过 HTML、结构化片段与表格推断，按字面保留换行。

普通 HTML 的加粗、斜体、下划线、删除线、链接、文字色、高亮、段落对齐、列表、表格和图片转换为已有节点/mark。Office 适配支持简单标签/class 样式、`mso-list` 列表标记、Excel 合并单元格、单元格底色/对齐/空格/换行；不运行外来脚本、不挂载外来页面测量样式，不将 CSS 或 HTML 存入文档。未知格式保留可读取正文；不能读取的图片地址保存为带替代文字/来源的普通段落，并提示实际导入结果。图片在正文中的先后顺序保持不变。

纯文本仅在表格上下文或规则明确的多行、等列 TSV 中推断单元格。以制表符缩进的代码和常见代码行不在正文中自动变表格。

本应用结构化片段携带其锚点引用的补充说明正文。文档片段和表格片段都在粘贴时一起重映射引用/正文 ID，并在同一事务中插入锚点与 metadata 区域的说明实体，避免共享可编辑正文或被孤儿清理提前删除。`clipboard/structured.ts` 为 DOM copy/cut 和程序化块复制提供纯数据帮助函数，没有反向依赖编辑器插件。

## 调度、取消与历史

24,000 字符以内的片段走同步快路径。更大的 HTML 由独立 Worker 使用现有 `linkedom` 解析和规范化；较大的结构化文档/表格片段、TSV 推断及纯文本同样在 Worker 转换，包含表格单元格内的粘贴。主线程按约 8ms 时间片自底向上构造 schema 节点，因此一个大表格内部也能让出事件循环。等待时只插入事务映射的状态装饰，不改变正文；最终插入为一次独立可撤销操作。

边界为每次 16,000,000 字符、250,000 个遍历节点、48 层嵌套、100,000 个表格单元格、2,048 条简单样式规则。10,000 行、4 列的常规 Excel 表格在这些边界内。超限明确提示分段粘贴，不截断正文，也不把所有体量宣称为毫秒级完成。

`clipboardImportTiming()` 提供响应、Worker 规范化、schema 构造、同步提交和总完成时间，响应时间与完成时间分别记录。最终一次事务的视图创建/布局仍由表格视图负责；Worker 不代表巨量 DOM 已消除。`.tmp/clipboard-measure` 的生产扩展浏览器基准可测同步提交、帧间隔和 Long Task，表格视图优化后需要重跑该基准，不能以只测 Worker 的数据替代。

## 图片

外部拖拽在正文块边界显示插入线，进入图片槽时只显示槽高亮。异步目标使用原始位置映射，空槽不会因 `TextSelection.near()` 跳到外部而失去落点。多个图片依次读取/保存，按剪贴板顺序在一次事务中填充后续空槽，容量不足时追加槽；原有图注保留。普通正文的批量图片同样只占一次撤销。

已有文档沿用受管理的相对图片路径；未保存文档/写文件失败的临时图像沿用现有图片资产流程。已开始的本地写入在取消时不按路径误删文件；如已经写入但未插入，提示保留路径。

## 验证

`clipboardImport.test.ts` 覆盖 HTML+PNG 优先级、Word 中英文列表/class 样式、Excel 合并/空格/换行/底色、脚本/URL过滤、原生说明重映射、表格行语义、空槽批量填充、撤销重做、10,000 行和深度边界。`clipboardImportAsync.test.ts` 覆盖占位、编辑期间位置映射、Esc、跨文档取消；已有图片插入与表格剪贴板测试继续运行。
