# 推荐字体的安装与选择

应用字体包注册的真实字体族为 `JetBrains Mono` 和 `Maple Mono Normal NF CN`。资源仅写入 NoteBoard 数据目录并注册到各窗口的 `FontFaceSet`，不会安装到 Windows。推荐组合用于代码、纯文本与代码块，正文、文件树和界面字体保持各自配置。

`fontPackStore` 在校验通过后注册字体；下载或导入入口明确表示“并使用”，完成后通过 `apply_recommended_fonts` 同步代码中西字体与设置。设置广播和本地确认均经 `SettingsReplica` 应用到 CSS 变量，因此设置显示与实际编辑区使用同一份状态。下载失败不修改字体选择。

`monoFontFamilySource` 与 `monoFontFamilyZhSource` 分别记录 `automatic`（跟随推荐默认）、`user`（明确选择）或 `legacy`（旧版来源未知）。手动选择字体包括选回系统默认都会记录 `user`；调整字号、行高等不改变来源。全部恢复默认会恢复两个 `automatic` 槽。

启动或升级后的已安装资源检查只更新 `automatic` 槽。旧版没有保存选择来源，不能凭当前字体名称判断用户是否曾主动选择；已存在但缺少来源的字体值按 `legacy` 保留。只有旧文件根本没有相应字体字段时才可认定该槽未保存过选择，迁移为 `automatic`。因此历史系统默认与用户主动选过同名字体的情形无法被可靠区分，须保守保留。

明确点击“下载并使用”“导入并使用”或“使用推荐字体”可把原选择切回推荐。安装开始时捕获各槽字体和来源，完成时由 Rust 在设置互斥锁内与最新持久快照比较；安装期间在本窗口或其他窗口作出的较新字体选择优先保留。自动应用同样在原生事务中判断来源，避免前端读取后再写入覆盖其他窗口的选择。没有实际改变时不重复写盘或增加 revision。

字体包已安装时，设置页显示简洁的安装和使用状态。下载体积、导入与删除收在“管理”里；已安装但未使用推荐组合时提供“使用推荐字体”。重新下载或导入成功后恢复折叠状态。

验证覆盖：Rust 迁移与条件事务测试；`fontPackInstall.test.ts` 验证安装到设置与渲染的链路、下载中用户选择和启动保留规则；`fontPackSettingsCard.test.tsx` 验证已安装状态默认收起管理控件。
