# 首次体验与功能示例

全新配置的空窗口在打开请求队列和会话恢复完成后，自动打开一份可编辑的“欢迎使用 NoteBoard.nb”。显式打开文件、窗口交接、已恢复标签或已有设置的用户保留原来的工作上下文。主页的“浏览功能示例”始终可以手动打开新的未保存副本。

`firstRun.ts` 集中判断启动条件：没有 `noteboard.introduction-seen`、空窗口启动、设置 revision 为 0，并且没有标签。示例图片准备完成后，`openShowcase(true)` 再次检查标签；期间到达的用户文件优先。动作返回实际创建的标签 key，只有成功创建后才记录已展示。图片读取或写入失败保留重试资格，不创建缺少图片的标签。

首次体验直接进入可编辑的功能示例文档，不额外显示文字步骤浮窗。功能示例与主页的手动打开入口保留。

`src/features/welcome/showcase.nb` 与 `examples/rich-document.nb` 保持逐字节一致。示例用段落 `blockBackground` 叠加局部文字高亮，保留独立文字颜色及高亮 marks；行间公式展示居左与居右排版，并用平滑过渡分段函数展示多行公式与积分。带列宽的居中与居右表格、文字与代码块的说明锚点继续保留。新能力优先替换已有说明，保持示例篇幅精简。回归测试覆盖首次打开、失败重试、上下文保护、原生格式往返、示例结构与公式渲染。更新只影响之后打开的示例副本，不修改已保存文件或恢复中的文档。
