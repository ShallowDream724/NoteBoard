# 提示块与文档图片

## 提示块

提示块的持久表示是标准引用块加 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]` 或 `[!CAUTION]`。正文是普通块节点，支持多段文字、列表、公式和嵌套引用；未识别该扩展的 Markdown 阅读器仍能显示引用正文。

`alertExtension.tsx` 负责解析、序列化及编辑器适配，正文必须由 `NodeViewContent` 承载。`alertPresentation.ts` 只保存类型、标题、SVG 路径与颜色，不能存储文档状态。标题按钮按需显示类型选择器；不用 Emoji。

## 路径和文件目录

文件选择增加可粘贴路径的入口，`normalizeFileInput` 处理 Windows 斜杠、引号及 file URI；保留系统浏览多文件功能。仅在路径入口规范化，不改写 Markdown 正文或网络链接。

目录中的文件单击或 Enter 即打开。图片成功写入或恢复后，通过 `refreshExplorerAfterWrite` 刷新相关目录，连续写入会在在途读取后补一次刷新。根目录变更后丢弃旧请求结果；刷新失败不重复保存或插入图片。

## 删除图片

- 编辑器适配层只收集语义图片节点的增删，程序化加载及模式同步不触发清理。
- `imageAssetLifecycle.ts` 串行处理决定，支持询问、保留文件、同步删除三种偏好。界面和 NodeView 不直接操作磁盘。
- 只自动清理已保存文档的专用图片目录。保存成功并确认当前会话仍有效后，才调用 Rust 文件操作。
- 检查其他打开文档及当前目录树的 Markdown/HTML 引用；遇到可能引用或无法完成检查时保留文件。目录外文档不在自动扫描范围内。
- 文件移入系统回收站；撤销恢复正文引用时，通过不透明恢复凭据恢复图片。恢复不覆盖原位置已有文件。
- Rust 将阻塞扫描及回收站操作放在线程池；操作串行。引用扫描最多 4096 份文档或 64 MiB，超限保留文件。
- 恢复凭据只属于本次运行，最多 1024 条，达到上限保留文件。应用重启后的恢复使用系统回收站。引用扫描与外部程序写入不是跨进程原子事务。

当前自动清理入口是可视化编辑中的图片节点变化；源码中任意文本删除不自动推断为删除磁盘图片。设置中可修改已记住的偏好。

验证覆盖解析/保存、同步事务排除、目录刷新竞态、保存失败与会话换代、共享引用，以及 Windows 临时测试文件的实际回收和字节完整恢复。
