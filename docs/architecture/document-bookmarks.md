# 文档书签

Markdown 与 NB 可视编辑共用右侧“大纲 / 书签”导航。列表沿文档顺序显示，失效项放末尾。文字选区保存精确范围（`kind: range`、位置与长度）；无选区时保存最近的文字段落，块菜单显式节点边界保存整个内容块。列表项、表格单元格段落、公式、代码、图片与折叠块均有独立落点。空段落、空白选区、隐藏元数据不创建书签；同类型且边界完全相同才视为重复，重叠但不同的范围可独立存在。添加操作幂等，已有书签给出反馈；块菜单的显式移除操作仍可切换。

正文用轮廓书签图标标记，五种颜色由列表图标菜单选择，颜色只属于本机分类。列表右键支持跳转、删除与临时批量删除；批量模式才显示逐项删除按钮，点空白或 Escape 退出。编辑器右键菜单也提供“添加书签”。列表预览保留粗体、斜体、行内代码与 LaTeX，去掉正文颜色、底色、位置与字号。预览最多 160 字、48 片段、256 遍历步；公式最多 512 字源码，超过时显示截断文本，进入可视区才由共享渲染队列加载。所有预览共用一个可回收 IntersectionObserver。

导航标签支持左右方向键、Home/End；书签可用键盘跳转、Delete 移除、Shift+F10 打开菜单。跳转只滚动所属文档：精确范围使用起始文字行的真实坐标，整块使用开头阅读行，居中并钳制首尾边界，不改变公式、代码或表格的内层滚动位置。只放置折叠光标，不框选整段或媒体；目标范围用橘色荧光底色约一秒渐隐，减少动态效果时用静态短暂提示。反馈由可销毁定时器与临时 decoration 管理，不写文档或历史。

浮动与侧栏模式共用左边缘宽度手柄及 `outlineWidth` 偏好。`core/dom/edgePanelResize` 将拖动预览合并到动画帧，只修改面板 CSS 变量；松手提交一次偏好，Escape、失焦、模式切换或卸载取消本次拖动并释放捕获与监听。键盘左右调整宽度，Shift 加大步长，Home/End 到达边界。侧栏不超过可用空间的 45%；窗口缩小时临时钳制，放大后恢复原偏好。标题切页位置不变，正文树使用较紧凑的缩进与右边距。

`features/bookmarks/model.ts` 管理轻量块与范围锚点，`rangeAnchors.ts` 管理范围预览与重开恢复，`extension.ts` 持有每编辑器插件状态，`commands.ts` 是各入口的唯一操作接口。普通事务只映射最多 100 个锚点；未变节点复用旧记录，文本预览最多读取 160 个字符。无滚动监听、逐块观察器、DOM 索引或长驻文档副本。明确块移动使用已有 `BLOCK_MOVE_META` 映射；源码同步/历史根替换按实际差异区间映射。删除留下失效条目以支持撤销：普通删除不会附着到后面同文的段落，只有历史事务实际重新插入目标边界且类型与预览匹配时才能恢复，撤销别处的输入不复活书签。重新加载、外部替换或无法保留边界的历史操作按类型与预览建立一次临时索引，重复候选仅在有限前后文唯一匹配时恢复，否则显示“内容已失效”；用户可以移除失效条目或重新添加。

`storage.ts` 按精确 docKey 使用独立的 `noteboard.document-bookmarks.v2:<编码身份>` 本机元数据键。不同窗口写不同文档互不覆盖，不使用共享读改写索引作为数据源；旧 v1 合并元数据在首次读取时迁移，已有 v2 项优先，复制失败保留旧数据。它不写 Markdown/NB 正文、不触发脏态，不要求 Markdown 转换为 NB；将文件发给他人不会附带书签。插件合并 500 ms 内的元数据写入，关闭时同步刷新；另存为、暂存身份转正与文件/目录重命名在统一 `commitDocumentIdentity` 边界先保存新身份、再移除旧身份，并阻止旧编辑器销毁后重新写回旧身份。迁移失败保留原持久副本。跨文件复制保留原文档身份隔离。

源码模式以 CodeMirror 正文为权威。保存、关闭、身份迁移和窗口转移的显式屏障从最新源码映射书签，保留的隐藏可视编辑器不改变正文；关闭或已提交转移先刷新、再释放旧持久化所有者，避免旧视图销毁覆盖目标窗口。源码优先的会话只有已有书签且源码变化时才按需载入共享语法，在屏障解析基线与当前正文各一次；异步期间的输入、会话或身份变化使捕获失效。失败保存的重复屏障复用最多 100 条基线锚点种子，防止再次把新锚点当作旧基线；不保存全文或文档模型，标签关闭、切换模式或身份改变即释放。“不保存并关闭”单独将当前锚点映回已有磁盘基线，不改变实时正文；简单文字编辑可恢复原书签，无法可靠映回的新增、删除或重复目标保持失效，避免误跳。正常关闭不回滚已保存的锚点。

每篇文档最多 100 个书签，到达上限时添加动作说明原因。200 篇文档、1000 个书签的上限仅约束不活跃内存缓存；清理内存不会删除任何持久书签，也不在每次保存时扫描全部 localStorage。当前打开的文档（包含没有可视编辑器的源码标签）和未写成功的记录受保护。已删除目标仍算入本篇上限，便于用户决定保留供撤销恢复还是移除。无可用 localStorage 或实际配额耗尽时保留本次会话状态，并在书签面板显示保存失败信息；迁移失败保留源身份的内存记录与持久副本以便重试；目的身份恢复写入后仅清理当时的原内存副本，同路径重新打开产生的新记录不受旧迁移影响。源窗口未能持久化书签时移窗会保留源文档，普通正文保存不因辅助元数据错误而失败；后续屏障可重试元数据写入，包含移除最后一个书签后的空记录。
