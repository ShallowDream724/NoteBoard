# 侧栏控制

左侧文件目录由标题栏最左侧的 SVG 按钮控制；该位置不再显示 Logo 或打开设置。设置沿用标题栏右侧的齿轮按钮。

右侧大纲适用于 Markdown 与 NB 富文本文档，独立覆盖在正文右侧。展开时，靠左的收起按钮与“大纲”标签组成紧凑头部；收起后在右侧同一高度显示小入口。操作栏显隐不改变大纲入口；不在标题栏重复放置开关。左右正文边缘的折叠把手及其全局鼠标移动监听已移除。大纲表面与布局约束见 [编辑交互](editor-interactions.md)。

资源管理器标题根据动作按钮与文字的实际宽度依次显示“资源管理器”“文件”或隐藏标题。标题不换行；隐藏后动作按钮从左侧排列。

文件与目录的展示统一使用 `components/FileIcon.tsx`；格式新建项通过模块级 `createFileTypeIcon` 复用同一分类与素材。采用 Pierre 文件图标和 NB 专属补充图标，浅色与深色分别使用对应配色；未知格式使用中性折角文档。素材离线打包，不依赖字体。完整消费者、映射优先级与资源更新方式见 [文件图标](../file-icons.md)。

文件树的展开符号采用 `DisclosureTriangle` 的细描边 chevron 变体，其它内容折叠符号继续使用原默认样式。缩进线属于每个已展开的可见分组：默认仅显示选中项的直接父分组线，选中目录时同样显示上一级线；关联 Markdown 子项使用其显示父项 NB 的线，不按磁盘路径另算。没有可见父分组时不生成隐含根线。鼠标进入文件列表或行获得键盘可见焦点时显示所有分组线，离开后恢复默认。每组一个 CSS 伪元素，沿分组自然高度延伸并与父项展开符号对齐，不为每行生成祖先线段、不测量 DOM、不增加悬停状态或鼠标监听。减少动态效果时关闭过渡；原地址 Tooltip 的延时、内容与位置保持不变。

| 操作 | 快捷键 |
| --- | --- |
| 加粗 | Ctrl+B（由文本编辑器处理） |
| 展开/收起左侧栏 | Ctrl+Shift+B |
| 展开/收起大纲 | Ctrl+Alt+B（当前文档为 Markdown 或 NB 时生效） |

Markdown 引用块不再占用 Ctrl+Shift+B；仍可输入 `> ` 或使用插入菜单。

## 职责与约束

- `layoutStore` 是面板可见性和宽度的唯一状态来源，继续使用现有窗口布局持久化协议。
- `SidebarToggle` 是无状态的展示组件；`TitleBar` 将布局状态与操作传入。
- 应用级快捷键由 `AppShell` 注册及注销，命中侧栏快捷键后停止向编辑器传播，不能同时改动正文。
- 鼠标切换侧栏不主动夺取编辑器焦点。按钮有键盘焦点样式、展开状态及快捷键提示。
- 面板显隐不更换编辑器实例，不创建正文历史记录；窗口拖动仍由标题栏空白区域负责。
- 原有 `RailToggle` 已删除。不要为顶部开关新增独立的持久化状态、全局鼠标监听或另一套快捷键分发。

## 窄窗口操作栏

`ResponsiveToolbar` 只负责测量和布局，`toolbarLayout.ts` 是纯布局策略；Markdown 和代码操作栏保留各自的命令分发。依据编辑区实际可用宽度和按钮实际尺寸调整，不能用整个窗口宽度或固定的 1475 px 阈值判断。

先压缩标签（正文变为 H，标题保留 H1–H6；插入等按钮保留图标）。随后按优先级隐藏：无序列表、有序列表、链接、高亮、行内代码、清除格式、图片、待办、删除线、下划线、斜体、重做、撤销、加粗、标题、插入。隐藏功能仍可通过输入语法、快捷键、选区菜单或原有插入菜单使用；不增加“更多”菜单或横向滚动。

操作栏收起按钮位于不收缩的独立区域，大纲使用自身的浮动入口。ResizeObserver 合并到动画帧内测量；尺寸没有变化时不重复更新状态。宽度变化时关闭旧下拉菜单，避免菜单失去锚点。隐藏节点不参与键盘导航。

选区菜单默认位于选区右下方，可在“设置 → 编辑器 → 选区工具栏位置”切换上下位置；碰到边界时自动避让。只响应正文的非空文本选择，公式源码输入时不显示。菜单在 EditorContent 挂载后确定滚动容器，挂载到 document.body；菜单可换行，色板沿用同一碰撞边界。

## 滚动条

`styles/scrollbar.css` 是唯一原生滚动条样式来源。轨道透明；中央滚动条保持可见并保留上下三角。左右侧栏继承各自容器的滚动条颜色：鼠标进入整个面板显示，离开后 220 ms 淡出；不改变滚动条几何尺寸，不新增滚动监听或自制拖动逻辑。系统减少动态效果时关闭过渡。
