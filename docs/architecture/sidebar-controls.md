# 侧栏控制

左侧文件目录由标题栏最左侧的 SVG 按钮控制；该位置不再显示 Logo 或打开设置。设置沿用标题栏右侧的齿轮按钮。

右侧大纲开关仅在 Markdown 文档中显示。操作栏展开时，放在“收起操作栏”按钮左边；操作栏收起时，位于编辑区右上角。顶部原有的操作栏恢复入口仍可用。左右正文边缘的折叠把手及其全局鼠标移动监听已移除。

| 操作 | 快捷键 |
| --- | --- |
| 加粗 | Ctrl+B（由文本编辑器处理） |
| 展开/收起左侧栏 | Ctrl+Shift+B |
| 展开/收起右侧栏 | Ctrl+Alt+B（当前文档为 Markdown 时生效） |

Markdown 引用块不再占用 Ctrl+Shift+B；仍可输入 `> ` 或使用插入菜单。

## 职责与约束

- `layoutStore` 是面板可见性和宽度的唯一状态来源，继续使用现有窗口布局持久化协议。
- `SidebarToggle` 是无状态的展示组件；`TitleBar` 和 `EditorToolbar` 将布局状态与操作传入。
- 应用级快捷键由 `AppShell` 注册及注销，命中侧栏快捷键后停止向编辑器传播，不能同时改动正文。
- 鼠标切换侧栏不主动夺取编辑器焦点。按钮有键盘焦点样式、展开状态及快捷键提示。
- 面板显隐不更换编辑器实例，不创建正文历史记录；窗口拖动仍由标题栏空白区域负责。
- 原有 `RailToggle` 已删除。不要为顶部开关新增独立的持久化状态、全局鼠标监听或另一套快捷键分发。
