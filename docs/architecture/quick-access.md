# 快速打开与命令面板

标题栏放大镜和 Ctrl+Alt+P 打开文件列表，Ctrl+Shift+P 打开命令列表。面板内的按钮与快捷键都可切换模式，在文件查询框输入 `>` 也可进入命令模式。方向键选中项目，Enter 使用当前项目，Esc 或点击面板外部返回原焦点。执行命令时先关闭面板并恢复焦点，再交给现有动作处理文档选区、后续对话框和编辑焦点。

文件视图先显示本窗口的已打开标签和全局最近打开文件。只在显式打开工作区且输入非空查询后读取工作区路径。原生工作线程按层遍历，最多读取 8,000 个目录项、256 个目录和 24 层的嵌套目录，跳过 `.git`、符号链接和 Windows 重解析点，并遵循文件树的隐藏文件设置。达到限制时显示提示。目录索引在面板本次打开期间复用，工作区或隐藏文件设置变动后重新读取；过期结果作废。搜索仅使用文件名与路径，窗口中的已打开标签优先于同路径的最近文件和工作区文件。选中文件沿用现有文件打开与标签激活路径。

命令视图使用共享快捷键目录和已注册的应用命令，复用新建菜单条目。设置、收藏夹和暂存区等无默认快捷键的操作调用现有入口。正文内 `/` 菜单继续提供内容插入动作。

当前 Markdown 或 NB 文档处于可视化模式时，点击“导航”或在文件查询框输入 `@` 可按名称查找标题及有效书签。导航模式与大纲共享同一编辑器的增量标题索引，读取现有书签状态，并沿用大纲和书签的跳转逻辑与阅读位置记录。首次订阅建立标题索引，后续只处理编辑器事务，输入查询词只筛选已有条目。

在代码编辑器中，`@` 可查找 JavaScript、TypeScript、Python、C、C++ 和 MATLAB 的函数、类等声明，JSON 和 YAML 的键，TOML 和 INI 的节，以及 HTML 和 XML 的元素 ID。每个结果显示所在行。跳转后再次进入 `@` 并选择“返回跳转前的位置”，可恢复原来的选区和滚动位置。当前编辑器实例保存最近 20 个跳转位置，文档内容编辑时会映射这些位置。

代码导航进入面板时读取 CodeMirror 当前文档，包含尚未同步的修改。它按文档快照与语言复用索引，优先使用已解析的语法树，MATLAB、TOML 和 INI 从完整行中提取常见声明。最多索引开头 120,000 个 UTF-16 代码单元和 1,000 个符号，达到上限时在面板中提示。执行跳转前校验编辑器实例、语言和文档快照。
