# 图片编辑器

## 交互与会话

`index.ts` 只挂载一个 Radix 弹窗运行时，提供 `openImageEditor`、`suspendImageEditor` 和 `discardImageEditor`。`ImageEditDialog` 管理会话、历史和保存状态；`canvasInteraction.ts` 统一处理选择、绘制、移动、缩放、文字与裁剪的临时状态；`ImageCanvasStage` 订阅按帧合并的变更，负责坐标映射、画布和 DOM 编辑覆盖层。`ImageToolProperties` 管理工具参数，`toolDefaults` 将界面参数转换成语义操作。画布和全部图像处理代码只在点击编辑入口后加载，不增加第三方绘图依赖。

一次拖动或连续滚轮缩放提交一个历史节点，参数滑块从按下至释放也是一次提交。绘制中的点列仅在当前手势里原地追加，结束后复制为不可变快照，避免长笔迹逐点复制整个数组。画布预览刷新合并到一帧，不逐点刷新整套弹窗。

文字、序号、箭头、几何图形、矩形马赛克、聚光灯与放大镜可直接命中和拖动，不必先切选择工具。绘制后自动选中；文字和序号的八点缩放保持比例，区域形状允许调整宽高。`selectionHandles.ts` 根据标注类型提供控制点：箭头只显示起点、终点和整体移动中点；折线只显示首尾及每个转折点，不绘制矩形选框，也不以路径包围盒的空白区命中。拖动节点只修改该节点，保留线宽、箭头样式和其他节点。

Alt 按住绕过对象命中，允许重叠绘制。铅笔、荧光笔、笔刷马赛克与擦除路径固定在画布上。滚轮及触控板缩放当前选中对象；没有选中对象时 Ctrl/捏合缩放预览，普通滚动保留画布滚动。触屏双指使用两触点的距离比，同样只提交一次缩放。

文字工具点击图片后直接在图上输入；再次点击已有文字可重编，拖动可移动。原位 textarea 与右侧文字/样式参数同步；点击画外结束编辑。编辑覆盖层不进入导出。Delete/Backspace 删除所选标注，输入框内按键仍编辑文字。

折线单独保存已确认节点和鼠标预览尾端，右键、Esc、画外点击、双击或 Enter 均只提交已确认节点；少于两个节点不生成折线。进入裁剪时显示完整源图及当前裁剪边框，拖动八个控制点或内部调整，Enter/应用提交，Esc/取消恢复。固定比例、旋转和镜像共用输出与源坐标变换，恢复画幅不删除标注。

关闭已修改的图片可保存、稍后继续或放弃。暂停先收拢当前手势并保留语义历史，再释放预览与导出任务。再次打开同一目标时恢复；保存对话框取消和写入失败均保留草稿。保存回调接收 AbortSignal，文档写入完成前取消不会替换正文引用；已开始的原生文件原子写入期间禁用关闭，避免把不可撤回的写盘描述为已取消。

界面提供独立的导出格式、质量和尺寸选项，默认 PNG/100%，尺寸限制在原分辨率的 1–100%，不提供上采样或超分选项。大图容量确认显示在当前弹窗内部；字体/颜色等参数只影响选中的标注或后续操作。属性栏提供常用颜色、原生自定义颜色、滑块与数值输入、形状和线型预览。窗口缩小时工具与属性栏保留滚动，画布按可用区域缩放，可放大和滚动查看细节。

参数按实际作用展示：序号首先显示整体大小，实心序号隐藏无效的描边选项，所有序号隐藏渲染器不支持的线型。空心/双圈的常用边框滑块为 1–8 px，箭头/形状/放大镜边框为 1–16 px，铅笔为 1–24 px；荧光笔、笔刷马赛克与擦除保留较大范围。数值输入可显式超出常用滑块范围，满足高分辨率图片需求，滑块最大值不再统一设为 100。

笔迹擦除与对象擦除均显示对应源像素直径的圆形光标，随画布缩放。`ImageEraseCursor` 独立更新轻量覆盖层，移动光标不触发底图重绘。对象擦除高亮圈内会删除的标注；`eraseGeometry.ts` 共用 hover 与连续路径扫掠判定，快速划过细线不会漏删，整个拖动一次撤销。不可变操作的几何边界用 WeakMap 缓存，先排除远处对象；圆形使用解析判定，椭圆点查询避免重复进行整条路径求距。擦除模式优先于标注移动，防止擦除时误拖对象。

## 语义模型与坐标

`src/features/image-editor/model.ts` 定义版本为 1 的 `ImageEditRecipe`。原图尺寸、裁剪区域、旋转/翻转及语义操作各自独立。所有操作的位置、尺寸、线宽和马赛克块大小采用原图像素坐标；先裁剪，再顺时针旋转 0/90/180/270 度，最后沿输出的水平/垂直轴镜像。`geometry.ts` 提供双向坐标映射、输出尺寸、选中命中、移动和裁剪约束。

`features/image/sharedTransform.ts` 为独立图片标签页和编辑器共用旋转/双轴镜像状态变换，查看器 CSS 遵循相同的输出轴语义。查看变换不写回原图；编辑器将同类操作写入可撤销历史。画布绘制显式依赖当前 recipe，外部按钮修改变换后立即重绘，不依赖下一次画布指针事件。

操作覆盖笔迹、荧光笔、直线/折线、首尾空心或实心箭头、实线/虚线/点划线、矩形、椭圆、文字（粗体/斜体）、矩形/笔刷马赛克、聚光灯、可拖画椭圆的放大镜、序号和笔迹擦除。放大镜的 `rect` 为新记录的权威几何数据，兼容旧 `center/radius` 草稿。序号支持十进制、罗马数字和字母，圆形/方形标记支持空心、实心和双层边框。对象擦除由会话删除命中的操作；笔迹擦除记录路径并在该路径内恢复原图（透明像素也恢复），后续操作仍然可绘制。擦除边缘按覆盖率只混合一次，避免清除和补图两次抗锯齿产生白边。马赛克与放大镜采样原图；它们不重复采样先前矢量标注。

历史节点只存不可变 recipe 引用和下一序号；数组共享未改变的语义操作。一次手势结束提交一步，撤销/重做恢复序号。历史最多保留 80 个过去节点，不存整图位图。新的提交清空重做分支。

## 资源与渲染

`textMetrics.ts` 为输入覆盖层、命中/缩放边框及导出共用字体、文字宽度、行高和基线。浏览器/Worker 使用单个微型测量上下文，结果按不可变文字操作存入 WeakMap，随操作释放；不按历史保留位图或无界字符串缓存。中文、emoji、多行及粗斜体不再按固定字符宽度估算。缺少 Canvas 的测试环境使用确定性的降级测量。

`loadImageResource(src, signal?, { maxDimension? })` 用正常 `fetch` 读取 asset/data/HTTP 来源，保留压缩 Blob，以支持后续导出；读取失败或跨域被拒绝时报告错误，不建立绕过来源权限的代理。默认保留长边最多 2048 像素的预览，可由显示需求选择 1024/2048/4096。`width/height` 始终是方向修正后的原图尺寸，`pixelWidth/pixelHeight` 描述实际解码预览。

浏览器临时图片解码器用于取得方向修正尺寸，生成缩略位图后即移除源引用；它在首次加载期间可能短暂解码整图，因此预览上限不是整个进程内存的硬上限。`getOriginal(signal)` 按需重新解码原图并返回由调用者负责释放的资源。`dispose()` 幂等关闭位图、清空图片/画布源并丢弃压缩 Blob 引用。AbortSignal 覆盖读取、解码和编码边界；浏览器不可中断的位图解码完成后也检查取消并立即回收结果。

`renderImageEdit(context, resource, recipe, options)` 只绘制到调用方画布，不改变画布尺寸、不保存画布引用。所有上下文 save/restore 使用 finally 配对。裁剪和变换使用同一映射同时作用于底图及标注。马赛克按最多 256×256 的采样块处理，临时采样画布在成功和失败路径均归零；不额外创建全尺寸标注层。

## 导出与容量

`exportImageEdit(resourceOrSource, recipe, options)` 默认输出原始裁剪/旋转分辨率的 PNG；`getImageExportSize` 返回实际输出宽高，保存元数据必须使用此值。用户可显式选择 JPEG/WebP 质量和缩放尺寸。只指定一边时按输出比例计算另一边；JPEG 的透明区域填白。编码结果为空、格式被浏览器回退、来源污染、解码/画布失败均阻止保存。

`estimateImageExportMemory` 按原图、输出和已保留预览每像素 4 字节估算最低工作像素内存。超过 512 MiB 时抛出带 `estimatedBytes` 的 `LargeImageExportConfirmationError`，界面显示具体预计用量；用户确认后传入 `allowLargeExport: true` 即可继续，不降低分辨率。16,384×16,384 PNG 因此可以在设备能力允许时导出。编码器和操作系统仍会占用额外内存，估算不是进程硬上限。

针对当前 Chromium/WebView2 画布路径，输出单边最多 32767 像素、总计最多 268435456 像素；WebP 格式另有 16383 像素的单边限制。达到容量/格式限制时明确报错，由用户选择其他格式或主动缩小尺寸；不会静默降采样。实际设备可能在更小的尺寸上分配失败，也会保留原图并报告失败。浏览器路径目前不提供原图分块解码或流式 PNG 编码。

支持 Worker 和 OffscreenCanvas 时，`export.worker.ts` 直接接收压缩源 Blob，在独立线程解码、渲染并编码，避免在主线程生成或传输整图像素副本。完成/失败即终止 Worker；取消直接终止任务并释放其解码和画布。缺少此能力时使用主线程后备路径，每批操作和马赛克采样块之间让出事件循环并检查取消。一次浏览器原图绘制或编码仍由浏览器自身实现，不能承诺内部的任一原子操作可中断。

导出为浏览器 Canvas 的常规 8 位渲染结果；PNG 对该结果无损，不保留源文件的 10-bit/HDR、原始色彩配置、EXIF 或其他元数据。导出结束后立即归零输出画布并释放临时原图解码，传入的会话预览继续由会话持有。资产写入及文档引用替换由集成层完成，只有编码和写入全部成功后才可替换引用。

## 文档与文件集成

`integration.ts` 隔离图片编辑界面与文档状态。普通图片、四宫格与轮播共用 `ImageComponent` 的“编辑图片”入口；独立图片标签页和大图预览也提供相同入口。界面模块仅在用户调用时动态加载，Markdown 的原生排版功能开关不限制图片像素编辑。

保存到文档先进入该文档的串行写入队列：已保存文档发布新的内容寻址资产，未命名文档写入持久恢复图片目录。编码读取、排队和写入之后都重新验证文档会话、活动标签、编辑器身份与图片目标；校验通过后以一个离散编辑事务只替换 `src`。对齐、宽度、alt、标题、图注、collection slot 段落及补充说明保持不变，撤销恢复原引用。目标失效或写入失败不改正文；已完成的资产写入不按路径删除，以免破坏其他引用或撤销历史。

独立图片使用系统另存为对话框，默认文件名为 `原名-edited.所选格式`。取消对话框保留编辑进度。用户选定路径后，经 `writeImageEdit` 传输原始二进制并原子保存；必须检查 `WriteResult.ok`。只有用户明确选择原路径时才覆盖原图，并广播图片刷新事件。

## 标签与草稿生命周期

第一次编辑图片时才建立目标记录。每个已编辑的文档编辑器共用一个 transaction 监听器，将目标位置穿过后续事务映射；目标键独立于位置，因此在图片之前输入正文后仍恢复原草稿。删除、替换图片、修改来源或替换整篇文档会作废目标；源图相同的新节点也不会承接旧节点的在途保存。

切换标签、切换源码视图或进入关闭/迁移状态时，同步暂停对话框并释放像素资源，保留轻量 recipe。在途保存捕获活动代次，离开后即失效，切回也不会继续应用迟到结果。后台编辑器被回收时解除 transaction 监听，只保留文档会话、内容版本、位置和来源；相同版本重挂载后重新绑定。回收期间若源码已修改，则作废无法可靠映射的旧目标。文档关闭或会话迁移会删除对应草稿，最后一个目标释放时注销全局生命周期订阅。
