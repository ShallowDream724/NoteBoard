# Markdown 公式

## 输入与保存

- `$…$`、`\(…\)` 是行内公式；`$$…$$`、`\[…\]` 是块公式，默认居中，在 NB 可视化编辑中可设为左、中、右对齐。对齐作为节点展示属性保存；HTML/PDF 导出使用相同对齐。
- 独立段落输入 `$$`、`\[` 或中文输入法的 `￥￥`，按 Enter 建立块公式并聚焦源码输入。工具栏、斜杠菜单和空段菜单插入空公式块时也是如此。
- `￥￥` 仅是编辑快捷方式，生成的节点保存为标准 `$$`。导入 Markdown 不改写人民币符号，单个 `￥` 保持普通文本。
- 单击公式编辑；块内 Enter 换行，Ctrl+Enter 或 Escape 回到正文。行内 Enter 回到正文。
- 正文 Ctrl+A 选择整篇文档，不自动进入被选中的公式；新建空公式块的节点选择或单击公式可进入源码。已经在公式源码内时，Ctrl+A 仍选择该输入框内容。
- 上下方向键从相邻正文的首尾视觉行选中块公式，再按方向键继续移动；行内公式从左右相邻光标位置选中，再按同方向键离开。导航依据文档节点位置，不依赖预览的渲染时机，手打创建与载入的公式共用行为。
- 空公式源码中按 Backspace 或 Delete 删除节点，光标回到可输入正文的位置；输入法组合期间不执行删除。撤销仍通过文档统一历史处理。
- 已确认的源码直接写入 ProseMirror 属性，保存无需等待失焦。输入法预编辑段由原生输入框保留，组合结束后提交实际文本；组合期间不更新文档、调整输入框高度或执行完成/删除/撤销快捷键。
- 源码输入框内的 Ctrl+Z、Ctrl+Y（及 Ctrl+Shift+Z）沿用正文的统一文档历史。公式源码、空公式块创建和相邻正文输入可连续撤销与重做；只改公式属性的历史步骤保留源码输入框、焦点和光标，撤销至空源码时节点仍在。撤销创建步骤移除公式并把焦点交回正文。

## 语法边界

`mathSyntax.ts` 只处理 Markdown 定界符，不替换 TeX 内部的转义、矩阵行距或环境。`\\[2pt]` 中的括号不是块公式开头。代码块、行内代码和转义定界符保持字面内容。

正文输入规则以本次输入和光标为边界：逐字输入在闭合定界符时建立公式，一次文字或输入法提交可同时包含公式、后续普通文字和多个公式；行首、行中、行尾及已有后文前的输入共用该规则。输入法补全先前未闭合的开头也可转换。相邻的 `$a$$b$` 拆为两个行内公式。代码、转义和货币文本仍按语法边界处理，旧字面文本不会因后续普通输入重新解释。NB 原生文件中显式 `text` 节点按源码保真读取，不在打开文件时重写为公式节点。

`$$` 或 `\[` 独立成行时，优先按独立成行的对应结束标记建立完整公式块（允许最多三个前导空格、尾部空白和 CRLF）。块内 TeX 是不透明源码：花括号错误、额外的 `\[` / `\]` 交给公式引擎报错，不能让 Markdown 把矩阵拆成正文和局部公式。未闭合的方括号块遇到下一个独立 `\[` 时停止查找，不借用下一块的结束标记。没有独立围栏对时保留原有紧凑和混合行定界符解析。边界查找为一次前向扫描，不创建行数组、不运行 TeX 引擎；兼容回退最多再运行原有扫描。

此规则不自动修正公式源码中的反斜杠。错误公式往返仍保留原文，用户修复后才恢复渲染；仅靠现存错误源码无法判定是输入问题还是旧版本保存改写。

定界符内部允许空白。美元号和货币之间天然有歧义，采用保守规则处理常见金额、连接词、中文标点和货币单位，避免 `$5，并且$2` 或 `$5USD then $x$` 吞掉正文和后续公式。数学乘积 `$2 kg$`、`$2 ab$` 及显式 TeX 命令保持有效。

任意文本无法只凭美元号完全消除歧义。需要明确的美元字符时写 `\$`；需要明确的数字／货币单位公式时可写 `\(5\,\mathrm{USD}\)`。这不影响普通公式的美元定界符用法。

## 模块职责

1. `mathSyntax.ts`：纯边界识别与序列化。
2. `documentNodes.ts` 定义共享 Markdown/ProseMirror 节点；`katexExtensions.tsx` 只附加输入行为与编辑视图，导出不加载这些交互组件。
3. `MathNodeView.tsx`：焦点与输入；不持有独立的正文草稿副本。`FormulaSourceEditor` 将原生输入法组合与文档提交隔离，组合结束和后续同值 input 只提交一次；外部撤销等值更新在非组合状态同步到输入框。`mathPreview.ts` 独立拥有空预览宿主的 DOM，滚动中不重渲染 React NodeView、不产生文档事务。
4. `mathRendering.ts`：共享 Worker 请求、相同公式去重及缓存；最多 512 项且按 UTF-16 估算不超过 4 MiB，不含引擎对象开销。同优先级短批次最多 16 式、8 Ki 源码字符、约 8 ms，每式结果直接回传，批次边界重排优先级，避免每个公式一次计时器及请求往返。取消立即隔离消费者；已发送工作仍受单式两秒无进展截止约束，未执行尾部返回调度器。`mathEngine.ts` 在 Worker 中按需加载 KaTeX/mhchem。详见 [worker 调度](../performance/math-worker-scheduling.md)。
5. `embeddedEditor.ts`：在公式所在段落前创建临时 ProseMirror widget，通过 React portal 放置源码输入；不插入正文节点。事务只映射活动公式位置，属性更新不会关闭输入。`FormulaSourceEditor` 负责自适应高度和手动纵向调整。行内预览仍保留在原段落。
6. `mathPreviewSession.ts`：每个编辑器拥有一个独立会话。至多 512 式、64 Ki 源码字符的文档主动预排；普通 Atlas 完成后不会因离屏反复拆装。较大文档只预备邻近上下两屏。按约 64 Ki DOM 节点、1024 项的驻留预算逐出较早离开的预览，邻近及正在编辑的内容豁免，因此这是工作集预算而不是整个可视区域的硬节点上限。后台预排按实际节点数停止，不能仅按公式个数放大 DOM。可视化内核显式传入活动/可见状态；隐藏时取消准备工作，保留既有 DOM，恢复时继续。进入/退出公式源码编辑只更新优先级，不重建相同预览。
7. `nearViewport.ts`：每个滚动容器共享邻近和可见观察器，横向浏览不会卸载。超出驻留预算才延迟 180 ms 经共享队列回收；共享 ResizeObserver 在布局后记录宽、高及行内基线，占位同时保留上伸部、下伸部和横向范围。未知几何不回收。回收后清除尺寸观察闭包，避免持有已移除 DOM。首次占位最多显示 100 个源码字符，完整源码始终可编辑。
8. `mathRenderQueue.ts`：三个优先级桶避免逐项选择时全队列扫描；每批挂载按约 1000 个估计节点及 3 ms JavaScript 时间预算，允许多个小公式同帧完成，不再固定为两式。一次复杂 DOM 插入不可抢占；大型或后台挂载在连续滚动时延后，轻量邻近项可提前完成。准备最多 16 项，其中四个槽位保留给前台；前台返回结果的预算独立于被延迟的后台结果，避免后台堵住屏内工作。旧任务结果不能写入新预览。预算与内存边界见[公式渲染预算](../performance/公式渲染预算.md)。

公式位置由文档块的 `textAlign` 决定。`core/math/alignment.css` 在 KaTeX 的两层布局边界继承该值，由编辑区和导出共用；不覆盖分数、矩阵列或编号的内部排版，也不重新请求公式渲染。独立 HTML 的 MathML 使用行内盒参与外层对齐，保留块公式的 displaystyle。

输入识别覆盖顺序输入、输入法提交，以及回头补起始符或在定界符内部输入。只有与本次输入相交的公式会转换，不在载入 NB 或输入无关文字时扫描重写旧文本。右侧最多查看 500 个字符，并在已有公式、图片等原子节点前停止；左侧识别窗口同样限制为 500 个字符。输入规则文本由 TipTap 自身的提取函数取得，避免维护第二份原子节点占位规则。

在已配对的定界符中间继续输入（例如先写 `$|$`）时，转换后沿用源码中的光标位置并保持编辑；行内源码末尾按右方向键或点击外部才离开。`mathEditingRequest.ts` 通过编辑器局部的临时事务状态交接焦点，不在文档属性中保存 UI 状态，也不影响其他编辑器。退出时同步把焦点交还正文，避免下一帧才聚焦导致连续按键丢失。

公式源码编辑占用所在正文块的可用宽度，初始至少三行（块公式四行），自动增长上限约 40vh，可手动拉到 75vh。长公式预览继续扩展整个编辑区的横向滚动空间，不新增公式内部滚动条。纸张适配仅在导出副本执行。

源码变化等待下一次 Worker 结果时，复用 ResizeObserver 已记录的几何占位；连续输入取消尚未完成的预览也继续保留该占位。正在编辑的公式还保留已观测的最小高度，临时括号错误产生的短错误提示也不会把输入框推向页面下方，关闭源码输入后释放。这样带行距的高矩阵不会在每个字符之间短暂缩成一行并触发浏览器滚动边界收缩。旧预览 DOM、观察器和会话记录仍立即释放，只保留轻量尺寸占位；不在每个按键测量布局，也不写入 `scrollTop`。

每个公式的宏定义相互隔离；不启用可信 HTML/URL 命令。错误公式保留源码并给出提示，不用空内容替代。

## 验证方式

`test/fixtures/math/academic-math.json` 是可复用的学术语料；自动检查渲染与读取—保存—重读，同时由 `scripts/generate-academic-fixtures.mjs` 生成人工测试图册。反例也属于语料，不能把“不支持的宏没有崩溃”记成支持成功。

输入规则、货币混排、输入法和空节点删除使用少量行为测试。输入法覆盖缺失 isComposing 标记的确认键、compositionend 前后两种 input 顺序、中文标点同值提交去重和嵌入输入框焦点/DOM 连续性。另保留屏外公式延迟排版回归。不会为每条公式复制一套测试程序。

`node scripts/check-math-alignment.mjs` 在无界面浏览器中测量左、中、右的真实坐标，覆盖编辑区、打印、独立 HTML、虚拟矩阵、撤销和重新读取，并验证提示块样式与标点混排输入。运行环境提供 Playwright；可用 `PLAYWRIGHT_MODULE` 指定模块位置、`BROWSER_CHANNEL` 指定浏览器，默认 Edge。浏览器依赖不进入应用包。
