# 文件格式判定

`.nb` 与 `.nbdoc` 均归类 `noteboard`，使用同一个原生记录 codec 与可视化富文本内核。它们不经过 Markdown 解析，也不提供普通源码模式；损坏记录通过错误块进入恢复视图。自动保存、导出和大纲等共同行为使用 `isRichDocument` 判断；格式契约见 [native-documents.md](native-documents.md)。

统一“浏览”入口由 `welcome/PathBrowser` 管理文件与目录选择；`fsio/browse` 提供常用位置及磁盘列表，`read_dir` 在后台线程读取直接子项。前端以请求代次丢弃过期响应，按可见区域虚拟化列表；筛选只遍历当前目录，不递归读取子目录。目录结果仍需完整读取并排序后返回，虚拟化降低 DOM 成本，不等同于流式目录读取。确认后路径交给现有 `openDocument`，由同一入口决定打开文件还是加入文件夹。

`core/fileFormats.json` 是前后端共用的文件能力清单，替代原来的三个类型/语言 JSON。每个条目声明 kind、language、extensions/filenames/prefixes 和可选 preview/delimiter。TypeScript 的 `fileFormats.ts` 与 Rust 的 `file_formats.rs` 各自构建一次有限查找表：完整文件名优先，其次最长文件名前缀，再查后缀，统一忽略大小写。`.env.production`、`Dockerfile.release`、Gemfile、.bashrc 等复用此规则；未知扩展名默认纯文本候选。没有路径缓存，不导入语法解析器或图标。`docKind.ts` 的兼容函数与旧公开映射均从清单派生，Rust dto 保留同名兼容函数。图标清单继续负责外观，不能用图标推断文件可编辑性。

`core/codeLanguages.ts` 提供代码块与代码文件共用的纯语言元数据，TypeScript LanguageId 由它推导。所有代码块语言都有常见文件后缀覆盖；有歧义的 `.h` 默认 C，`.m` 默认 MATLAB，`.conf` 默认 INI。JavaScript/TypeScript 的 JSX/TSX、Shell 和配置别名保留统一语言标签。文件查看以阅读和基础编辑为限，没有编译器、调试器或项目索引。

状态栏与代码工具栏使用文档的当前语言元数据。工具栏可手动选择高亮语言或恢复文件名识别；选择只影响当前打开会话，不改文件内容、文档类型或脏态。CodeMirror compartment 热重配保留原实例、光标和历史，异步加载与旧语言校验会取消或丢弃过期结果。工具可用性由轻量 `textLanguageTools.ts` 描述，XML 格式化不出现在其它语言菜单里。未提供可靠 formatter 的语言保留高亮和基础编辑，不假装提供全语言格式化。

文件编辑器保留原生 CodeMirror 语法，并为 Python、C/C++、PHP、JavaScript/TypeScript、CSS 按需载入原生解析器；其余语言按模块懒加载 `@codemirror/legacy-modes` 的 StreamLanguage。解析由 CodeMirror 增量、分时执行，保留多行词法状态，不在按键处理器中调用全文高亮。原生语法保留结构折叠，StreamLanguage 提供词法高亮与缩进；工具栏提供语言名称、跳转行、折叠及展开入口，并复用已有查找、换行、行号和原生复制。代码块的后台高亮服务独立保留。

代码输入通过实例内 `codeSnapshot` 暂存当前历史组的一份不可变 CodeMirror Text，组内每次输入不展开全文、不做全文差异比较。新组开始、500ms 空闲、保存、撤销/重做、视图捕获或卸载时物化快照，复用统一历史的 materialize hook 和文档提交屏障。初次输入立即标记待确认内容并启用撤销；物化后按基线恢复精确脏态。快照同时核对会话代际和能力注册实例，旧实例的定时器、flush、清理不能覆盖同路径新会话。仅缓存当前 Text 对应的一份物化字符串，卸载释放。

DOCX、PDF、PPTX、XLSX、压缩包、媒体、程序以及 PSD/AI/Sketch/Blend/FBX/GLB 等专业创作格式明确归类 Unsupported，只读取元信息，不加载编辑器、不触发无必要的大文件正文确认。它们可以点击，通过统一文件信息页交给系统默认程序、定位文件或复制路径。OBJ/MTL、ASCII STL/DXF/STEP、未知 DAT 等可能是文本的格式保留候选，不根据设计/3D图标一律判二进制。

磁盘候选先检查最多 8KiB 前缀，识别常见二进制签名、NUL 和非文本控制字节；有限正文读取后再次检查完整内容并严格解码 UTF-8、UTF-8 BOM、GBK。其它不能无损往返当前写入编码的文件交外部程序，取消过去“猜其它编码却标 UTF-8”的行为。短 1–2 个汉字 GBK 样本存在编码歧义，采用严格解码和字节重编码相同的窄回退；无 BOM、字节恰好合法 UTF-8 的其它编码无法绝对识别。普通 UTF-8 直接消费原字节缓冲，BOM 原地移除，避免再分配整份正文。读取以调用方限制或打开文件时长度为界，读取期间增长不会返回截断内容或无限扩容。

`readDocument(path, maxReadBytes?)` 的可选上限由原生端实际执行，不是前端先查大小再无限读取。旧的一参数调用兼容；重读、prepare 和 probe 共用读取/嗅探策略，不把文档归属注册与低层读取耦合。`prepare` 保留用户的大文件确认流程，文件继续增长越限时重新确认。

改名由 documentStore 重算类型和语言，包括没有扩展名的特殊文件名互换；windowStore 从文档记录刷新标签。已有正文和脏态保留，未解码二进制不能仅靠改成 `.txt` 就变成空白可编辑文档。语法选择及预览实现没有注册新的 Windows 文件关联。

## 文本预览与配置工具

HTML 与 CSV/TSV 的预览能力来自格式，不随手动语法选择改变。Vue/Svelte/Astro 使用 HTML 词法视图，默认展示源码，不当作普通 HTML 页面执行。源码切回预览前提交最新内核快照，保留源选区/历史；视图选择保存到已有 Tab.viewMode，随标签回收恢复。

CSV/TSV 的 `DelimitedPreview` 是只读数据查看器，源码编辑仍使用同一 CodeMirror。独立按需 Worker 建立每记录 16 字节的行索引，保留源字符串，绝不常驻所有解码单元格。双轴虚拟化仅请求可见行列；A1 定位、原始源码行号、完整字段详情/复制支持访问末行末列。引号、多行字段、CRLF、空字段和不齐列数正确处理，第一行不会被擅自移作标题，HTML/公式按纯文本显示。每个挂载预览拥有 Worker，卸载终止；滚动只保留 active + latest 请求。边界为 8Mi UTF-16 单元、20万记录、1万列、400万字段；超限或语法错误明确回源码，不悄悄只展示前N行。窗口至多128行×64列、摘要字符串合计256Ki单元，完整单字段按需读取。视图通过 lazy import 加载，复用现有虚拟化依赖。

SVG 保持图片 kind 和原图片缩放/编辑功能，增加按需加载的只读 XML 源码视图。原生读取上限2MiB，支持复制/查找/换行，源码从不插入可执行DOM；卸载销毁 CodeMirror并丢弃迟到读取。此处不把源码编辑伪装为图片编辑，也不修改原 SVG 文件。

JSON 格式化/压缩使用 token 重排，保留重复键、大整数、负零、科学计数与字符串字面量。较大 JSON 或高膨胀输出走共享后台服务，最多一个 active + 一个 latest；手动操作优先于自动诊断。编辑、选区变化、语法切换、实例销毁或超时终止/丢弃任务；返回内容核对原文和选区，不能覆盖后续输入。闲置 Worker 立即释放，不缓存完整文本。自动 JSON/YAML 检查最多512Ki字符；手动最多8Mi字符，JSON输出也有8Mi上限。小JSON同步限32Ki字符、层级64和估计输出128Ki；其它进入后台。

YAML 使用现有 Lezer 语法解析器和缩进 Tab 检查，字符串中的 Tab 不误报；不声称实现 schema 或重复键语义验证。XML 使用真正 XML 解析，格式化保留混合文字、CDATA、注释和 xml:space；主线程输入最多256Ki字符、格式化输出1Mi字符、层级256，超限建议选区。DTD 保守拒绝以限制实体展开；自动诊断跳过此支持限制，不伪报语法错误。自动后台10秒、手动30秒超时释放；没有新加依赖或完整 IDE/媒体解码器。
