# 文档图片的网络共享边界

Markdown 和 NoteBoard 文档中的图片在自动显示、注释正文、打印与独立 HTML 导出前，统一通过 `core/documentImageSource.ts` 检查原始引用。本地文档内的绝对 UNC、远端 `file://`、Windows 设备别名，以及通过 percent 编码或 `asset://localhost` / `http(s)://asset.localhost` 包装的远端路径均不自动访问。被阻断的图片显示说明占位；原始节点、复制与保存内容保持不变，不把阻断结果写入文档。

用户主动打开网络共享中的文档后，该文档目录下的相对图片仍可解析。保存可能将相对引用重基为绝对路径，因此也允许与已打开文档完全相同服务器与共享名的绝对图片引用；通过组件比较，其他服务器或共享名不获许可。相对与绝对 `..` 均不能跨出该共享根。普通本地文件、合法本地 asset URL、内嵌图片和普通 Web 图片保留原有行为；打开独立图片标签页与主动点击文件链接也保留显式打开行为。仅打开网络资源管理器根目录不会给其他本地文档授予此权限。

导出 worker 同时向宿主发送已解析路径和原始图片引用。宿主根据本次打开的文档目录重新解析并匹配，之后才转换 asset 地址或读取原始字节。`portableHtmlAssetUrls` 默认拒绝直接网络路径；只有通过已打开共享目录验证的路径可以内嵌。被阻断的图片以说明占位导出，不通过其他读取入口重试。

Pandoc 的语义 Image 节点在生成 AST 时应用相同检查，并携带文档目录用于共享授权。被阻断的源只形成说明文字，不进入外部 Pandoc 写入进程的图片读取清单。

目前不提供逐图片弹窗或自动授权。需要读取被阻断的绝对共享图片时，可在系统文件管理器中手动打开，或从已主动打开的共享文档使用相对引用。

Excalidraw 的 `files[*].dataURL` 按格式语义仅接受 `data:image/...` 内嵌资源，不继承网络共享许可。发现外部路径或资源 URL 时拒绝整幅场景解析。画板显示错误，不挂载图形引擎、不初始化空白场景或新历史，flush 和卸载也不会覆盖原文档；修正后重新打开。
