# 原生文档保存与关联 Markdown

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `core/nativeDocument` | 公开帧协议、元数据与错误记录，不依赖编辑器实例 |
| `editorDocumentCodec` | 帧与不可变编辑树之间转换、块/行弱缓存 |
| `document-format/capabilities`、`featureGate` | 格式能力判定、转换确认、选区恢复和安全回放 |
| `convertDocument` | MD → NB 身份迁移，捕获/写入/提交边界 |
| `documentSession` | 每文档串行写队列、会话代际、保存基线与脏态 |
| `nativePersistence`、`nativeSaveAs` | 同一快照的 NB/MD 投影、路径重定位、版本条件 |
| `nativeSaveCommit` | 保存回执同步；保留 I/O 期间新输入，更新关联标签 |
| Rust `fsio/native_documents` | 暂存、备份、成对提交、版本复验、失败回滚及启动恢复 |
| `linkedMarkdownUpdates` | 外部关联文件检查、冲突状态和已接受版本回执 |
| `linkedMarkdownUpdatesMerge` / Worker | 有基准的局部文字合并；不猜测结构对应关系 |
| `markdownAssociationIndex` | 目录头部批读与文件树分组；不持有正文 |
| `nativeDocumentLifecycle` | 打开/保存/关闭事件及关联目录监听的生命周期 |

工具栏不直接写文件。手动保存、自动保存、更新关联 Markdown 共用保存队列；另存为和格式转换复用身份迁移屏障。外部文件的明确覆盖操作仍走保存队列与版本条件，不绕开成对提交。

## 保存版本

NB 的 `@meta.markdown` 保存相对路径、规范化文本 SHA-256 和投影规则版本。换行统一为 LF 后计算校验，不把整份 MD 缓存在 NB 中。正文状态与磁盘基线分离。

1. 捕获已确认输入，生成 NB 和关联 MD 的同一版本；投影在一次性 Worker 中执行。
2. 检查关联 MD 的已保存版本和打开标签的未保存输入。
3. 后端在同卷暂存目标结果，在应用恢复区写入备份与提交日志；每个目标替换前复验版本。
4. 两份文件都完成才提交保存回执。失败则回滚；崩溃后的恢复不覆盖后续外部写入。
5. 补写元数据回执只修改有效 NB 的小段头部。无关联的 NB 不插入空元数据；源码是权威时不单独改隐藏视觉树的元数据。
6. 只有实际写入的快照成为磁盘基线。最后等待期间的输入在同步身份提交边界再次读取，保留在新文档里并保持未保存状态。

成对提交是可恢复事务，不是跨文件的文件系统原子操作。正常成功保存会清理恢复副本；明确删除的原 MD 归档到应用恢复区 `native-recovery/removed-sources`，不参与后续未完成事务扫描。第一次文件读取前完成一次启动恢复检查。

暂存仍只写内部恢复区。不保存不再写入两端，也不撤回之前已经成功的保存。

## 外部更新

只在关联路径发生变化或文档打开/保存时检查，不订阅每键正文变化。目录监听引用计数共享；事件反向索引只调度受影响的 NB。全局最多两个检查任务，队列仅保存路径身份；关闭取消排队任务及在途 Worker。

外部文件校验值确实改变后才重建投影基准、解析和合并。按对应结构顺序遍历，文字使用局部公共前后缀识别替换，不做全文 LCS、模糊匹配或逐补丁复制整棵树。基准结构与投影不一致、共同编辑重叠或无法保留样式时，保留双方并显示可操作的提示。

合并只改变内存文档，进入撤销链，并标记未保存；它不修改 NB 磁盘基线。会话仅保留校验值与稀疏文字补丁。保存时已接受版本绑定会话代际、关联路径及 NB 磁盘基线；旧排队快照不能借新回执覆盖远端改动。撤销自动合并后仍可通过冲突提示明确选择处理方式。

## 时间与内存边界

- 打开、完整保存、导出和外部导入允许线性工作；普通输入不重建完整导出树。
- 视觉序列化缓存不可变段落、表格行和列表项；源码输入捕获 CodeMirror Text 引用。缓存随节点释放，不建立第二份常驻文档模型。
- 目录关联读取每批最多 256 个 NB 头，每个最多 64 KiB，按文件时间/大小缓存并在目录刷新失效。
- 外部转换和合并临时文档树在 Worker 内，任务结束即释放。应用新外部版本时，已挂载编辑器仍需一次完整解析；当前不是全篇增量重建引擎。
- 大型合并表格及单个巨大记录仍有实际布局/解析成本。虚拟表格、公式调度、导出布局各自有独立预算，不以文件语法名称推导性能结论。

磁盘语法与可手写示例见 [NB 编写规范](native-authoring.md)，产品行为见 [格式与保存决策](native-format-and-save-decisions.md)。
