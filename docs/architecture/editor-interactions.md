# 编辑区折叠、拖拽和菜单

内容展开/折叠统一使用 `components/DisclosureTriangle` 的实心 SVG 三角：折叠向右，展开向下；React 控件与编辑器 DOM widget 共用同一路径，旋转图标时不旋转点击区域。标题章节、独立折叠块、大纲、代码块及代码段、文件/收藏树、多维表子行和分组、思维导图分支、欢迎页更多格式均遵循此约定。普通菜单、导航及布局面板开关保留各自图标。

## 扩展装配与视图包装

`buildExtensions` 是 NB、MD 可视编辑器共用的完整装配入口。`withRichPresentation` 仅在 `configure()` 生成的独立定义上包装 NodeView，用 `getExtensionField` 保留原视图的上下文；不修改原定义、不增加继承层。当前 TipTap 的 `extend()` 会复制父配置，若通用视图包装再用它派生，含 `this.parent()` 的插件 hook 会重复执行，导致同 key 插件使整个编辑器无法加载。

装配回归覆盖空文档、NB 节点树与 Markdown 的初始化、并存和重建，代码控件测试使用实际外观包装。发布前还必须启动打包程序，检查首次示例页、NB/MD 打开及实际编辑；独立组件或转换 Worker 检查不能代替应用入口验收。

代码行号固定不换行，左侧空间按已有行索引在两至五位数字间调整，支持最多 10000 行、512000 字符；计算宽度不额外扫描文档或读取布局。超过 400 行时仅绘制视口附近最多 400 个行号和着色窗口，以每编辑器一个滚动/尺寸监听合并到一帧，通过坐标命中和二分查找定位行范围。代码段折叠保留 2000 行、128000 字符的独立预算，大块仍显示行号但不运行结构折叠解析。代码块菜单提供明确的“转为正文”，不显示正文的标题、列表、引用和文字配色；保留说明、模糊和通用块操作。

代码高亮与行号共用独立的 `codeVisibility` 服务，通过实际几何交集判断代码是否进入视口，不依赖光标或通用媒体预加载观察器。标签页从隐藏停放区恢复时重新测量。行号不等待高亮 Worker；Worker 临时失败保留已映射颜色，并在可见期间退避重试，间隔最多 30 秒。源码变化、离开可见区域或卸载时取消旧任务与计时器；解析器异常不进入成功缓存。长代码保持稳定文本分段以减少着色窗口移动时的无障碍树重建。预算及验收证据见 [代码可见性](code-visibility.md)。

## 标题折叠

`headingFolding` 以 ProseMirror DecorationSet 保存视图状态，不写入 Markdown，不参与导出。章节范围为顶层标题至下一个同级或更高级标题之前。下级标题和所有正文块都属于该范围；嵌套折叠独立保存。

普通行内输入只映射 decorations，结构或标题级别变化才重建显示轮廓；折叠/展开按顶层块一次遍历计算隐藏状态。搜索、大纲跳转或键盘选区进入隐藏部分时自动展开其祖先章节，避免光标落在不可见内容中。

`blockReorder` 接收文档顶层与第一层折叠块正文中的块边界，移动始终留在原内容区域，不跨折叠块或拖进其后代。折叠标题移动整个章节 Fragment；其他块仍单块移动。一次移动是一个原子事务，拒绝落入自身范围，落点计算跳过隐藏节点。移动前后关闭原生历史组，并向应用快照队列明确标记独立动作，保证撤销只还原本次移动。

独立折叠块保持富文本 `block+` 模型，代码块保持字面源码模型；两者只共享折叠指示器。`blockInteractionScope` 沿祖先路径判断辅助控件范围：第一层折叠块内部支持文字浮层、块菜单及同区域拖拽，第二层及更深保留编辑、粘贴和折叠，但不显示这些辅助控件。命中不扫描整篇文档，拖拽索引只收集当前区域的直接子块与列表项；表格单元格和深层折叠内容不进入索引。

编辑器块移动、表格行列重排与表格留白框选共用 `dragEdgeScroll`。靠近可见滚动边缘时按距离调整速度、按帧耗时推进并限制单帧位移；指针停住而内容继续滚动时，每帧重新计算当前落点或选区。离开边缘即停止，取消、失焦、松手及视图销毁均释放动画帧。块落点复用当前区域的缓存索引并二分读取几何，表格只二分读取当前轴的行或列，滚动帧不遍历全文。

向折叠块、Callout/Note、引用或表格单元格末尾插入图片、表格、图表等非文本块时，共用 `containerEditing` 在同一事务中补充可输入尾段，选区停在最近的容器内。既有折叠块和 Callout 以图片等结尾时，末尾空白处可点击继续输入；选中末尾块后 Enter/向下键也可创建尾段。不在加载时改写整篇文档，也不为每次输入遍历所有容器。详见 [容器编辑边界](../container-editing.md)。

`blockNavigation` 按文档节点判定可见块停点：可选择的原子块（图片、块公式、Mermaid、PlantUML、信息图、分割线等）以及图片组合。正文段落首尾用上下方向键进入相邻停点；已选中块可继续进入相邻停点或正文。图片组合内的图注不参与外层导航，轮播左右键仍由组合自身处理。表格、代码块和 Callout 等非原子内容保留各自的编辑行为。Mermaid 仅在插入入口明确标记新建事务时自动打开源码；块移动只映射当前源码编辑会话的位置，预览态保持预览，编辑态保留取消时的原始内容。历史恢复不自动夺取源码焦点。

列表把手的选择、菜单、拖动源与范围反馈共用列表项边界。指针经过浏览器生成的编号或列表留白时，`listItemHitTest` 按垂直坐标二分定位当前项，沿当前分支识别嵌套项和待办正文，不遍历整表或为每行创建控件、监听器或长期 DOM 缓存。列表末项下半行的落点仍处于列表关闭前的边界，避免因相邻正文段落而把一项移成独立列表；编号由列表模型和浏览器按位置更新，保留原始起始编号与子列表。

`BlockRangeFeedback` 将列表项的水平方向范围扩展到其直接父列表的留白，覆盖编号、项目符号或待办框，垂直方向仍取当前项本身。嵌套项采用本级列表范围，不包住祖先或同级其他项。较宽编号用当前模型路径直接取得起始序号与项索引，再按实际 CSS 计数样式和字体测量；把手定位和范围反馈共用 `listMarkerGeometry` 的行边界、十进制、字母和罗马编号。每个 view 仅持有一个按需创建的 1px 测量画布，反馈层/把手卸载时释放；替代此前跨文档常驻的全局画布。不向 DOM 插入节点、不扫描列表、不缓存每行结果，也不增加监听器或改变选区。所有反馈范围仍裁剪到当前滚动视口。

编号占据较多左侧留白时，把手采用已有的 30px 紧凑外观；极宽编号使左侧放不下时，放在本行右侧空白中，避免遮住编号。位置计算同时返回实际宽度，React 与 CSS 使用同一结果，类型图标、菜单和拖动行为保持可用。

`ScopedListCommands` 在共享文档扩展和多维表文本入口统一覆盖 `toggleList`，工具栏、快捷键和块菜单不各写一套转换逻辑。光标只转换当前项；连续选区按各项正文的交集决定范围，跨层选择保留未选中的祖先和同级项；选区在下一项首段开头结束时不包含下一项。`listTypeConversion` 只为涉及的列表生成临时结构计划，复用未选中的节点和子列表，保留格式、待办状态及有序列表续段的起始编号；相邻兼容目标列表在同一事务合并，避免逐项转换产生重复编号。同类型取消和普通段落包裹仍用原结构命令。转换保留正反向选区、可一次撤销，不扫描全文、不持有额外编辑器或 DOM 状态；链内 `can()` 在复用不可变节点的隔离 state 上验证，不污染调用者事务。

“清除文字样式”与“还原为正文”职责分开：前者使用轻量 `textStyleMarks` 的白名单和事务函数，保留链接、批注和段落结构，包括整块选中的 Callout；主编辑器、斜杠、多维表文本及批注共享该规则，嵌入编辑器不导入文档视图或重型扩展。Callout 菜单的“取消提示块”明确调用独立结构命令。后者通过 `paragraphRestoration` 按正文交集规划列表/普通引用拆分与标题还原，支持光标、反向选区、整个列表/引用的 NodeSelection 和 AllSelection，保留文字 marks、媒体、未选中项和语义容器。嵌套项只在原祖先项内恢复正文；只命中祖先正文时不解除未选中的子列表。CodeBlock 保留字面代码。主工具栏、块菜单、Ctrl+0 和斜杠命令共用 `restoreParagraph`；矩形 CellSelection 在共享入口拒绝，与工具栏限制一致，避免只处理最后一格。

源码模式清除样式复用现有增量语法树，只在目标范围删除成对的实际样式标记，完整行内代码解除和 toggleCode 共用 `markdownTextEscape`，保留字面语义。`sourceBlockGuards` 对受影响的段落使用同一块 lexer 判断清理后新暴露的结构，按原 AST 的列表正文列/引用层级处理续行，避免 Setext、表格或 Callout 误转。只分配操作局部的段落片段与共享 Text rope，不重新解析整篇文档。既有行内公式保持行内节点和原 TeX；显式 display 定界符因解除周围样式暴露到独占行时，优先用可往返的行内定界符，多行/注释则用现有 schema 的 HTML 行内容器和可读来源。实际 MathInline Markdown writer 同样复用 `inlineMathCarrier`，在段首或多行 TeX 会改变块归属时保留节点定界符和行内语义，覆盖清理、可视编辑保存、重新打开的完整往返。源码 inline grammar 在 Escape 前识别公式，Math/Callout 的块探针只看后续完整行，首行交给 tokenizer，防止 Marked 的 slice(1) 探针剥开原转义。恢复正文只处理目标行的结构前缀。

多维表短程原生历史装配 `DiscreteHistoryBoundary`：仅在已有离散编辑元数据之后追加无文档修改的 history 边界，保证紧邻输入与列表转换/格式清理分别撤销；不引入主编辑器快照队列、文档扫描或长期缓存。

顶部 `TextResetControl` 为分体按钮：主区域立即清除样式，箭头悬停或键盘向下展开两项菜单，并解释各自保留的内容；菜单复用 `useHoverMenu` 的焦点、互斥、离开缓冲及销毁清理，Portal 不夺取原文字选区。窗口较窄、主按钮收入工具栏时，两项动作仍在插入菜单中可用。

## 工具栏菜单

`components/useHoverMenu` 管理主菜单与子菜单的悬停计时、离开缓冲、键盘焦点和箭头状态。主菜单互斥；子菜单沿用父菜单生命周期。窗口失焦与组件卸载均清理定时器。配色控件仅箭头悬停展开，主区域保留应用记忆配色的动作。

分体按钮的主区域、箭头和 Portal 色板属于同一悬停分支。进入任一区域会取消当前菜单及全部祖先的关闭计时，不额外打开子菜单；离开整个分支才沿祖先链安排关闭。

`useEditorOverlayDismiss` 明确区分编辑器、所属浮层和应用其他区域。外部点击、焦点移出和窗口失焦关闭旧浮层。通过 `data-nb-editor-menu` 标记 Portal 菜单与表格选择条；普通页面按钮不会被当作编辑器菜单。文字选区工具条另用可视边界隐藏已滚出屏幕的选区。

斜杠命令在输入首个 `/` 时开启共享文档历史组，后续查询文字与同步执行的命令留在同组；命令完成后下一次输入另起一组。因此撤销一次可回到触发前正文，重做一次恢复命令结果。建议菜单是临时界面：执行或 Esc 时结束 Suggestion 会话，历史快照恢复出的 `/query` 不会自动弹出；继续真实输入才重新参与建议匹配。一级菜单“更多”末尾保留可见的“清除文字样式”，全局搜索也可用 `/clear` 找到。

## 表格选择条

`tableSelectionHandles` 只复用两个 DOM 按钮，跟随当前行和逻辑列，命中区为 22px。鼠标离开延迟 450ms 隐藏，进入选择条取消延迟；不显示左上角全选点。每帧只读取当前行及目标列的几何，合并单元格通过 colgroup 二分定位逻辑列。选择命令用 TableMap 创建行列选区，不通过滚动或复制内容完成。

按住移动超过 4px 后进入行列重排；开始时建立几何和安全边界索引，移动中二分定位边界，仅绘制落点线，不反复重建表格。松开才提交一次结构事务。跨行/列合并格扩大为不可拆开的连续组，目标不能切开其他合并格。表格索引按不可变节点缓存，构造与提交为 O(R×C)，每次落点查找为 O(log R) 或 O(log C)。取消、窗口失焦、受拖表格改变均清理临时状态。

已有格子选区或正在框选时，尺寸拖动的蓝绿提示线不显示。列宽与行高调整同样只在松开时提交。平均分配行高使用一个属性 Step，避免对每一行复制一次整表。

## 结构操作和剪贴板

`discreteEdit` 是拖动、合并、拆分、增删、粘贴和排版等离散动作的历史入口，同时分隔原生撤销组与应用快照组。剪切和粘贴分别可撤销。

内部剪贴板携带选择范围语义与 ProseMirror slice，同时提供 HTML 和纯文本。整行/整列粘贴到表格时插在目标前；在正文空段落粘贴时建立新表格。普通矩形粘贴按源尺寸写入，不重复平铺或静默截断源数据。结构重排复用原单元格节点，保留文字 marks、底色、对齐、合并和行高/列宽。

工具条依选择语义展示动作：部分格子清空内容、整行或整列删除对应结构、整表删除表格；仅在可合并/可拆分时展示对应按钮。表头控件仅在相关首行/首列选区出现，合并格不能跨表头边界。

## 内容块菜单与大纲

空段插入菜单按写作流程排列为「文字与列表 → 内容块 → 图片 → 公式与图表」，把常用文字结构放在图片组合前。任务清单的界面名称统一为「待办」，包括顶部工具栏、块菜单、拖动提示和快捷键目录；磁盘节点 `taskList` / `taskItem` 不变。

非空块把手显示类型图标与拖动点，空段落显示“＋”。悬停选择整个块并展开菜单；空段菜单按分组提供标题、列表、链接、图片、表格、代码、折叠、公式和图表等已有插入能力，超出视口时滚动。插入在原空段位置完成，不额外遗留空段；异步链接/图片操作跟踪原始位置，目标被删除或已经填入内容时不覆盖它。菜单遵循文档格式的能力显示与转换规则。开始拖动立即关闭菜单。折叠标题改级别只处理标题，引用、剪切、删除与移动处理整个折叠章节。复制成功后才执行剪切删除。

正文布局变量由 `appShell.css` 集中管理：`--document-gutter` 同时决定左右留白，大窗每侧 80px，编辑面板不超过 720px 时每侧 64px。正文容器在设置的内容宽度上加回两侧留白，再限制为不超过面板；不超过 960px 时充分使用面板宽度。居中图片、表格和公式共用正文中轴，不为某种节点单独平移。大纲独立覆盖正文，开关不改变这些宽度变量。这里使用编辑面板/正文容器查询，有无文件栏自动反映到可用宽度，不监听窗口 resize 重算文档。底部保留 64–120px 阅读余量，仅影响编辑视图，不进入 PDF。

窄面板的非空块把手收为 30px 类型图标，省去额外六点握柄，但原菜单、拖拽事件与无障碍名称保留；空行加号一直为 30px。较宽面板保留 50px 完整把手。宽度由 CSS 容器策略统一声明，定位读取相同变量，不复制断点或增加窗口监听；从空行切到非空块时不使用上一个把手的旧宽度。64px 同时容纳紧凑把手、8px 操作间距和标题/表格的 22px 边缘控件。

`headingHandleMarker` 只在现有标题折叠 widget 上挂载显示属性，通过标题的直接子控件隐藏 H1–H6 前缀，不依赖 DOM 子序号。该 widget 忽略自身属性变动，因此不会像修改标题 DOM 那样触发 ProseMirror 重建。目标变化只移除旧标记、设置新标记；坐标更新不重复设置，也不产生文档事务。已有事务映射目标位置，并在 widget 被重建后恢复标记。命中在滚动容器逐帧合并，指针位于左侧空白通道时仅向正文边缘探测一次，关闭菜单重新检查最后指针位置；不遍历整篇文档或表格单元格。模糊内容的 NodeSelection 不自动解除模糊，实际悬停或键盘聚焦才显示原文。

大纲位于正文右侧，面板内收起、右侧小按钮展开，不另设搜索。滚动条仅悬停可见且无上下箭头。正文折叠使几何索引失效，隐藏标题不参与当前滚动项定位；滚动期间只查缓存的几何索引。

大纲上沿固定在文档舞台内 56px，不随外观变化上移。顶部使用靠左的收起按钮与“大纲”标签，和列表仅隔 4px；头部不参与列表滚动。面板取消整圈描边，使用弱阴影和单层 8px 静态局部模糊，背景保留 94% 的主题底色。减少透明效果或不支持模糊时恢复实底。窄窗仅约束尺寸，不另定义表面样式；外观不增加编辑器实例、JS 动画、计时器或滚动监听。

大纲当前项和悬停底色只包住标题文字，层级缩进、折叠按钮与剩余行宽均保持透明。主编辑区的原生滚动条也不保留上下箭头。折叠内容块沿用主题色，标题与正文用细分隔线和独立内边距区分。
