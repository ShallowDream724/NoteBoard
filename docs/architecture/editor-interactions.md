# 编辑区折叠、拖拽和菜单

内容展开/折叠统一使用 `components/DisclosureTriangle` 的实心 SVG 三角：折叠向右，展开向下；React 控件与编辑器 DOM widget 共用同一路径，旋转图标时不旋转点击区域。标题章节、独立折叠块、大纲、代码块及代码段、文件/收藏树、多维表子行和分组、思维导图分支、欢迎页更多格式均遵循此约定。普通菜单、导航及布局面板开关保留各自图标。

## 扩展装配与视图包装

`buildExtensions` 是 NB、MD 可视编辑器共用的完整装配入口。`withRichPresentation` 仅在 `configure()` 生成的独立定义上包装 NodeView，用 `getExtensionField` 保留原视图的上下文；不修改原定义、不增加继承层。当前 TipTap 的 `extend()` 会复制父配置，若通用视图包装再用它派生，含 `this.parent()` 的插件 hook 会重复执行，导致同 key 插件使整个编辑器无法加载。

装配回归覆盖空文档、NB 节点树与 Markdown 的初始化、并存和重建，代码控件测试使用实际外观包装。发布前还必须启动打包程序，检查首次示例页、NB/MD 打开及实际编辑；独立组件或转换 Worker 检查不能代替应用入口验收。

代码行号固定不换行，左侧空间按已有行索引在两至五位数字间调整，支持最多 10000 行、512000 字符；计算宽度不额外扫描文档或读取布局。超过 2000 行时仅绘制视口附近最多 400 个行号，以每编辑器一个滚动/尺寸监听合并到一帧，通过两次坐标命中和二分查找定位行范围。代码段折叠保留 2000 行、128000 字符的独立预算，大块仍显示行号但不运行结构折叠解析。代码块菜单提供明确的“转为正文”，不显示正文的标题、列表、引用和文字配色；保留说明、模糊和通用块操作。

代码高亮 Worker 的临时失败保留已映射颜色，并在附近可见期间退避重试，间隔最多 30 秒。离开附近区域、源码变化或卸载时取消旧任务与计时器；不能因连续几次失败永久停止恢复。

## 标题折叠

`headingFolding` 以 ProseMirror DecorationSet 保存视图状态，不写入 Markdown，不参与导出。章节范围为顶层标题至下一个同级或更高级标题之前。下级标题和所有正文块都属于该范围；嵌套折叠独立保存。

普通行内输入只映射 decorations，结构或标题级别变化才重建显示轮廓；折叠/展开按顶层块一次遍历计算隐藏状态。搜索、大纲跳转或键盘选区进入隐藏部分时自动展开其祖先章节，避免光标落在不可见内容中。

`blockReorder` 接收文档顶层与第一层折叠块正文中的块边界，移动始终留在原内容区域，不跨折叠块或拖进其后代。折叠标题移动整个章节 Fragment；其他块仍单块移动。一次移动是一个原子事务，拒绝落入自身范围，落点计算跳过隐藏节点。移动前后关闭原生历史组，并向应用快照队列明确标记独立动作，保证撤销只还原本次移动。

独立折叠块保持富文本 `block+` 模型，代码块保持字面源码模型；两者只共享折叠指示器。`blockInteractionScope` 沿祖先路径判断辅助控件范围：第一层折叠块内部支持文字浮层、块菜单及同区域拖拽，第二层及更深保留编辑、粘贴和折叠，但不显示这些辅助控件。命中不扫描整篇文档，拖拽索引只收集当前区域的直接子块与列表项；表格单元格和深层折叠内容不进入索引。

向折叠块末尾插入图片、表格、图表等非文本块时，`disclosureEditing` 在同一事务中补充可输入尾段，选区停在容器内。既有文档以图片等结尾时，末尾空白处可点击继续输入；选中末尾块后 Enter/向下键也可创建尾段。不在加载时改写整篇文档，也不为每次输入遍历所有折叠块。

## 工具栏菜单

`components/useHoverMenu` 管理主菜单与子菜单的悬停计时、离开缓冲、键盘焦点和箭头状态。主菜单互斥；子菜单沿用父菜单生命周期。窗口失焦与组件卸载均清理定时器。配色控件仅箭头悬停展开，主区域保留应用记忆配色的动作。

分体按钮的主区域、箭头和 Portal 色板属于同一悬停分支。进入任一区域会取消当前菜单及全部祖先的关闭计时，不额外打开子菜单；离开整个分支才沿祖先链安排关闭。

`useEditorOverlayDismiss` 明确区分编辑器、所属浮层和应用其他区域。外部点击、焦点移出和窗口失焦关闭旧浮层。通过 `data-nb-editor-menu` 标记 Portal 菜单与表格选择条；普通页面按钮不会被当作编辑器菜单。文字选区工具条另用可视边界隐藏已滚出屏幕的选区。

## 表格选择条

`tableSelectionHandles` 只复用两个 DOM 按钮，跟随当前行和逻辑列，命中区为 22px。鼠标离开延迟 450ms 隐藏，进入选择条取消延迟；不显示左上角全选点。每帧只读取当前行及目标列的几何，合并单元格通过 colgroup 二分定位逻辑列。选择命令用 TableMap 创建行列选区，不通过滚动或复制内容完成。

按住移动超过 4px 后进入行列重排；开始时建立几何和安全边界索引，移动中二分定位边界，仅绘制落点线，不反复重建表格。松开才提交一次结构事务。跨行/列合并格扩大为不可拆开的连续组，目标不能切开其他合并格。表格索引按不可变节点缓存，构造与提交为 O(R×C)，每次落点查找为 O(log R) 或 O(log C)。取消、窗口失焦、文档改变均清理临时状态。

已有格子选区或正在框选时，尺寸拖动的蓝绿提示线不显示。列宽与行高调整同样只在松开时提交。平均分配行高使用一个属性 Step，避免对每一行复制一次整表。

## 结构操作和剪贴板

`discreteEdit` 是拖动、合并、拆分、增删、粘贴和排版等离散动作的历史入口，同时分隔原生撤销组与应用快照组。剪切和粘贴分别可撤销。

内部剪贴板携带选择范围语义与 ProseMirror slice，同时提供 HTML 和纯文本。整行/整列粘贴到表格时插在目标前；在正文空段落粘贴时建立新表格。普通矩形粘贴按源尺寸写入，不重复平铺或静默截断源数据。结构重排复用原单元格节点，保留文字 marks、底色、对齐、合并和行高/列宽。

工具条依选择语义展示动作：部分格子清空内容、整行或整列删除对应结构、整表删除表格；仅在可合并/可拆分时展示对应按钮。表头控件仅在相关首行/首列选区出现，合并格不能跨表头边界。

## 内容块菜单与大纲

空段插入菜单按写作流程排列为「文字与列表 → 内容块 → 图片 → 公式与图表」，把常用文字结构放在图片组合前。任务清单的界面名称统一为「待办」，包括顶部工具栏、块菜单、拖动提示和快捷键目录；磁盘节点 `taskList` / `taskItem` 不变。

非空块把手显示类型图标与拖动点，空段落显示“＋”。悬停选择整个块并展开菜单；空段菜单按分组提供标题、列表、链接、图片、表格、代码、折叠、公式和图表等已有插入能力，超出视口时滚动。插入在原空段位置完成，不额外遗留空段；异步链接/图片操作跟踪原始位置，目标被删除或已经填入内容时不覆盖它。菜单遵循文档格式的能力显示与转换规则。开始拖动立即关闭菜单。折叠标题改级别只处理标题，引用、剪切、删除与移动处理整个折叠章节。复制成功后才执行剪切删除。

正文布局变量由 `appShell.css` 集中管理：左侧 88px 控件通道，右侧 24px；不足 640px 的正文容器右侧收至 16px。大纲收起且编辑面板不超过 960px 时取消额外的百分比居中边距；较宽面板在用户正文宽度基础上补回 64px 控件空间，最大不超过面板。大纲展开时保留原有正文宽度比例，实际正文容器不足 640px 再收紧。这里使用编辑面板/正文容器查询，有无文件栏自动反映到可用宽度，不监听窗口 resize 重算文档。底部保留 64–120px 阅读余量，仅影响编辑视图，不进入 PDF。

`headingHandleMarker` 只在现有标题折叠 widget 上挂载显示属性，通过标题的直接子控件隐藏 H1–H6 前缀，不依赖 DOM 子序号。该 widget 忽略自身属性变动，因此不会像修改标题 DOM 那样触发 ProseMirror 重建。目标变化只移除旧标记、设置新标记；坐标更新不重复设置，也不产生文档事务。已有事务映射目标位置，并在 widget 被重建后恢复标记。命中在滚动容器逐帧合并，指针位于左侧空白通道时仅向正文边缘探测一次，关闭菜单重新检查最后指针位置；不遍历整篇文档或表格单元格。模糊内容的 NodeSelection 不自动解除模糊，实际悬停或键盘聚焦才显示原文。

大纲位于正文右侧，面板内收起、右侧小按钮展开，不另设搜索。滚动条仅悬停可见且无上下箭头。正文折叠使几何索引失效，隐藏标题不参与当前滚动项定位；滚动期间只查缓存的几何索引。

大纲当前项和悬停底色只包住标题文字，层级缩进、折叠按钮与剩余行宽均保持透明。主编辑区的原生滚动条也不保留上下箭头。折叠内容块沿用主题色，标题与正文用细分隔线和独立内边距区分。
