# 补充说明

补充说明是作者正文的一部分。选中文字或可选内容块后调用“添加说明”，阅读时从虚线下划线或问号打开正文。首版不支持说明内再创建说明。

分割线属于排版元素，不提供新建说明；菜单、草稿入口和直接创建命令共用 `canAnnotateBlock`。旧文档中已存在的分割线说明仍可阅读、编辑和删除，载入时不丢弃内容。

## 原生结构

文档开头的单个 `annotationStore` 包含一个或多个 `annotationBody`。它位于可见正文之前，避免被末尾标题章节的折叠或拖动包含。每个 body 有稳定 `id`，内容为普通 `block+`，可包含段落、列表、表格和图片。正文内 `annotationReference` mark 的 `id` 和块的 `annotationId` 指向这个实体；长正文只保存一次。说明浮窗和阅读状态不进入文档 JSON。

一次跨行添加创建一条说明，共用同一 ID；删除此说明解除它的全部引用，不影响另一次创建的独立说明，也不删除锚点正文。多个锚点时，浮窗标题显示“ N 处共用”，删除提示明确全部关联范围。计数来自既有增量锚点索引，仅在浮窗挂载时计算，不另存说明正文或为关闭的浮窗建立监听器。

`annotations/schema.ts` 仅声明共享语法，可以用于编辑器、Worker、原生编解码和导出。`model.ts` 负责引用遍历、实体收集、递归说明清理和剪贴板 ID 重映射。原生文档校验须保证 store 仅在顶层，ID 唯一且引用完整，并将 store 规范化到正文之前；普通 block 语法本身不能表达这些跨树约束。

`beginAnnotation` 只打开草稿并保留映射书签，取消或 Escape 不改变文档。首次保存将锚点与正文作为一次父文档事务提交；目标被删除时保留草稿并提供重新选择目标的操作。`addAnnotation` 是直接提交内容的程序接口。更新正文和移除也走父编辑器的 `dispatchDiscreteEdit`。`AnnotationBehavior` 在原事务后清理失去最后一个锚点的实体，清理与删除锚点同组撤销，撤销时两者一起恢复。图片引用仍是普通子节点，已有资产扫描可以递归发现它们。

块菜单使用 `beginBlockAnnotation(editor, pos)` 直接捕获块书签，不向主编辑器派发 NodeSelection。表格插件会把派发的整表选择规范化为单元格选择，因此不能用当前选区代替菜单的块目标。块说明的属性写入使用 `BlockMetadataStep`，保留内容引用和空位置映射；创建整表说明不扫描所有单元格，删除复用现有锚点索引。

## 阅读与编辑

`AnnotationLayer` 默认以 `findScrollContainer(editor.view.dom)` 的滚动区域为边界，也接受显式 `container`。非固定窗口与锚点共享 `useHoverMenu` 的进入/离开延迟；移入窗口会取消关闭，点击外部关闭非固定阅读窗口。问号、文字锚点与窗口操作支持键盘访问。Escape 关闭并恢复焦点；说明按钮使用现有 Tooltip。

`dismissTransientAnnotations(editor)` 通过绑定在该编辑器 DOM 上的界面事件收起临时阅读窗口，保留固定窗口和未保存草稿，不改文档和选区。示例引导在保存完成并转入插入内容步骤时调用，防止刚保存的阅读浮窗覆盖下一步的正文输入位置。Layer 负责窗口生命周期，调用方不点击内部按钮、不操作浮窗 DOM。

浮窗 DOM 暴露 `data-annotation-editor-key`，新草稿同时暴露映射中的 `data-annotation-target-from/to` 及失效状态。它们只描述当前界面模型，不进入文档存储；上下文引导据此区分编辑器和草稿捕获范围，避免把另一文档或部分选区的草稿当作目标说明。阅读已有说明不伪造新草稿范围。

文字选区和整段/标题的文字均显示虚线下划线，问号在最后一个字的右上方，使用零宽锚点 decoration，独立的可折叠间距将后文与问号分开；行末允许问号伸出正文边缘，间距不产生空行，标记不能独立换行。锚点用仅在视图中生成的连接符绑定前一个字，并允许后文正常换行。整段的虚线使用独立样式类，点击段末或正文仍然放置光标，说明从问号打开；文字选区的行内锚点保留悬停阅读。代码和图表的说明在工具条中占独立位置，与复制、编辑按钮分开；图片及组合的说明依附实际图框，随尺寸和对齐移动。表格由 `TableAccessories` 在真实 table 右上角放置 18px 问号，与整表位置和列宽一起变化，不给单元格或整表文字加下划线。块的 `annotationId` 不随 Enter 分段继承，原段保留说明，新段不复制引用。标记定位依赖文档结构和 CSS，不在滚动或鼠标移动时测量所有锚点。

自定义 NodeView 通过 `ownsAnnotationMarker` 显式接管标记布局，索引只向有效块装饰传递说明 ID；共享 `AnnotationMarker` / DOM marker helper 负责统一外观。默认语法视图仍使用零占位 widget，不因缺少自定义 NodeView 而丢失入口。布局归属只在建立编辑器时收集，不在事务中扫描扩展或 DOM。`setNodeMarkup` 等替换块起始边界的事务会重建相应装饰，避免尺寸更新后入口消失；普通正文输入继续映射已有装饰。

编辑说明时 Enter 保存，Shift+Enter 换行，输入法确认键不触发保存。保存事件在嵌入编辑器的键位处理前捕获，避免被换行指令吞掉。阅读与编辑状态均在浮窗标题栏提供删除按钮；文字工具栏中的添加/编辑说明使用同一个问号图标与提示。

问号标记统一使用主题次级文字与主文字混合的前景、略带主题色的底色和清晰轮廓；普通标记为 16px、整表为 18px，均不参与正文行宽。悬停增强轮廓，键盘聚焦另加可见外圈，避免三种主题中的低对比标记难以发现。

固定、位置、尺寸仅保存在 Layer 的阅读状态。窗口通过指针捕获拖动和调整尺寸；指针取消恢复手势前几何，窗口/面板缩小时收回可达边界。移动和缩放也支持方向键，按 Shift 增大步长。只有打开的说明挂载正文视图；文档变更时映射缓存锚点/实体位置与装饰，仅检查事务触及范围（文字标记按完整文字块归并），浮窗移动不遍历文档。孤立实体清理从索引得出待删 ID，只解析相应 body 与 store 位置；无说明的长文档输入不进行全文遍历。

正文编辑采用轻量 ProseMirror 视图与共享 schema。草稿有本地撤销，保存时替换父文档中的对应 body，一次文档操作完成；取消不改正文。正文支持现有富文本 HTML 粘贴、加粗、斜体、下划线、删除线、行内代码、文字颜色、高亮、链接、标题、列表、引用和图片节点，可以粘贴含图片的富文本或通过图片地址/相对路径插入。图片沿用父文档的相对路径基础目录。公式和图形块在轻量正文视图中显示其完整源码，不会实例化整套主编辑器的图形编辑控件或递归浮窗。

`BodyFormatToolbar.tsx` 只消费草稿 `EditorView` 与事务更新后的 `EditorState`；`bodyFormatting.ts` 负责选区格式状态和原始 PM 命令，不伪装 TipTap Editor。工具栏在说明的嵌套滚动区域顶部保留可达位置，鼠标操作不抢走选区，键盘可以 Tab 或左右方向键访问；部分格式选区使用 `aria-pressed="mixed"`，不支持的操作禁用。颜色复用共享色板；新建链接需要选择文字，光标位于已有链接内时可以修改或移除整条链接，包含其中的不同样式片段。清除文字格式与主编辑器保持相同语义：清除展示 marks、保留链接，空选区清除当前段落并清除后续输入格式。每次视觉格式操作与前后输入独立撤销。

说明编辑通过 `editingScope.ts` 注册外部编辑上下文，顶栏在该上下文激活时禁用正文编辑命令与历史，防止旧正文选区被误改。说明重新获得焦点会重新激活自己的上下文，结束或卸载时释放注册。草稿内容仍独立于父文档，事务回调仅用于更新局部工具栏状态；光标状态查询不遍历全文。输入法组合期间禁用局部格式操作，并继续保留 Enter 确认与保存的原有边界。

移动内容块只改变锚点位置，说明实体继续由同一 ID 关联；移动及其撤销、重做均保留实体。索引使用半开范围判断事务影响，避免文档末尾自动补段落时误将相邻轮播的说明判为孤立并清除。

`bodyView.ts` 与主编辑器共用 `createClipboardImportPlugin`：小片段直接处理，大 HTML/Office/原生片段/纯文本走同一 Worker 和分片物化；说明内去掉递归说明引用。纯图片沿用父文档 docKey 与同一资产保存租约，落点随草稿事务映射。Escape 优先取消尚未完成的粘贴、保留草稿；卸载取消任务。编辑窗使用现有 `data-shortcuts-suspended` 边界，Ctrl+Z/重做只作用于草稿历史。读/编辑视图共同使用表格 viewport 和 row/table/cell NodeView，大表不在说明窗口退回全量单元格 DOM。

## 交换边界

结构化复制先通过 `annotationBodiesForFragment` 附带被引用的 body，再对整个片段调用一次 `remapAnnotationIds`，确保副本不共享原说明。粘贴应把说明实体合并至顶层 store，新建时位于文档开头，与锚点插入共用一个事务。`annotationBodyContent` 清理说明内部的递归实体和引用，保留普通内容。

Markdown、HTML、打印及 Word/LaTeX 使用独立导出投影：正文编号引用与完整文末说明。可见层隐藏 store 只属于编辑显示，导出不可依赖屏幕 DOM。静态正文视图对复杂图形保持共享 schema 的语义 DOM，首版不嵌入主编辑器的图形专用控件。

## 验证

`test/editor-md/annotations.test.ts` 覆盖富文本分片共用一个实体、图片块锚点、创建/保存/删除的撤销重做、删除最后锚点的原子清理、禁止递归说明、复制 ID 重映射和窗口边界约束，并以 4,000 段文档验证普通输入只检查当前文字块。`annotationLayer.test.tsx` 的 DOM 交互测试覆盖悬停缓冲、固定状态和键盘关闭；真实布局与触摸手势仍需浏览器验证。

`annotationBodyFormatting.test.ts` 验证草稿格式与独立撤销、混合状态、共享 schema 限制、清除保留链接、跨样式链接编辑和输入校验；`annotationBodyToolbar.test.tsx` 验证可见按钮状态、鼠标选区和焦点保留、局部撤销/重做与色板应用。原有 `annotationBodyView.test.ts` 保持大表虚拟化、异步粘贴映射、卸载取消和独立键盘历史的覆盖。
