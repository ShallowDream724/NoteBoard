# 互动练习

从欢迎页主动开始互动练习，会打开一份未保存的 NB 笔记副本。它不更改默认文档类型或纯 Markdown 设置。练习中的文字、块、表格和说明使用正常编辑器能力，可以继续编辑、保存或导出。

浮动任务卡提供 11 项短任务：选中文字、背景高亮、二级标题、提示块、折叠块、填写表格、三线表、行内公式、补充说明、移动块、撤销与重做。任务按选区和文档实际语义判断，接受正常编辑入口。完成后由用户点击继续，卡片不会改写正文、改变选区、抢焦点或自动跳到下一步。可以跳过任一项，也可以在清单返回任务。

卡片可以折叠或移到另一侧。定位练习内容只在用户点击时滚动一次，不跟随输入。切换到其他标签时隐藏卡片并释放编辑器监听；返回后继续。关闭练习标签或退出练习会清空观察状态，退出不关闭或修改笔记。重新练习创建新副本，保留之前的编辑内容。同类 NB 另存为或重命名时，练习跟随原子发布的标签身份；转换为其他格式时结束练习。

完成状态表示用户在本次练习中达成过目标，不承诺后来继续编辑时该效果仍存在。跳过的任务不会计入已完成。导出仅在结尾作为探索提示，没有把点击菜单当作完成证据。

## 模块接口与资源边界

- `practiceStore.ts`：启动可加载的轻量 Zustand 状态，只有练习 key、当前任务 ID、已完成与跳过 ID；不存课程、编辑器、文档内容，不持久化。
- `startInteractivePractice.ts`：`startInteractivePractice(options?: { fresh?: boolean }): Promise<string>`。入口通过动态导入调用。默认恢复仍然打开的练习标签，保留进度；无会话时加载课程材料与 `welcomeActions.openNativeTemplate(title, content)`，创建副本后建立会话。只有显式 `{ fresh: true }` 的重新练习操作创建另一个副本。
- `InteractivePracticePanel.tsx`：默认及命名导出，props 为 `{ activeEditor: Editor | null; activeKey: string | null }`。由壳在会话存在时懒加载，置于文档容器内。
- `practiceDetection.ts`：纯语义谓词，以及一个当前编辑器的 `transaction` / `destroy` 订阅。仅匹配活动练习 key 且 `editorDocumentKey` 一致时读取编辑器状态，无全局轮询、全文 JSON 序列化或其他文档扫描。普通任务只在进入任务及文档变化时检查；选区任务额外响应选区事务。历史任务监听统一文档历史的公开成功导航事件，要求新编辑后真实撤销再重做，且正文确实恢复；只在这项任务期间持有撤销前的不可变节点引用，结束后释放。
- `practiceLifecycle.ts`：由 AppShell 在练习会话存在期间订阅标签列表，跟踪关闭及原子 key 迁移；画板演示等隐藏面板的视图不影响清理，不订阅文档内容。身份迁移要求同一索引被带磁盘路径的 NB 标签替换、标签数量一致、其他标签 key 未变。

定向测试位于 `test/learning`，覆盖种子无预完成、目标语义、真实历史、错文档隔离、监听释放、跳过退出重来和标签身份。
