# 示例文档上手引导

首次启动的空窗口自动打开「欢迎使用 NoteBoard.nb」，直接在这份可编辑的功能示例中开始引导。已有配置、恢复中的文档、通过文件启动的窗口保留原来的打开行为。主界面原有的「浏览功能示例」也会打开示例并开始引导；没有独立练习按钮或第二份练习文档。

八个短步骤串起实际编辑流程：查看 Note 的问号说明、拖选文字、添加高亮、打开说明编辑、写入并保存说明、输入 `/note`、插入 Note、展开折叠内容。每一步圈出真实目标，箭头从旁边的提示卡指向它。跨行文字按实际行框圈出；提示卡避开目标及已打开的说明面板。空行目标留出拖拽按钮的点击区域。命令判定只接受 `/note` 的实际搜索结果，关闭菜单后提供重新输入的目标。

选区、高亮、打开编辑和打开命令菜单等明确操作完成后自动进入下一步；阅读、保存和插入结果留给用户点击继续。未保存的说明草稿、仅高亮部分文字、示例中原有的提示块都不算完成。可以跳过任何一步或退出，退出保留编辑内容。引导期间暂时隐藏当前文档的大纲，避免其遮挡说明按钮，不更改用户的大纲设置。

引导不抢焦点或替用户修改内容。进入正文步骤时仅滚动到目标一次，之后不会追着用户滚动；目标离屏时可点击定位。SVG 圈和箭头不接收鼠标，只有提示卡可交互。存在模态对话框时暂时隐藏引导。切换标签时解除监听，返回可继续；关闭标签或转换为其他格式结束引导。同类 NB 另存为或重命名时随原子标签身份迁移。

## 职责与资源边界

- `practiceStore.ts` 只保存会话 key、代次、当前步骤及完成/跳过 ID，不保存编辑器或文档，也不持久化。每次开始递增代次，防止同一个标签重启时复用旧基线或异步回调。
- `startInteractivePractice.ts` 的 `startShowcaseGuide(key): void` 绑定已创建的 NB 标签。`openShowcase` 完成图片准备、创建真实示例后调用；失败和被其他文件抢先占用的首次启动不会创建引导。
- `practiceCourse.ts` 保存短文案及目标词，不持有另一份文档模板。
- `practiceDetection.ts` 是文档语义判定，跳过隐藏说明存储；正文不变时不重新遍历。选区步骤额外检查选区变化。开始时保存提示块计数，新增提示块才算完成。
- `guideTargets.ts` 集中适配编辑器节点、实际工具栏及弹层。文字通过 ProseMirror 位置转换为 DOM Range；菜单和 NodeView 状态来自可见 DOM，避免用编辑器存储属性推断未持久化的折叠状态。
- `guideGeometry.ts` 为纯几何函数，负责行框、视口约束、障碍避让和箭头定位，独立于 React、编辑器和文案。
- `InteractivePracticePanel.tsx` 按需加载并通过 portal 绘制提示。只观察当前会话编辑器；transaction、滚动、尺寸和必要 DOM 变化统一合并到一帧。忽略引导自身变动，无轮询、全文 JSON 序列化或其他文档扫描。关闭、切换或销毁时取消帧、定时器、observer 和事件监听。
- `practiceLifecycle.ts` 由 AppShell 订阅标签身份，不订阅文档内容。身份迁移要求同一索引被带磁盘路径的 NB 标签替换、数量一致且其他 key 未变。

`test/learning` 覆盖任务语义、目标几何、错误文档隔离、关闭清理和同 key 重启；`test/welcome/showcase.test.ts` 覆盖首次启动、并发打开保护及示例往返保存。生产构建和原生交互验收见 [可视化编辑验收](visual-editing-acceptance.md)。
