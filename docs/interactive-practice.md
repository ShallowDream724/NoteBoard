# 示例文档上手引导

首次启动的空窗口自动打开「欢迎使用 NoteBoard.nb」，直接在这份可编辑的功能示例中开始引导。已有配置、恢复中的文档、通过文件启动的窗口保留原来的打开行为。主界面原有的「浏览功能示例」也会打开示例并开始引导；没有独立练习按钮或第二份练习文档。

八个短步骤串起实际编辑流程：查看 Note 的问号说明、拖选文字、添加高亮、打开说明编辑、保存说明、输入 `/note`、插入 Note、展开折叠内容。每一步标出真实目标，附近的小尖角浮层介绍用途和可以尝试的操作。文字只测量模型选区中的文本节点，排除问号等装饰控件，同一行的嵌套样式合并为一个框。空行目标留出拖拽按钮的点击区域。关闭命令菜单后提供重新输入的目标。

顶部高亮按钮因响应式布局收起时，引导改为指向选区浮动工具栏里的同一操作，不要求用户扩大窗口。

浮层复用已有 Radix Popover 的定位与视口碰撞处理，优先出现在目标上方，空间不足时翻转或平移；与目标保持短距离，以小尖角连接。说明面板的悬停开关不参与重新摆位。完成动作后立即撤掉当前浮层和框，短暂等待后自动切步，避免显示旧步骤或追逐移动的按钮。

文案介绍功能用途，再给出可以尝试的操作，不评价用户是否掌握，也不重复催促。流程依据 [Apple Onboarding](https://developer.apple.com/design/human-interface-guidelines/onboarding) 的情境学习原则，以及 [Windows TeachingTip](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/dialogs-and-flyouts/teaching-tip) 的就近提示方式；保留本应用的主题和交互规范。

所有步骤根据实际操作自动推进，不设置“继续”或结束确认页。悬停/点击问号并展开说明即完成阅读动作；保存后，正文中存在对应说明记录即完成保存，空格和空说明也有效。未保存或取消的草稿、仅高亮部分文字、示例原有的提示块不算完成。提前完成保存或插入的快速操作也可被下一步识别。可以跳过任何一步或退出，末步完成后自然回到示例，保留编辑内容。引导期间暂时隐藏当前文档的大纲，不更改用户的大纲设置。

引导不抢焦点或替用户修改内容。进入正文步骤时仅滚动到目标一次，之后不会追着用户滚动；目标离屏时可点击定位。目标框不接收鼠标，只有提示卡可交互。存在模态对话框时暂时隐藏引导。切换标签时解除监听并暂停自动推进，返回可继续；关闭标签或转换为其他格式结束引导。同类 NB 另存为或重命名时随原子标签身份迁移。

## 职责与资源边界

- `practiceStore.ts` 只保存会话 key、代次、当前步骤及完成/跳过 ID，不保存编辑器或文档，也不持久化。每次开始递增代次，防止同一个标签重启时复用旧基线或异步回调。
- `startInteractivePractice.ts` 的 `startShowcaseGuide(key): void` 绑定已创建的 NB 标签。`openShowcase` 完成图片准备、创建真实示例后调用；失败和被其他文件抢先占用的首次启动不会创建引导。
- `practiceCourse.ts` 保存短文案、目标词及可选的切步停留时间，不持有另一份文档模板。自动推进是统一行为，不允许某一步意外退回手动确认。
- `practiceDetection.ts` 是文档语义判定，跳过隐藏说明存储；正文不变时不重新遍历。选区步骤额外检查选区变化。开始时保存提示块计数，新增提示块才算完成。
- `guideTargets.ts` 集中适配编辑器节点、实际工具栏及弹层。文字通过 ProseMirror 位置转换为 DOM Range；菜单和 NodeView 状态来自可见 DOM，避免用编辑器存储属性推断未持久化的折叠状态。
- `guideGeometry.ts` 只负责文本行框合并与范围计算，独立于 React、编辑器和文案。浮层摆位由现有组件库负责，不再维护另一套箭头/障碍排序引擎。
- 保存步骤完成后通过说明模块的 `dismissTransientAnnotations(editor)` 收起临时阅读浮窗，再转入空行输入，避免浮窗覆盖下一步。固定窗口和未保存草稿保留；教程不操作说明模块内部 DOM 或修改正文。
- `InteractivePracticePanel.tsx` 按需加载并通过 portal 绘制提示。只观察当前会话编辑器；transaction、滚动、尺寸和必要 DOM 变化统一合并到一帧。忽略引导自身变动，无轮询、全文 JSON 序列化或其他文档扫描。关闭、切换或销毁时取消帧、定时器、observer 和事件监听。
- `practiceLifecycle.ts` 由 AppShell 订阅标签身份，不订阅文档内容。身份迁移要求同一索引被带磁盘路径的 NB 标签替换、数量一致且其他 key 未变。

`test/learning` 覆盖任务语义、目标几何、错误文档隔离、关闭清理和同 key 重启；`test/welcome/showcase.test.ts` 覆盖首次启动、并发打开保护及示例往返保存。生产构建和原生交互验收见 [可视化编辑验收](visual-editing-acceptance.md)。
