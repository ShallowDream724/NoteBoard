# 块把手与批量选区

悬停仅显示把手、范围反馈与操作菜单，不派发选择事务。按住指针划选文字期间把手保持可见但不接收指针，也不展开菜单；单击或超过 4px 后拖动是独立的操作。撤销、删除目标、取消、窗口失焦和卸载均释放菜单状态、指针捕获、拖动 lease、索引、计时器和滚动器。文档变化使正在执行的拖动失效，不能把旧坐标用于新文档。

`blockSelection.ts` 在选区变化时解析所选区间的逻辑单位：普通块、独立列表项及第一层折叠块正文。祖孙不重复计数，位于下一段起点的排他尾界不包括该段；CellSelection 使用表格操作。原 TextSelection 的方向和文字范围用于清理、还原与剪贴板/删除。两项及以上展示批量菜单，把手定位于首项，不悄悄回退到某个单项。

单块菜单的清理、还原和链接在该块内已有文字选区时沿用原范围。位置、布局和容器操作绑定菜单目标；剪切、复制、删除内容块的标签明确整块作用域。批量菜单的删除为“删除所选内容”，按原文字范围执行；拖动按完整逻辑单位移动，提示显示数量。

`blockSelectionMove.ts` 在手势开始时一次准备不可变片段和删除区间，预览只解析目标祖先及 Schema，不在每次指针移动时切片文档或克隆 JSON。同列表排序直接移动原项；跨列表保留来源样式与编号，由 `listBoundaryInsertion` 分段目标列表。完整移走列表时带走说明，部分移动不复制列表外壳说明 ID。未选祖先和兄弟保留，禁止自身范围内及不同编辑区域的落点。所有删除和插入为一笔离散事务，保留顺序、原节点属性和一次撤销。

折叠章节按实际隐藏范围移动；多段位移通过 `BLOCK_MOVE_META.ranges` 把折叠标题映射到新位置。`BlockRangeFeedback` 只测量首尾 DOM，裁剪到视口，始终只持有一个图层；拖动时同一图层显示源范围，结束即释放。临时源样式不写进由 ProseMirror 管理的正文 DOM，也不逐个持有所选元素，避免 DOMObserver 重绘回收和千项样式遍历。无每块常驻监听器或文档副本。

真实 UI 回归覆盖反向划词经过把手、悬停后撤销目标、单词清理范围、批量排序和一次撤销，以及浮动辅助栏的紧凑提示策略。模型测试覆盖跨列表插入、嵌套项、注释/样式、非法和过期计划、千项列表。

应用统一历史负责 Ctrl+Z/重做；原生 ProseMirror 历史仅在连续编辑中提供分组信号。主文档的 UndoRedo 扩展通过 `nativeHistory` 包装原生历史状态字段。应用历史导航完成后，元数据事务只重置该字段，释放已经失效的重复撤销片段；正文、选区、插件数组及插件视图保留，不重新配置或卸载公式等嵌入编辑器，也不触发新的文档变化。分组深度计数同步归零。嵌入编辑器继续使用普通原生历史。压测使用应用快捷键，并按正常批量操作重新选中目标列，避免把内部 undo 当成一次新的应用编辑。
