# 1.0.4 发布前审查

日期：2026-10-13。审查基线为 `v1.0.3`，不包含用户本地的 `src-tauri/examples/pdf_smoke.rs` 修改和 `output/` 文件。

## Astra 审查与修复

按用户要求，Astra high 独立只读审查了书签持久化与标记、拖放路由和临时目录展开、颜色补偿、保存协调与原子写、内容块边界和分页关键路径；没有逐行覆盖全部改动，也没有替代原生窗口交互验收。

- 确认 1 项 P2：PDF 表格适宽后仍被误报超宽，导致常规导出按钮不可用。最终宽度检查错误地除以表格自己的缩放比例。
- 修复：最终校验使用可见宽度，嵌套表同时缩放父单元格的可用宽度。初始列宽规划保持未缩放坐标。
- 真实 Edge 复核：表格可见宽度 702.96875 px，可用宽度 702.99213 px，修复后 `issues: []`。新增回归覆盖显式适宽、自动单组缩放、父子同时缩放及恢复原尺寸后的真实溢出。
- 复查未发现新的发布阻断；本轮未发现已证实的 P0/P1。

- TypeScript 检查通过。
- 前端全量：347 个文件、3014 项测试通过。
