# 1.0.4 发布前审查

日期：2026-10-13 至 2026-10-14。审查基线为 `v1.0.3`，不包含用户本地的 `src-tauri/examples/pdf_smoke.rs` 修改和 `output/` 文件。

## Astra 审查与修复

按用户要求，Astra high 独立只读审查了书签持久化与标记、拖放路由和临时目录展开、颜色补偿、保存协调与原子写、内容块边界和分页关键路径；没有逐行覆盖全部改动，也没有替代原生窗口交互验收。

- 初次确认 1 项 P2：PDF 表格适宽后仍被误报超宽，导致常规导出按钮不可用。最终宽度检查错误地除以表格自己的缩放比例。
- 修复：最终校验使用可见宽度，嵌套表同时缩放父单元格的可用宽度。初始列宽规划保持未缩放坐标。
- 真实 Edge 复核：表格可见宽度 702.96875 px，可用宽度 702.99213 px，修复后 `issues: []`。新增回归覆盖显式适宽、自动单组缩放、父子同时缩放及恢复原尺寸后的真实溢出。
- 复查未发现新的发布阻断；本轮未发现已证实的 P0/P1。

## 回归结果

- TypeScript 检查通过。
- 前端全量：349 个文件、3023 项测试通过；此后补充的单图导出和默认高亮回读修复另做定向回归。
- Rust library：132 项通过；1 项需要新生成 Chromium PDF 的专用集成测试按原配置忽略。
- 本轮改动的 ESLint 检查通过。全仓检查仍有 40 项已有错误，所在文件与 `v1.0.3` 相同，主要为历史测量脚本的浏览器全局声明、测试类型及两处正则规则；未把全仓 lint 描述为通过。
- 三主题实际配色组合、大字号说明/书签标记、书签精确范围跳转和折叠隐藏，均有真实 Edge 检查；相关脚本位于 `scripts/check-readable-ink.mjs`、`scripts/check-inline-markers.mjs`、`scripts/check-bookmark-panel.mjs`。

完整回归还发现边缘滚动停止后会重复写入零位移，已避免该冗余写入。万行表格测试在并行环境中曾因整项运行超过默认 5 秒而超时；仅将该项总时限改为 15 秒，保留不重建行布局、复用 DOM、少量挂载单元格、选区与内容保持等断言。事务耗时记录为诊断信息，不伪装成性能上限断言。此调整经 Astra 复核，全量重跑通过。

## 打印与主题复查

- 打印预览的原生读取曾将一个 PDF.js range 请求拆成多次回调，第一段就让 reader 结束。现按原生 1 MiB 上限分段读取、合并后只交付一次；同起点请求保序，关闭预览后忽略晚到结果。Astra 复核通过。真实 Edge 与 PDF.js worker 读取 3,146,329 字节 PDF，触发跨 1 MiB 请求，逐字节一致且无错误；7 项单测覆盖分段、并行、短读和取消。
- 主题测试改用真实赤陶标识 `hu-po`。真实 Edge 检查三个主题的提示块、自定义底色、流程图与时序图以及往返切换；文字对比度至少 4.5，连线和箭头至少 3。屏幕补偿不进入文档 JSON、HTML 或剪贴板序列化。
- Astra 发现单独复制、导出 Mermaid 沿用屏幕深色 SVG，白底接收端可能看不清。修复为显式操作时惰性生成浅色 SVG，按当前源码缓存，编辑和卸载取消旧准备；块内、全屏和独立预览共用出口，复查通过。
- 最后复核发现默认高亮的 DOM 回读会产生空字符串，从而跳过默认背景补偿。解析已归一为 `null`，补偿层兼容历史空串；Astra 亲自重跑高亮及实际图表菜单的 11 项定向测试全部通过，已报告问题均闭环。

## 发布方式

版本保持 `1.0.4`。先验收本机构建与覆盖安装，再将同一 NSIS 安装包和 SHA256SUMS.txt 上传到草稿 Release，核对附件后发布。`.github/workflows/release.yml` 仅保留手动触发的云构建后备入口，需选择匹配版本的 tag；推送 tag 不再重复构建。更新文案使用 `docs/releases/1.0.4.md`。
