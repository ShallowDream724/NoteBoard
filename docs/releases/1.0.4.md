# NoteBoard 1.0.4

### Added

- **🔖 文字与内容块书签**：选中文字后，可从右键菜单或左侧块菜单添加书签；没有选区时标记当前段落或内容块。书签按文档顺序排列，点击可跳到长段落中实际选中的位置，并用短暂的橘色底色提示落点。列表支持公式预览、五种颜色、右键删除和临时批量删除。书签保存在本机，不随文档分享，也不占用正文撤销记录。
- **🧭 大纲侧栏模式**：在「设置 → 编辑器 → 大纲与书签」选择浮动面板或右侧栏，两种模式都能拖动边缘调整宽度、切换大纲与书签，并记住上次使用的页面。
- **🖼️ 两宫格与可调整图集**：新增左右、上下两宫格，已有宫格可添加行列、删减图片；四宫格、六宫格和九宫格使用对应布局图标。左右方向键按行依次浏览图片，上下方向键在同列图片和图注之间移动。
- **📁 工作区拖放文件**：拖动树内文件可将其移入其他目录；从系统资源管理器拖入则复制到工作区。放在文件夹上进入该目录，放在已有文件上进入它的父目录；落点高亮并显示完整路径，同名文件不会被覆盖。
- **💾 顶部保存按钮**：标签栏左侧新增保存入口，未保存时以静态颜色提醒。保存中、已保存和保存失败状态与标签圆点、底部状态栏同步，`Ctrl+S` 仍可直接保存。

### Changed

- **↔️ 表格列宽拖动**：默认加宽一列时，后续列随之移动，表格总宽度一起改变。在「设置 → 编辑器 → 表格 → 列宽拖动」可改为调整相邻两列；最外侧边缘始终调整整表宽度。
- **🖨️ 宽表格打印**：默认根据内容收紧手动拉出的空白列宽、行高，并让长文本换行；需要保留尺寸时，可选“保留原列宽”。调整只作用于导出，不改变文档中的表格和文字。
- **🌙 墨夜文字与高亮**：降低正文、标题和代码文字的亮度，提高次级提示、保存状态的对比度。黄色、橙色等高亮上的文字按实际底色调整显示颜色，覆盖表格、图注、说明和工具栏配色预览；文档保存与导出的原始颜色保持不变。
- **🎨 赤陶代码配色**：保留灰色代码底，用紫、蓝、绿区分语法角色；代码、Mermaid 和 PlantUML 的语言标签改用独立配色。保存提示保持暖色，同时提高与背景的对比度。
- **📝 连续选区的说明标记**：跨越多个段落的一次说明只在选区末尾显示一个标记；点状下划线只用于单段内不超过 100 字的短选区。分散在不同位置、共用同一说明的锚点仍分别保留入口。

### Fixed

- **🔗 链接末尾输入**：光标位于链接末尾时继续输入，新增文字不再自动成为链接；在链接内部编辑仍保留链接。
- **🪟 悬停菜单关闭**：修复顶部正文菜单、预览及部分浮层离开后滞留、点击外部无法收起的问题，减少切换操作时的遮挡。
- **📍 内容块之间插入正文**：修复文档以表格开头、两个表格相邻时难以插入段落，以及鼠标移向靠左加号时按钮消失的问题。
- **🖱️ 表格边缘操作**：修复表格上侧、左侧难以选中行列，边缘选择条与尺寸拖动互相阻挡的问题；居中、居右内容的把手靠近内容，拖动反馈仍覆盖整行。
- **📂 拖放临时展开**：悬停时展开文件夹，进入更深子目录时保留祖先，移出后收回临时打开的分支。完成拖放后只保留目标路径及原本展开的目录，工作区根目录不变。
- **🎯 文件拖放入口**：工作区接收复制，正文接收图片插入，顶部标签区与主页接收打开文件；正文无法插入的文件不再兜底触发打开窗口，混合文件也不会被部分插入。全屏打开提示改为顶部小提示。
- **🔖 书签图标交互**：正文图标可点击定位书签列表，右键可移除；文字旁的书签与说明标记按字号保持在右上角，折叠章节中的标记同步隐藏。移除书签栏常驻的“已添加书签”提示。
- **📄 容器分页**：较短的提示块、折叠块、引用与代码块尽量整块留在一页；图片与图注、宫格内单张图片与图注一起排版。长文字容器和长表格仍可跨页，避免一律整块换页留下大段空白。
- **📐 表格适宽导出**：修复表格已经缩到正文宽度，却仍被误报超宽、无法直接导出的问题，包含嵌套表格。
