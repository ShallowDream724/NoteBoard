# NoteBoard 1.0.5

### Added

- **一边读 PDF，一边写笔记。** 打开本地 PDF 即可连续向下滚动。右键 PDF 标签，选择「在右侧打开」，就能把参考资料留在笔记旁边。按住 Ctrl 滚动鼠标滚轮可围绕指针缩放，也可以在底栏输入页码直达某页。
- **用几行文本写出表格、图片宫格和折叠块。** 在 Markdown 或 NB 正文单独输入 `::: table 2*3`，按 Enter 就有两行三列的表格。输入 `\blur{答案}` 可以把答案藏起来。`Ctrl+/` 切换源码和可视化时会保留编辑位置。主页的「AI 编写指南」可复制给 AI，让它按同一套语法生成笔记。
- **在键盘上找文件、命令和段落。** `Ctrl+Alt+P` 按文件名或路径搜索工作区，`Ctrl+Shift+P` 查找命令。在搜索框输入 `@`，可以跳到笔记标题、书签，或当前代码文件里的函数、类和配置键，并能返回跳转前的位置。
- **误拖文件也能撤销。** 重命名、移动、从外部拖入，以及在文件树中复制或剪切后粘贴，都支持 `Ctrl+Z` 和 `Ctrl+Y`。拖完点一下正文，撤销仍会把文件移回去。如果接着写了字，就先撤文字。每次撤销或重做文件操作，都会短暂显示文件名和结果。

### Changed

- **文件路径成了导航入口。** 点击底栏的文件夹可浏览下级目录，点击文件名可打开同目录的其他文件。收起侧栏也能用。图片的分辨率、宽高比和缩放比例，PDF 的页码和缩放，都收在同一行。窗口变窄时，文件名会保留 `.md`、`.ppt` 等扩展名。
- **代码从标签栏下方直接开始。** 行号常驻，点击底栏行列可跳转，点击语言可切换高亮。缩进菜单把「以后用空格还是 Tab」和「转换已有缩进」分开。编码菜单也分为重新打开和保存，遇到乱码时可以先换编码读取。读压成一行的 JavaScript 时，可点底栏的「长行阅读」按语句分行，复制或保存时仍保留原文。
- **HTML 预览可以看到本地配图。** 与页面同目录、子目录里的相对路径图片都能显示。`Ctrl+/` 可切到源码，改完再切回即可预览。遇到需要运行脚本的交互页面，预览会提示用浏览器打开。

### Fixed

- **编辑 Markdown 会保留原有写法。** 在源码模式改一行再保存，其余段落的空行、列表标记和转义写法会原样保留。含链接、公式和普通表格的笔记可以继续保存为 `.md`。
- **从网页复制的长文保留段落。** 修复了整页复制聊天记录时误报「嵌套过深」、复制单条回答时标题和表格挤进同一段的问题。长文贴好后可以从插入处往下读。如果等待时已滚到别处，会保留新的阅读位置。
- **磁盘文件变化后可以先看差异。** 其他程序改了正在编辑的文本时，点「查看差异」可对照本地编辑和磁盘版本，再决定覆盖或重新加载。修复了提示条按钮可见却无法点击的问题。
