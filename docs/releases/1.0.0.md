# NoteBoard 1.0.0

NoteBoard 1.0.0 带来原生笔记格式、图片组合、补充说明和更完整的表格编辑。你可以继续阅读与编辑 Markdown，在需要丰富排版时升级为 NB，再通过关联 Markdown、PDF、Word 或 LaTeX 与其他工具配合使用。

## 原生文档与 Markdown

- 新增 `.nb` 和 `.nbdoc` 原生文档，两种扩展名使用相同格式与专属图标，保留文字颜色、高亮、段落对齐、表格底色、合并关系及行高列宽。
- 新建笔记默认使用 `.nb`，也可选择 `.nbdoc`；支持 Windows 文件关联和右键“用 NoteBoard 打开”，保留已有的 `.nb` 默认程序。
- NB 支持可视化与源码编辑，文本文档也可由脚本或 AI 生成。个别内容格式有误时，保留原文并提供源码定位，便于修正。
- Markdown 继续支持阅读、可视化编辑和源码编辑。在 Markdown 中使用颜色、精确表格尺寸、图片组合等增强功能时，可确认转换为 NB 后继续操作。
- 转换默认保留并关联原 Markdown；也可选择删除原 Markdown、不再关联。已有同名 NB 时会提示，避免覆盖。
- 保存关联 NB 时，同时更新对应 Markdown；也可使用“更新关联 Markdown”主动同步。外部 Markdown 中能明确对应的局部文字改动可合回 NB 并保留原有样式，存在冲突或结构歧义时提示处理。
- 文件树将同目录内唯一关联的 Markdown 收在 NB 下方，展开即可打开、定位和重命名。
- 设置中的“纯 Markdown 使用偏好”可将新建默认改为 Markdown，并隐藏 NB 专属功能入口。
- 支持导出不含 NoteBoard 私有样式数据的 Markdown。文字、链接、图片引用、公式和图表源码保留；复杂表格使用标准 HTML 保存单元格中的多段落、列表和代码。

## 文字排版与内容整理

- 文字颜色和高亮合并到同一色板，可分别设置或叠加使用；彩色 A 显示记忆配色，单击即可再次应用。
- 色板箭头悬停展开，选择颜色后保持打开，便于连续调整。文字色和高亮色使用相同大小的色块，高亮第一格为透明。
- 正文与标题支持左对齐、居中、右对齐和分级缩进。
- 标题可折叠下方章节；拖动折叠标题时，下级标题和正文一起移动。
- 内容块旁增加类型图标和操作菜单，支持格式转换、复制、剪切、删除及下方插入。开始拖动时菜单自动收起。
- 有序列表、无序列表和任务列表支持逐项拖动、复制和删除。
- 右侧大纲采用更简洁的布局，收起后保留小型展开按钮，滚动条仅在悬停时显示。
- 新增可编辑的功能示例，包含公式、矩阵、表格、提示块、代码和 Mermaid。

## 图片与补充内容

- 图片菜单提供四宫格、六宫格、九宫格和图片轮播，支持预留空槽、图注与布局切换。
- 可直接粘贴图片，或拖入正文和图片格；拖入时显示插入位置，批量插图可一次撤销。
- 图片轮播提供翻页按钮和位置圆点；打印与 PDF 自动展开全部图片。
- 新增带标题的折叠块，以及悬停或聚焦即可揭示的模糊效果。
- 可为文字、图片和其他内容块添加补充说明；悬停阅读，也可固定、移动和调整说明窗口大小。说明正文支持多段文字、列表、图片与表格。
- 支持粘贴网页、Word 和 Excel 中可表达的文字样式、列表、链接、图片和表格；“仅粘贴文本”保留无格式内容。
- 导出 Markdown、PDF、Word 和 LaTeX 时，完整保留折叠正文与说明内容；图片组合转为静态网格，轮播包含全部图片。Markdown 将补充说明整理到文末，Word 和 LaTeX 使用脚注。

## 表格编辑

- 支持为格子、整行或整列设置底色；表头保留独立样式，文字颜色与高亮可叠加使用。
- 表格外沿的选择条可单击选中行列，也可按住拖动排序；内容、样式与合并关系随之移动。
- 首行和首列可设为表头，相关按钮按当前选区显示。
- 支持水平与垂直对齐、平均分配列宽和行高、合并与拆分单元格。
- 根据选区显示需要的操作：删除整行或整列、清空选中格子，或删除整个表格。
- 整行整列剪切后可插入到目标位置，在空白段落粘贴可建立新表格。剪切、粘贴、排序、合并和拆分均可撤销。
- 拖动尺寸时显示预览线，松开后应用；选格时不再闪现尺寸调整提示。
- 支持标准表与三线表。三线表隐藏底色并禁用填色，切回标准表可恢复原色。

## 公式、提示块与输入辅助

- 数学公式支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`，支持矩阵换行及行距参数。
- 行内与独立公式可直接编辑源码；错误 TeX 保留完整内容并显示错误。
- 行内和独立公式均可设置文字颜色与高亮；在 NoteBoard 源码模式中修改公式时保留配色。
- 支持 Note、Tip、Important、Warning、Caution 五种提示块，在引用块开头输入 `[!` 即可选择。
- 新行输入三个中文间隔号 `···` 后按 Enter，可快速创建代码块。
- 默认使用 Ctrl+1 至 Ctrl+6 设置标题，Ctrl+0 恢复正文，Ctrl+U 切换下划线。

## 自定义快捷键

- 设置中可搜索命令，录制按键或手动输入组合，并为同一命令设置多个组合。
- 支持禁用、恢复单项默认及全部恢复默认，修改后同步到其他窗口。
- 同一场景下的重复组合会提示冲突并阻止保存；Windows 下可检测被其他程序注册的全局快捷键。

## PDF 预览与文件导出

- PDF 排版预览可调整纸张、方向、页边距、字号、行距和页码。
- 超宽公式与表格可选择缩放、换行或分栏续表，并可逐个调整。
- 改善重复表头、跨页边界和超高行续页，导出检查会标出无法完整容纳的内容。
- 重新生成时保留旧预览，显示进度与已用时间。
- Word 和 LaTeX 导出保留支持的文字颜色、高亮、段落对齐、缩进、表格、图片、公式与说明脚注；导出前可查看目标格式的适配提示。
- HTML 可独立导出，并保留折叠、模糊揭示和轮播等阅读交互。导出后可直接打开文件、定位目录或复制路径。

## 修复与改进

- 修复拖动内容块、合并与拆分表格后撤销不完整的问题。
- 修复 Ctrl+Z 无响应、重复均分使表格持续变宽，以及关闭整表菜单后拖拽把手暂时消失的问题。
- 修复单击表格边界导致列宽跳变、文字突然换行，以及长表格选列后滚动位置跳动的问题。
- 修复文字工具栏在失去焦点或点击其他区域后仍残留的问题。
- 拖拽把手避让列表序号和标题折叠按钮；改善大型表格的选区显示、均分尺寸和章节折叠响应。
- 改善源码与可视化切换时的内容、样式、光标及滚动位置保留。
- 修复矩阵换行、提示块类型再次保存、异步插图及部分键盘输入问题。
- 改善另存为、重命名、暂存恢复、窗口间标签转移和外部文件修改检查。
- 文件与文件夹合并为同一个“浏览”入口，支持多选、路径导航和目录内筛选。
- 双击文件打开 NoteBoard 时，正文先打开，文件树随后定位到该文件的直接父目录；保留侧栏显隐状态，可通过路径栏继续向上浏览。
- 文件树刷新保留展开状态，保存与导出后自动更新目录；调整标签页、侧栏边界和设置页布局。
- 优化长文档、多公式笔记及大型表格的编辑响应，减少拖动过程中的重复计算。
- 增加新版本检查与非模态更新提醒，支持忽略指定版本。

## 使用说明

- 提供 Windows x64 安装包，使用系统 WebView2；已有用户可覆盖安装。
- Word、LaTeX 导出需要本机 Pandoc 3.0 或更新版本；LaTeX 文件的后续编译需要 TeX 环境。HTML 可独立导出，字体包为可选下载项。
- 原生文档中的本地图片仍是外部文件引用，搬到其他电脑时需一起迁移图片。
- Markdown 保存不新增 NoteBoard 私有样式注释。需要完整保留增强排版与交互内容时，使用 NB；关联或导出的 Markdown 按其可表达的形式保留内容。
- 目标 Markdown 软件对公式、图表和标准 HTML 表格的支持可能不同；PDF、Word 和 LaTeX 的具体排版也受字体与转换工具影响。

自由画板、多维表格、思维导图、Draw.io、图表脚本和文本对比继续保留。感谢 [CrazyFigure/NoteBoard](https://github.com/CrazyFigure/NoteBoard) 提供基础项目。
