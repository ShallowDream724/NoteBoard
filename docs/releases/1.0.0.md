# NoteBoard 1.0.0

NoteBoard 1.0.0 带来了更完整的 Markdown 排版、表格编辑、自定义快捷键和 PDF 导出体验。公式、数据、代码和图表可以放在同一份笔记中编辑，再按需要排版、保存和分享。

本次更新汇总了本分支自上游 0.3.5 以来的功能与修复。自由画板、思维导图、Draw.io、多维表格、图表脚本和文本对比继续保留。感谢 [CrazyFigure/NoteBoard](https://github.com/CrazyFigure/NoteBoard) 提供基础项目。

## feat · Markdown 排版

- 新增文字颜色，与高亮放在同一块色板中，可以分别设置或叠加使用。
- 彩色 A 同时显示上次使用的文字色和高亮色，点击一次即可复用整组配色。
- 右侧箭头支持悬停展开色板，展开时带旋转反馈；鼠标经过 A 本身时不会误开菜单。
- 文字默认色位于色板第一格，高亮第一格为透明；“重置”可以同时清除文字色和高亮。
- 色板支持键盘选择，悬停展开时保留正文光标和选区。
- 正文和标题支持左对齐、居中、右对齐及分级缩进。
- 顶部工具栏和文字选区工具栏提供一致的排版操作。
- 新增可编辑的功能示例，包含公式、矩阵、表格、提示块、代码和 Mermaid。首次空配置启动时展示，也可从主页重新打开。

## feat · 公式与输入辅助

- 数学公式支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`。
- 行内公式与独立公式均可直接进入源码编辑，再回到排版显示。
- 支持矩阵换行及行距参数。错误的 TeX 会保留完整源码并显示错误，方便继续修改。
- 支持 Note、Tip、Important、Warning、Caution 五种提示块，类型可以随时修改。
- 在引用块开头输入 `[!` 即可选择提示块类型。方向键选择，Enter 或 Tab 确认，Esc 退出；确认后直接进入正文。
- 在新行单独输入三个中文间隔号 `···` 后按 Enter，可直接创建代码块。普通句子中的中点和省略号不触发转换。
- 默认使用 Ctrl+1 至 Ctrl+6 设置标题，Ctrl+0 恢复普通段落，Ctrl+U 切换下划线。

## feat · 表格编辑

- 支持为单个格子、整行或整列设置底色。
- 表头保留独立样式；填色后，单元格文字仍可单独改颜色或高亮。
- 表格外沿增加行、列和整表选择把手，快速选中需要操作的范围。
- 首行、首列选区可设为表头。取消其中一项时，另一项的表头交点会保留。
- 新增单元格水平和垂直对齐，以及均分列宽。
- 支持合并单元格；选中合并过的格子时才启用拆分操作。
- 列宽、行高可以拖动调整，并随文档保存。
- 文字选区显示文字工具栏，格子选区显示表格工具栏，减少工具栏相互遮挡。
- 支持标准表与三线表。三线表隐藏底色并禁用填色，切回标准表后可恢复原色。

## feat · 自定义快捷键

- 设置页可搜索文件操作、Markdown 格式、源码与代码编辑、查找替换等命令。
- 支持直接录制按键或手动输入组合，每个命令可以设置多个组合。
- 支持禁用单个命令的快捷键、恢复单项默认值，以及全部恢复默认。
- 同一使用场景下的重复组合会提示冲突并阻止保存。
- Windows 下可检测被其他程序注册的全局快捷键，便于避开截图软件等程序的常用组合。
- 修改后立即生效，并同步到其他 NoteBoard 窗口。

## feat · PDF 排版与导出

- 新增原生 PDF 排版预览，可调整纸张、方向、页边距、字号、行距和页码。
- 超宽公式与表格可以分别选择排版方式，包括适宽缩放、表格换行和分栏续表。
- 每个对象可以单独调整，其他公式和表格保留原来的设置。
- 预览显示生成阶段和已用时间；重新生成时保留旧预览，便于对照。
- 增加导出检查，对无法完整容纳的内容标出位置和原因。
- 改善表格列宽分配、公式换行、重复表头及跨页边界；超高行续页带有连接标记。
- 导出成功后显示反馈、刷新对应目录，并打开和定位生成文件。
- 导出结果页提供“用系统默认程序打开”“在文件管理器中定位”和“复制完整路径”。
- Word、HTML、LaTeX 可通过本机 Pandoc 导出；设置页显示检测到的路径与版本，也可手动指定。
- 转换警告与导出失败分别提示，已经保存的文件不会因后续展示异常被误报为保存失败。

## fix · 编辑与保存

- 修复矩阵中的换行和行距参数被误拆成 Markdown 或另一段公式的问题。
- 修复源码与可视化切换时的语法保留、光标映射和滚动定位问题。
- 修复提示块再次保存后类型或内容丢失的问题。
- 修复选中未高亮文字后，工具仍显示已高亮的问题。
- 修复 Ctrl+U 被浏览器默认行为抢先拦截的问题。
- 修复单击表格边界就改变列宽、导致短文字突然换行的问题。
- 修复拖动行高时列布局跟着变化，以及部分行边界难以拖动的问题。
- 修复长表选择整列后视图跳到表尾的问题。
- 文字颜色、高亮、对齐、缩进与表格样式可随 Markdown 文件保存。源码模式应用配色时保留正文的原有拼写、空格和标记。
- 修复异步插入图片时切换文档，图片落入错误文件的问题。
- 改善重命名、另存为与暂存恢复，避免旧内容覆盖新版本。
- 加强外部修改检查，包括文件大小不变的内容替换，减少自动保存覆盖外部改动的风险。

## fix · 文件与资源管理器

- 刷新目录保留已展开的文件夹和当前定位。
- 导出和保存图片后自动更新对应目录，无须再手动刷新。
- 定位文件时保留当前根目录下其他已展开分支。
- Ctrl+O 支持输入文件或文件夹路径，自动判断并打开；Ctrl+Shift+O 可直接浏览文件夹。
- 修复 Windows 路径粘贴和文件树单击打开的部分异常。
- 文件树选中背景延伸到右侧边缘，隐藏滚动条时不再留空槽。
- 移除文件树滚动条上下箭头，修复鼠标离开后滑块偶尔常驻的问题。

## fix · 窗口、标签与设置

- 调整标题栏空间分配，新建按钮跟随最后一个标签，常用窗口操作保持可达。
- 改善活动标签的圆弧、长标题渐隐和关闭按钮反馈。
- 修复标签滚动边缘只剩一小片时出现突兀残片的问题。
- 统一左右侧栏分隔条的视觉宽度与拖动体验。
- 修复最小化后退出、再次启动时窗口缩成细条的问题，并保留正常尺寸和最大化状态。
- 设置页适配更大的 UI 字号和窄窗口，长字体名不再撑出卡片。
- “排版与字体”增加页面级“全部恢复默认”。
- 调整设置页说明文字的位置，明确各项字体和缩放设置的作用范围。
- 改善晨光、琥珀、墨夜主题预览。
- 修复关闭设置后再次闪现“设置”提示，以及部分按钮焦点残留、提示溢出的问题。

## feat · 更新提醒

- 从本分支的 GitHub Release 检查新版本。
- 启动后自动检查，后续定时检查；更新以非模态气泡提醒，不打断编辑。
- 可以暂时关闭提醒，也可以忽略某个版本。忽略旧版本后，后续新版本仍会提醒。
- “关于”页支持手动检查和查看版本详情，并区分网络失败、暂无正式版本和已是最新版。

## perf · 长文档与响应速度

- 缩短 Markdown 首次打开的等待，减少初始化时重复加载正文。
- 改善大量公式、矩阵和代码块的加载与滚动体验。
- 降低长文档输入、搜索、大纲定位和历史撤销时的重复处理开销。
- PDF 预览按可见页面加载，减少多页文档同时占用的画布内存。
- 改善大型表格拖动的响应，减少拖动过程中的整表更新。
- 文件树刷新只检查已打开的目录分支，不读取大型附件内容。
- 改善反复切换和关闭文档后的内存释放。

## 兼容说明

- 本次提供 Windows x64 安装包，使用系统 WebView2。
- Word、HTML、LaTeX 导出需要本机 Pandoc；字体包为可选下载项。
- 扩展样式保存在 Markdown 的 HTML 注释中。支持 HTML 的预览器通常隐藏注释并正常显示正文；禁用 HTML 的预览器可能显示注释文字。其他 Markdown 软件不会自动还原 NoteBoard 的颜色、对齐、列宽与合并结构。
- PDF 和 HTML 保留扩展排版；Word、LaTeX 中无法保留的样式会通过转换提示说明。
- 大型表格、长公式和复杂图表仍可能增加排版时间，PDF 正文修改后需要重新生成预览。

已有用户可以覆盖安装，笔记仍保存在原来的本地目录中。
