# NoteBoard 1.0.0

这是这个分支的第一个正式版本。从上游 0.3.5 开始，几轮改动主要围绕一件事：让一份带公式、表格、图片和代码的长笔记，从打开、编辑、保存到导出，都能顺畅地用起来。

感谢 [CrazyFigure/NoteBoard](https://github.com/CrazyFigure/NoteBoard) 提供的基础。原有的画板、思维导图、Draw.io、多维表格、图表脚本和文本对比继续保留。下面记录的是这个分支在此基础上的新增与修整。

## feat · Markdown 与学术写作

- 数学输入支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`。行内公式和独立公式都能直接进入源码编辑，再回到排版后的显示。
- 公式编辑、预览与文档保存使用同一套语法边界。矩阵里的换行和行距参数不会被误拆成另一段 Markdown。
- 错误的 TeX 会保留在完整公式节点里，显示错误并允许继续修改。不会为了“显示出来”丢掉原始内容。
- GitHub 风格提示块支持 Note、Tip、Important、Warning、Caution。标题、图标和正文分别排版，类型可以修改，保存后再次打开仍保留。
- 在引用块开头输入 `[!`，即可选择提示块类型。上下方向键移动，Enter 或 Tab 确认，Esc 退出；确认后直接进入正文，不必再点一次鼠标。
- 中文输入时，新行单独输入三个间隔号 `···` 再按 Enter，可以创建代码块。普通句子里的中点、ASCII 省略号、已有代码中的中点都不会触发。
- 高亮颜色记忆独立于文档。选中未高亮的文字时，点击荧光笔应用上次颜色；选中已高亮的文字时，点击即可取消。
- 荧光笔沿用原图形，只给笔头上色。鼠标短暂停留展开色板，点击仍直接应用；图标和箭头合并为一个紧凑控件，顶部工具栏和选区工具栏保持一致。
- 色板支持键盘选择；悬停展开不会夺走正文焦点，也不会同时出现一层“应用高亮”的提示文字。
- 标题快捷键改为 Ctrl+1 至 Ctrl+6，Ctrl+0 恢复普通段落；Ctrl+U 切换下划线。可视化和源码模式都支持，数字键按物理按键识别，减少输入语言变化造成的失效。
- 增加可编辑的功能示例，包含公式、矩阵、表格、五种提示块、代码、Mermaid 和常用操作。首次空配置启动会展示，主页也可以随时重新打开；已有文件和恢复的标签不会被替换。

## feat · PDF 与其他导出

- 增加原生 PDF 排版预览。纸张、方向、页边距、字号、行距和页码可以在同一窗口调整。
- 超宽公式和表格支持单独选择排版策略，包括自动排版、缩到正文宽度、表格换行和分栏续表。修改一个对象时，其他对象的设置保持不变。
- 预览使用真正生成的 PDF，并只绘制当前可见页面及邻近页面，避免长文档一次铺开所有画布。
- 生成预览时显示实际处理阶段和已用时间；更新现有预览时保留旧页面，并显示正在更新。等待期间能看见任务还在推进。
- 增加导出诊断。无法完整容纳的内容会标出位置和原因，可以定位后调整，也可以明确选择按当前预览继续导出。
- 超宽内容列表可以搜索，条目高度和滚动区域保持独立，解决长文档中列表被挤成细条的问题。
- 改善表格中的公式换行、列宽分配、重复表头和跨页边界。超高行续页时保留明确的连接关系。
- 保存成功后显示成功反馈，更新左侧目录，并打开、定位生成文件。PDF 的结果页显示“导出成功”，提供默认程序打开、文件管理器定位和复制路径，不再把刚生成的文件当成一次格式错误。
- Word、HTML、LaTeX 继续通过本机 Pandoc 转换。自动找到的 Pandoc 路径与版本会显示在设置中，也可以手动指定。
- 转换警告和导出失败分别处理。文件已经保存时，即使后续展示遇到问题，也不会把它误报为保存失败。

## fix · 文档保存与内容往返

- 修复源码与可视化切换时的 Markdown 语法保留和位置映射问题，减少滚动位置跳动及定位偏差。
- 表格列宽和文档级表格样式可以持久保存。样式写入 Markdown 的 HTML 注释中，正文仍可由其他 Markdown 软件读取。
- 修复提示块在解析、编辑和重新保存时类型或内容丢失的问题。
- 图片插入与异步任务绑定到原来的文档会话，避免操作尚未完成时切换文件，图片却落入另一篇笔记。
- 保存图片资源后主动更新对应目录，不再依赖系统文件监听恰好及时到达。
- 图片清理延后到正常保存之后，并提供可逆处理路径，避免尚未保存的编辑导致资源过早删除。
- 重命名和另存为统一迁移文档身份、历史、暂存、基线和视图状态；改名不再顺带强制保存正文。
- 暂存写入按版本串行处理。关闭文档前校验待保存版本，旧异步结果不能覆盖后来重新打开的同名文件。
- 外部文件修改继续与文档基线核对，包括文件大小没有变化的替换。发现冲突时阻止旧自动保存覆盖外部修改。
- 修复高亮工具的选区状态残留。选中另一段未高亮文字时，工具不会继续假装它已经高亮。
- 修复全局浏览器快捷键拦截抢先消耗 Ctrl+U 的问题，让编辑器先处理格式操作。

## fix · 资源管理器与路径

- 刷新目录保留已展开的文件夹和当前定位，不再把“刷新”当成“重新打开根目录”。
- 手动刷新只读取根目录和已展开目录，不递归扫描未打开的分支，也不读取附件内容。目录里有大模型文件、视频或其他大文件，不会因为刷新就把它们装进内存。
- 连续写入和文件监听事件共用目录更新队列。正在读取时又发生变化，会在完成后再核对一次，避免遗漏后续文件。
- 标签跟随、定位按钮、文件打开和导出结果共用同一套定位动作。目标仍在当前根目录内时，保留其他展开分支；只有跨目录时才切换根。
- 目录切换带有代次校验，晚到的读取结果不能把用户刚打开的新目录换回旧目录。
- Ctrl+O 同时接受文件路径和文件夹路径，自动判断后打开；浏览文件、浏览文件夹放在同一个入口里。Ctrl+Shift+O 仍可直接选择文件夹。
- 修复 Windows 路径粘贴与文件树单击打开的行为，减少不必要的路径重复扫描。
- 文件树选中背景延伸到右侧边缘，滚动条覆盖显示，不再留一条永久空槽。
- 移除文件树滚动条上下的小三角。鼠标离开后隐藏滑块，键盘导航或拖动时仍保持可见，普通点击遗留的焦点不会让滑块常驻。

## feat / fix · 窗口、标签与设置

- 重新分配标题栏空间：左侧保留侧栏与主页，新建按钮跟随最后一个标签，右侧保留导出、设置、侧栏和窗口控制。保存继续使用快捷键，快捷换主题和手动检查更新不再挤占标签区。
- 标签默认保持轻量，悬停时才显出分块。活动标签采用连续的顶部圆角与底部反向圆弧，融入工作区；关闭按钮和新建按钮使用圆形反馈。
- 长标题末尾渐隐，关闭按钮保持可见。滚动边缘只剩一小片的标签会收口，避免在新建按钮前露出突兀的残片。
- 窗口内容区左右上角使用统一圆角；左右侧栏共用同一种分隔条，视觉宽度与拖拽命中范围分别处理。
- 修复最小化后退出、重启窗口缩成一条的问题。Windows 使用正常还原矩形恢复尺寸和位置，并保留最大化状态。
- 设置页随可用宽度和 UI 字号重新分列。长字体名、较大字号和窄窗口下，控件可以正常收缩与换行，关闭按钮保持可达。
- 字体选择列表首次打开才加载，多处选择器共享结果；大量系统字体使用虚拟列表显示，避免一次挂载全部选项。
- “排版与字体”增加页面级“全部恢复默认”，一次恢复界面、正文、代码和文件树排版。默认值直接来自新安装使用的原生设置模型。
- 设置中的说明文字放回对应标题下方，明确缩放快捷键的作用区域，减少挤在标题右侧的碎片文案。
- 外观主题卡片增加配色渐变、透明叠层和文档小样，能直接看见晨光、琥珀、墨夜各自的氛围。
- 统一按钮焦点和 Tooltip 行为，修复鼠标关闭设置后又冒出“设置”提示、顶部提示向上溢出等问题。

## feat · 更新提醒

- 更新源固定为本分支的 GitHub Release，不会把上游安装包覆盖到当前分支。
- 启动后自动检查，正常情况下每半小时检查一次；设置按钮附近显示非模态更新气泡，编辑不会被强制打断。
- 暂时关闭某个版本的提醒后，本次运行不再重复提示，下次完整启动才再次提醒。选择“此版本不再提醒”则持续忽略该版本，后续新版本仍可提醒。
- “关于”页保留手动检查和版本详情。网络失败、没有正式版本、已经是最新版分别显示，不把连不上 GitHub 说成没有更新。
- 请求有超时、退避和限流处理。离线暂停，恢复网络后重试；自动检查失败保持安静，不周期性弹出错误框。

## perf · 长文档和内存

- Markdown 初次打开直接用正文初始化编辑器，并提前准备常用编辑器模块，减少空编辑器创建后再次替换全文的工作。
- 拆开文档语法、浏览器编辑器与导出转换的依赖，导出 Worker 不再因为编辑器的浏览器事件初始化而失败。
- 隔离 Markdown 词法分析器，减少重复规则注册和全文反复前探；源码位置索引可以复用。
- 公式和代码高亮采用有界后台队列，支持取消、过期结果检查、缓存上限和空闲释放。
- 大矩阵预览按邻近视口窗口化，减少首次挂载与测量规模；公式占位保留稳定尺寸，降低滚动时的跳动。
- 大纲和导出布局读取尽量限制在受影响的块，避免一次局部变化触发整篇文档的重复扫描。
- 正则搜索移到可取消 Worker，并复用搜索索引。空查询不再触发无意义的滚动定位。
- 历史快照复用已有末端结果，减少回放和重复序列化；未变化的文档不重复捕获暂存正文。
- 收拢编辑器会话归属与卸载清理，处理回收后仍被回调闭包引用的编辑器实例，减少多次切换文档后的内存累积。
- 表格拖动统一到受限的手势调度，合并布局读取与提交，避免每一个指针事件都同步更新整张表。

## refactor · 后续维护

- 文档模型、编辑器能力、会话生命周期、保存队列和视图状态明确分工，避免业务入口各自保存一份文档状态。
- 提示块类型、输入补全和展示共享元数据；高亮偏好与正文格式分离；不同工具栏共用同一个高亮控件。
- 文件树刷新与定位集中到独立动作层，导出引擎不直接操作目录树或标签页。
- 设置通过字段补丁与 revision 同步，旧响应不会覆盖其他窗口的新设置；失败只撤回对应的本地修改。
- 补充输入边界、撤销、快捷键、目录竞态、设置并发、导出交接等回归检查，并同步相应架构文档。
- 正式发布说明随源码保存，构建读取对应版本的说明，避免发布时只剩一串没有上下文的提交标题。

## 使用前可以了解的几件事

- 当前发布包面向 Windows x64，使用系统 WebView2；其他平台没有随本次发布验证。
- Word、HTML、LaTeX 转换需要本机 Pandoc。字体包是可选下载项，仍使用原项目提供并带校验的资源。
- PDF 正文变化仍需重新生成文档；长公式、多页表格或复杂图表会增加等待时间。预览窗口化减少的是画布数量，不等于所有排版都能瞬间完成。
- 可编辑表格仍使用原生表格布局。特别大的表格和复杂合并单元格仍可能产生布局峰值，自动排版也不会任意改写 TeX 的数学含义。
- NoteBoard 的表格样式注释可由其他 Markdown 软件忽略；这保证正文可读，但不代表每款软件都能还原相同列宽。Pandoc 无法保留的样式会通过转换提示说明。

安装包见本页附件。已有用户可以覆盖安装，笔记仍保存在原来的本地目录中。
