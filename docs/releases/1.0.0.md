# NoteBoard 1.0.0 · 预发布

这一版主要完善了文档编辑与分享：用 NB 保留完整排版，用 Markdown 与其他编辑器交换内容，再把笔记、表格和图示导出成 PDF、Word 或 LaTeX。

这是 1.0.0 的首个候选版本，标签为 `v1.0.0-rc.1`，应用内版本号为 `1.0.0`。欢迎试用，也欢迎带着复现步骤来反馈问题。

## 下载与安装

- **Windows 10 / 11 x64**：下载本页 Assets 中的 **`NoteBoard_1.0.0_x64-setup.exe`**，运行即可安装。已有版本可覆盖更新。
- 安装需要 WebView2；缺少时，安装程序会联网下载。
- `SHA256SUMS.txt` 用于校验下载文件。GitHub 自动生成的 Source code 是源码，不是可运行程序。
- 安装后点击主页的 **浏览功能示例**，可以直接试着编辑文字、图片、表格和公式。

## 文档与 Markdown

- **完整保留排版**：`.nb` / `.nbdoc` 保存文字颜色、高亮、段落对齐、表格样式、图片组合和补充说明。两种扩展名使用同一格式。
- **在原文件旁转换**：MD 转 NB 后，新文件生成在同一目录。保留关联时，文件树以 NB 为主体，展开可见原 MD，文件位置清楚可查。
- **继续与 Markdown 配合**：保存 NB 同时更新关联 MD；普通文字回改可以合回 NB，保留原有颜色和高亮。同段冲突会提示处理，不自动覆盖。
- **两种编辑方式**：NB 与 MD 都能切换可视化和源码模式，按当前任务选择。

## 写作与内容整理

- 选中文字即可使用辅助工具栏；段落左侧菜单支持整块编辑、移动、复制和删除。
- 标题可折叠，拖动标题时带上整节内容；列表支持逐项调整顺序。
- 提示块可自选图标、标题、文字色、边框和背景。输入 `[!` 或 `【！` 调出类型补全，Note、Tip、Important、Warning、Caution 仍可直接使用。
- 折叠块收起长说明；文字、图片、表格和代码块可添加补充说明，说明跟随内容移动。

## 表格与图片

- 为格子、整行或整列设置底色与对齐，调整行高列宽，合并、拆分或均分单元格。
- 表格整体位置与格内文字对齐分开设置；支持表头、标准表、三线表和表注。
- 单张图片支持图注；宫格与轮播支持组合尺寸，宫格可调整左、中、右位置，轮播固定居中。
- 点击图片可放大查看。图片组合导出为静态网格，轮播在打印时包含全部图片。

## 公式、图示与画板

- 支持行内公式、独立公式和矩阵；错误输入保留源码，方便继续修改。
- Mermaid 可放大查看，容器随图示调整；查看缩放不影响打印比例。
- 可编辑 Mermaid、PlantUML 和 Infographic 脚本，并导出 SVG / PNG。
- 自由画板、思维导图、Draw.io 和多维表格继续提供，适合草图、提纲和项目资料整理。

## 打印与导出

- PDF 预览可调整纸张、方向、页边距、字号、行距与页码；超宽表格和公式可单独处理。
- PDF 使用配置的文档字体，支持本机字体与可选字体包。保存后在新标签页打开，不跳走当前文件树目录。
- Markdown 导出移除 NB 专属样式，保留文字、链接、图片引用、公式与图表源码；折叠正文展开，说明编号附到文末。
- HTML 可独立打开，保留折叠、轮播和模糊揭示等阅读交互。
- Word / LaTeX 导出保留支持的排版与说明脚注，需要本机安装 **Pandoc 3.0+**；编译 LaTeX 另需 TeX 环境。PDF、HTML 和 Markdown 导出不需要 Pandoc。

## 桌面体验

- 晨光、琥珀、墨夜三种主题；界面、正文、代码和文件树可分别设置字体。
- 快捷键可以修改、禁用或恢复默认；侧栏与大纲可收起，窄窗口下留出更多正文空间。
- 同一窗口支持笔记、代码、图片与 PDF 标签页，也可拆成多个窗口。

## 本次修复

- 关联 MD 在应用内或外部修改后，NB 能收到更新；连续保存不会再因为旧源码残留而误报“未保存”。
- MD 转 NB 后，文件树会刷新并定位新文件，展开关联 MD。
- 改善段落说明的位置、保存与删除操作，以及说明随内容移动的行为。
- 修复分割线后退格退化成 Markdown 标记、公式输入时滚动位置被拉动等问题。
- 改善表格行列选择、尺寸调整、打印布局，以及块菜单、标题标记和拖拽反馈。

## 试用前了解这几件事

- **复杂结构回传仍有限制**：NB 的折叠块、补充说明等降级到 MD 后会改变块结构。此时再改 MD，即使是普通段落，也可能进入结构冲突保护，不能自动合回 NB。两边内容会保留，等待处理。
- **图片仍是外部文件**：搬动或分享 NB / MD 源文档时，请一起带上图片目录。
- **部分图形工具需要联网**：PlantUML 当前通过在线服务渲染，图表源码会提交给该服务；Draw.io 从 diagrams.net 加载。
- **本次只发布 Windows x64**。暂无 macOS、Linux、ARM64 安装包，也没有内置云同步或实时协作。
- 预发布版本从 Releases 手动下载；应用内更新检查当前面向正式版本。
