# NoteBoard 1.0.3

这次更新集中改善列表编辑、网页粘贴和本地文件浏览，同时补齐上手引导，以及代码、配置和数据文件的查看工具。

### 新增

- 🔢 **列表编号样式。** 有序列表支持数字、圈号、方框、中文、括号数字、大小写罗马数字和大小写字母。可以接续上方列表，也可以从指定数字重新编号；光标所在行、左侧块菜单和明确选区都能直接操作。
- 🗂️ **CSV / TSV 表格查看。** 在源码和只读表格视图之间切换，按 A1 地址定位单元格，查看、复制完整字段。支持带引号、跨行字段和不齐列数的数据；大表按可见区域加载单元格，超出预览上限时提示查看源码，不截断数据。
- 🧑‍💻 **更多代码与配置工具。** 扩展常用文本文件识别与语言高亮，支持手动切换高亮语言。JSON、YAML 和 XML 提供对应的格式化或校验；JSON 格式化保留大整数、重复键和原始字面量。
- 🖼️ **SVG 源码查看。** SVG 保留图片查看功能，并可切换到只读 XML 源码。专业二进制格式提供使用默认程序打开、在文件管理器中定位和复制路径的入口。
- 🧭 **可操作的新手引导。** 在可编辑的功能示例中尝试说明、选中文字、添加批注和插入内容。引导根据实际操作自动推进，提示跟随当前目标，随时可以跳过或退出。
- 💡 **图文悬停说明。** 常见文字格式、列表、代码、表格、图片宫格和轮播等操作增加效果示意与快捷键提示。选中文字后的浮动工具栏继续保持简洁，图文说明集中在顶部与左侧菜单中。

### 改进

- 📁 **统一文件类型图标。** 文件树、标签页、收藏和文件选择入口使用同一套离线图标，常见代码、配置、图片与文档格式更容易区分。
- 🌳 **更清楚的目录层级。** 文件树使用线条式展开符号，默认突出当前活动层级，悬停时显示完整层级线；颜色随主题协调变化。
- ✍️ **清除样式与还原正文分开操作。** `Ctrl+\` 清除文字样式；`Ctrl+0` 将标题、所选列表项等还原为正文。部分文字选区保留段落共有排版，完整文字段落可以清除对齐、缩进和底色；图片、表格、公式和轮播的整体布局保留。
- 📖 **全文阅读视图。** 表格可以自然展开或分别在块内滚动；公式可以自然展开、自动换行或在块内滚动。设置作用于当前文档及新增内容，不修改公式源码。
- ↔️ **对称的正文留白。** 正文阅读区域按窗口宽度调整两侧空间，居中图片与内容块在视觉上保持居中。右侧浮动大纲简化外框与顶部操作区，不挤压正文。
- 🪶 **按需加载与资源释放。** 文件查看器、图文帮助和画板按需加载；大数据预览使用虚拟化，后台解析可以取消，关闭视图后释放对应资源。

### 修复

- 🖱️ **列表按行选择与拖拽。** 修复操作某个列表项时误选整个列表的问题。支持批量移动所选内容，也可以把正文、待办或公式等内容放到列表之间；有序列表的接续关系随操作更新。
- 🔗 **Markdown 网页粘贴。** 网页文字、链接、加粗、列表等可用 Markdown 表达的内容优先保留在 MD 中，避免仅因网页配色或对齐触发 NB 转换。修复确认转换后粘贴内容未正确插入的问题；纯文本粘贴仍按字面插入。
- 🏷️ **网页小图标不再占满正文。** 混合网页内容中的网站 favicon 和明确的装饰图不再被放大成正文图片块。正常配图、单独复制的图片和明确的 Markdown 图片继续保留；`[image](地址)` 仍是普通链接。
- 🎯 **选中文字不被左侧菜单打断。** 修复鼠标经过把手时覆盖原文字选区、批量操作只作用于某一行，以及撤销后把手不再出现的问题。拖拽期间收起会遮挡落点的辅助栏。
- 🔢 **编号显示与菜单输入。** 修复列表转换后的行距、圈号与首行文字对齐、编号示例排列和长编号挤掉拖拽栏的问题。长编号完整显示并右对齐；输入起点时菜单保持打开，超限值明确提示，撤销能恢复整次输入。
- 🧩 **菜单展开与遮挡。** 修复指针进入子菜单后菜单提前收起、帮助预览遮住相邻操作，以及顶部菜单被大纲覆盖的问题。多选菜单使用明确的“改为有序列表”或“取消有序列表”文案。
- 📍 **切换标签不再重设工作区。** 保留用户打开的资源管理器根目录，定位工作区内的文件时展开必要的祖先目录。工作区外的文件通过手动定位进入对应目录，并保留各标签的打开来源。
- 🔄 **会话恢复中的图片加载。** 修复恢复标签后图片一直停在“正在加载”、必须关闭重开才能显示的问题。
- 🈶 **中文格式标记。** 修复中文标点紧贴加粗、斜体、删除线或组合格式时，源码解析与可视编辑结果不一致的问题。
- 🧾 **长内容阅读与画板加载。** 修复长表格阅读时部分内容不显示、宽内容滚动区域相互干扰，以及画板初始化与重复加载的问题。

### 安装

- **Windows 10 / 11 x64：** 下载 [NoteBoard_1.0.3_x64-setup.exe](https://github.com/ShallowDream724/NoteBoard/releases/download/v1.0.3/NoteBoard_1.0.3_x64-setup.exe)，已有版本可以覆盖安装，也可在应用的“关于”中检查更新。
- 同页提供 `SHA256SUMS.txt` 用于校验。GitHub 的 Source code 是源码归档。
- 编号起始值支持 **1–999,999,999**。CSV / TSV 表格视图与 SVG 源码视图为只读，CSV / TSV 可切回源码编辑。
- SVG 源码视图支持读取 **2 MiB** 以内的文件；更大的文件可使用默认程序打开。
