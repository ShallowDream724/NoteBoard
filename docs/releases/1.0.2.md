# NoteBoard 1.0.2

### 新增

- 📄 **NB 原生文档。** `.nb` 保存文字颜色、高亮、段落布局、表格样式、图片组合与补充说明，也保留可视化和源码两种编辑方式。文件直接放在本地目录中，无需导入专用资料库。
- 🔗 **与 Markdown 关联保存。** MD 转换为 NB 后，两份文件保存在同一目录，文件树中可从 NB 展开原 MD。保存 NB 时同步更新关联 MD；能逐块对应的 MD 文字修改可以合回 NB，保留原有颜色和高亮。同段冲突会留下两边内容，等待处理。
- 🖼️ **统一图片编辑器。** 文档图片、宫格、轮播和独立图片共用编辑入口。裁剪、旋转、镜像之外，还可使用铅笔、荧光笔、箭头、折线、形状、文字、马赛克、聚光灯、放大镜和自动序号。文字、形状等标注可以拖动、缩放和重新编辑，修改支持撤销与重做。
- 🎨 **图片标注样式。** 按工具记住颜色、尺寸、粗细等常用参数；文字直接在图片上输入，箭头和折线可逐点调整。矩形与笔刷马赛克分别用于区域遮挡和涂抹，擦除前能看到作用范围。导出可选择 PNG、JPEG、WebP、尺寸与有损质量。
- 🧩 **图集与补充说明。** 图片可组成四宫格、六宫格、九宫格或轮播，并添加图注。长内容可以放进折叠块，文字、图片、表格和代码块可带上可点开的说明；说明随所属内容一起移动。
- 📊 **文档表格排版。** 支持单元格、整行和整列的底色与对齐，合并、拆分、均分，以及拖动调整行高列宽。表格整体位置与格内文字对齐分别设置，可选标准表、三线表和表头，并在下方添加表注。
- 🖨️ **PDF 排版预览。** 导出前调整纸张、方向、页边距、字号、行距和页码，检查超宽表格与公式的处理方式。打印使用配置的文档字体；轮播展开全部图片，折叠块展开正文。生成的 PDF 在新标签页打开。
- 🌐 **独立 HTML 阅读页。** 导出的网页保留折叠、轮播、模糊揭示、公式与图表，补充说明可在原位置点开查看。代码块保留语法高亮与语言栏，支持复制、折叠和换行。本地图片与公式字体内嵌到文件中，接收者用浏览器即可阅读；应用内也可预览、定位文件或另存副本。
- 📝 **Word、LaTeX 与 Markdown 导出。** Word / LaTeX 保留支持的表格、图片、公式和说明脚注，便于继续排版。Markdown 导出保留正文及可表达的结构，展开折叠正文，把说明整理到文末。
- ➕ **按位置插入内容。** 空段落左侧的 **+** 和 `/` 菜单可以插入表格、图片、公式、提示块及折叠块。输入名称即可搜索，用方向键选择、Enter 确认；已有内容通过左侧把手拖动，拖动标题可带上整节内容。

### 改进

- ∑ **公式输入与修改。** 支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 和矩阵，中文输入时也可使用成对的人民币符号，常见金额保留为文字。新建空公式后直接进入编辑；行内源码随输入自然折行，预览紧贴源码下方，长公式可在预览内滚动。公式写错时保留源码，全角括号误用会给出对应提示。
- 💻 **更多代码与配置语言。** JavaScript、TypeScript、Python、Java、C、C++、C#、Go、Rust、SQL、PowerShell 等常用语言按文件后缀或文件名识别并高亮。代码文件可查找、跳转行和折叠；文档代码块可搜索并切换语言。
- ⚙️ **设置与快捷键。** 界面、正文、代码和文件树可分别选择字体；字号、行距、正文宽度和选区工具栏位置可调整。快捷键支持搜索、修改、禁用和恢复默认，设置面板适应窄窗口与较大字号。
- 🌓 **三种主题。** 晨光、琥珀、墨夜统一覆盖正文、菜单、公式源码和浮层，也可跟随系统。字体选择提供即时预览，可使用本机字体或下载可选字体包。
- ↩️ **连续撤销与重做。** 正文、公式源码、图注、表注和折叠块内的编辑使用连贯的历史。撤销内容修改时保留正在使用的输入位置，撤销新建公式或图表时回到正文继续写作。
- 📐 **沿用导出设置。** PDF 的纸张、方向、边距、字号、行距和页码配置会保留到下次使用。导出采用打开导出窗口时的最新内容，包含尚未保存的修改，无需先保存原文档。
- 🔔 **更新提醒与详情。** 新版本提醒更紧凑，更新说明按标题、列表和链接排版；长说明可独立滚动，“下载并安装”按钮始终可见。
- ⚡ **长文档与大图。** 代码滚入视野即可显示高亮与行号；长代码按可见范围绘制。正文大图使用适合显示尺寸的预览，复制、查看和编辑仍使用原图。公式、嵌入图表及画板减少重复渲染和处理。

### 修复

- 🔗 **关联文档更新。** 修复 MD 在应用内或外部修改后未同步到 NB、连续保存后仍误报未保存，以及转换后文件树未及时定位新文件的问题。
- ⌨️ **公式焦点与输入法。** 修复公式编辑中焦点丢失、输入法确认与快捷键冲突，以及高矩阵在连续输入时短暂收缩、拉动滚动位置的问题。
- ↩️ **代码输入与命令历史。** 修复代码块中文组词被高亮刷新打断、命令插入后重做异常，以及撤销后命令菜单残留的问题。Mermaid 支持方向键选中，拖动后保留原来的预览或编辑状态。
- 🧩 **容器编辑。** 修复复杂撤销后代码高亮与行号消失、空折叠块无法退格删除的问题。
- 📋 **表格选择与图注编辑。** 调整表格边缘的行列选择区域，保留表注和相邻正文的点击位置；修复把手遮挡工具栏、表注需要点击两次，以及图注和表注的焦点与历史问题。
- 🖼️ **图片粘贴与删除。** 在宫格或轮播中粘贴图片时保留目标位置和单一图注入口。删除带图注的图片可选择保留文字，并记住该选择。
- 📄 **导出显示。** 修复公式对齐、块颜色和任务清单状态在导出中丢失，以及本地图片在独立 HTML 中无法显示的问题；完善表格、图片组合与补充说明的导出排版。
- 🌐 **网页布局。** 修复表格单元格被正文段距拉高、普通居右公式出现多余滚动条，以及窄窗中提示块边框被裁掉的问题。超宽表格和公式在各自区域内滚动，保留完整内容。
- 🖨️ **分页错误定位。** 修复错误公式随标题移到下一页后，上一页仍出现空红框的问题。
- 🪟 **窗口与文件操作。** 修复最小化后重启窗口尺寸异常、标签与侧栏空间分配不稳定，以及外部打开文件后目录定位不一致的问题。

### 安装与格式说明

- Windows 10 / 11 x64 安装包：`NoteBoard_1.0.2_x64-setup.exe`。已有版本可覆盖安装；缺少 WebView2 时，安装程序会联网下载。
- PDF、HTML 和 Markdown 导出不需要 Pandoc；Word / LaTeX 导出需要 Pandoc 3.0+，编译 LaTeX 另需 TeX 环境。
- NB 中的图片仍使用外部文件引用，移动源文档时需一起携带图片目录。折叠、说明等结构降级到 Markdown 后，回改可能进入冲突保护，不能自动合回 NB。
- PlantUML 使用在线渲染服务，Draw.io 从 diagrams.net 加载；这两项需要网络。
