# NoteBoard 1.0.2

NoteBoard 1.0.2 汇总了本分支在原项目 0.3.5 基础上持续开发至今的完整变化，涵盖原生文档、表格排版、图片编辑、公式输入、导出和桌面交互。原项目的本地文件、Markdown、画板、多维表格及图表能力继续保留；下面集中介绍新增能力，以及原有功能发生的变化。

## 新增

### 原生文档与结构化内容

- 📄 **NB 原生文档。** 新建 `.nb` 文档，可以完整保存文字颜色、高亮、段落布局、表格尺寸、图片组合和补充说明。文件仍放在自己的本地目录中，可以直接打开、移动和管理，无需先导入专用资料库。
- 📝 **原生文档源码。** NB 同时提供可视化与源码编辑，源码采用可读的 UTF-8 文本。切换模式时保留对应的编辑位置；未知或损坏的记录保留原文，其他可读部分继续展示，也可以跳到源码中修复。
- 🔗 **NB 与 Markdown 关联保存。** 从 MD 转换的 NB 保存在原文件旁边。选择保留关联后，保存 NB 会同步更新 MD；文件树中以 NB 为主体，展开即可看到关联的原 MD，不额外创建一层目录。
- 🔄 **关联 MD 的文字回传。** 对于结构能逐块对应的文档，MD 中的文字修改可以合回 NB，保留 NB 的颜色和高亮。双方修改同一段，或降级后结构无法对应时会提示冲突，保留文件内容，避免把修改套到错误位置。
- 🎨 **随文字保存的样式。** 文字颜色和高亮可与正文一起插入、删除、移动、复制和撤销。使用超出 Markdown 表达范围的排版时，应用会提供转换为 NB 的入口，让增强样式有明确的保存方式。
- 🧩 **折叠块。** 将较长的资料、解释或草稿收进带标题的折叠块。标题与正文之间有清晰的分界，块内可以继续放文字、图片、表格和其他内容，展开状态随原生文档保存。
- 💬 **文字与整块的补充说明。** 可以给一段文字、图片、表格、代码或其他内容添加可点开的说明。说明保留在所属内容旁边，随内容移动，不必把解释直接插进正文；多个锚点可以指向同一条说明。
- 🫧 **模糊揭示。** 原生文档可以隐藏需要稍后查看的内容，并在阅读时揭示。HTML 保留对应交互；纸面导出显示完整内容，避免接收者拿到无法展开的空白。

### 文档表格

- 📊 **单元格与批量排版。** 选择单元格、整行、整列或整张表后，可以设置底色、水平对齐与垂直对齐。选区直接决定操作范围，适合整理对照表、记录表和资料清单。
- ↔️ **持久化行高与列宽。** 行高、列宽可以拖动调整，也可以对所选范围均分。尺寸写入文档，重新打开后继续保留；明确设置的宽度不会因为切换编辑状态而重置。
- 🧱 **合并、拆分与表头。** 支持合并所选单元格、拆分已有合并格，并设置表头。表格选择、编辑和导出共同处理跨行、跨列结构，合并格里的内容不会按覆盖到的每一格重复输出。
- 📐 **标准表与三线表。** 提供文档级表格样式与单表设置，标准网格和三线表可用于不同场景。表格结构与文字内容保留，不需要靠手动删除边框拼出三线表。
- ↔️ **表格位置独立设置。** 整张表可以靠左、居中或靠右，单元格文字另行对齐。表格摆放位置与格内文字方向分开管理，右对齐的表格不会强迫所有文字一起靠右。
- 🏷️ **可直接编辑的表注。** 表注位于表格下方，支持原位编辑、选中文字后格式化，以及撤销和重做。表注随表格保存，导出时继续放在对应表格旁边。
- 🖱️ **表边选择与拖选。** 表格两侧提供按所在行选择的区域，上下留白可按横向位置选择列，也可以拖动扩展选择。表注自身和相邻正文保留独立点击区域，便于居中表格的操作。

### 图片、图集与图注

- 🖼️ **四宫格、六宫格与九宫格。** 多张图片可以作为一组内容放进文档，每张图片保留自己的图注。组合可调整尺寸，宫格可设置在正文中的位置，适合放对照图、步骤图和一组资料。
- 🎞️ **图片轮播。** 图片可以按顺序逐张阅读，轮播整体居中。导出为 HTML 后仍能用箭头和圆点切换；导出为 PDF 时展开全部图片，让纸面内容完整可读。
- ✍️ **原位图注。** 单张图片与图集中的图注可以直接点击修改，不必先进入另一个弹窗。图注有自己的格式化与历史边界，编辑说明文字不会误触发图片移动。
- 🛠️ **统一图片编辑入口。** 文档图片、宫格、轮播和独立图片共用编辑器。裁剪、旋转、镜像与标注集中在同一处，修改支持撤销和重做，不需要在几种图片视图中重复学习操作。
- ✏️ **绘制与标记工具。** 图片编辑器提供铅笔、荧光笔、箭头、折线、形状、文字和自动序号。文字可以直接在图片上输入，已有标注可以继续选中、移动、缩放或修改。
- 🔍 **强调与遮挡工具。** 聚光灯、放大镜和马赛克可用于突出局部或遮挡信息。矩形马赛克适合处理一片区域，笔刷马赛克适合沿局部涂抹，擦除前可看到当前作用范围。
- 🎛️ **图片工具记忆。** 不同工具分别记住常用的颜色、粗细、尺寸等参数。重新切换工具时继续使用上次的样式，减少每次开始标注前的重复设置。
- 📤 **图片导出选项。** 编辑后的图片可选择 PNG、JPEG 或 WebP，并调整导出尺寸与有损质量。图片查看、复制和编辑保留使用原图的入口，文档中的显示尺寸不会替代原始素材。

### PDF 排版与导出

- 🖨️ **原生 PDF 排版预览。** 在应用内调整纸张和排版，查看实际分页结果，再导出 PDF。生成的 PDF 在新标签页打开，原文档和当前文件树目录保持原位。
- 📄 **纸张与页面方向。** 可选择纸张尺寸以及纵向、横向排版。上下边距与左右边距分别调整，不再只能给四边设置同一个数值。
- 🔠 **字号、行距与段距。** 正文字号、段内行距和段后间距分别设置，适合区分紧凑笔记、阅读材料与正式文稿。数字输入允许先完成输入，再处理有效范围，不会在输入两位数的第一位时抢先改值。
- 🔢 **明确的页码设置。** 页码开关、页码位置和页码格式分别标明用途。可设置页码显示方式及位置，预览与最终文件使用同一配置。
- ↔️ **宽表格处理。** 超出纸张宽度的表格提供布局处理选项，在可读性与页面适配之间选择。显式列宽、复杂单元格内容、跨页续行和续表边缘共同参与排版，避免只有外框缩小、格内内容仍越界。
- ∑ **长公式排版。** 可换行的表达式按可用宽度处理，矩阵与较高公式使用相应的续排路径；无法在可读尺寸内放下的内容会明确标记。需要时可选择适宽缩放，不把所有长公式统一压成难以阅读的小字。
- 🎯 **能定位的导出诊断。** 超宽内容和公式错误集中显示，点击条目可以定位到预览中的对应位置。错误、排版选项和内容处理说明分开呈现，复制按钮明确标为“复制报错”。
- 📏 **页数与预计大小。** 预览底部同时显示页数和 PDF 文件大小；没有状态提示占用时放在左侧，便于导出前了解结果。生成过程显示实际阶段与进度，选项连续变化时等待短暂停顿再生成。
- 💾 **沿用上次页面配置。** 纸张、方向、边距、字号、行距、段距和页码配置会保留到下次打开。修改部分配置时复用已有导出会话，避免每次都重新载入整篇文档。
- 🧾 **完整的打印内容。** 轮播展开全部图片，折叠块展开标题与正文，模糊内容恢复可读，补充说明按纸面阅读方式编号。待办保留勾选状态，块颜色和表格样式也进入导出。

### 独立 HTML 与文档交换

- 🌐 **可独立分享的 HTML 阅读页。** HTML 保留折叠、轮播、模糊揭示、公式和图表，接收者用浏览器即可阅读。页面不受纸张分页限制，也不额外在正文顶部插入文件名页眉。
- 💬 **在原位置查看说明。** HTML 中的说明从正文锚点打开，支持鼠标悬停、点击及键盘操作。内容显示在阅读浮层中，关闭后返回原文，不需要跳到文末来回寻找。
- 💻 **HTML 代码语言栏。** 代码块保留语法高亮与蓝色语言名称，并提供复制、折叠和换行控制。复制使用原始代码文字，保留缩进和换行，不把工具栏文字一起带走。
- 🧳 **内嵌本地图片与公式字体。** HTML 将引用的本地图片和使用的 KaTeX 字体写进文件，离线打开时继续保留图片与数学排版。远程图片仍使用原 URL，NB 源文档本身的图片引用方式不因此改变。
- ↔️ **超宽内容局部滚动。** 宽表格和长公式在各自区域内横向浏览，页面继续正常纵向阅读。表格保留显式列宽与对齐，HTML 沿用应用的公式能力及复杂度保护上限，不额外施加 PDF 的分页限制。
- 📂 **预览、定位与保存副本。** HTML 可在应用内预览，也可以切换到源码、用默认浏览器打开、定位所在文件夹或另存副本。独立网页中也提供打印与保存副本入口。
- 📝 **从文档结构导出 Word 与 LaTeX。** 表格、图片、公式和说明按目标格式支持的结构转换，说明使用脚注。原生文档不必先压成普通 Markdown，再重新猜测表格和公式。
- 🔄 **面向交换的 Markdown 导出。** 导出正文、链接、图片引用、公式和图表源码，去掉 NB 专属表现。普通表格使用标准 Markdown；包含多段落或复杂内容的表格使用标准 HTML 保留结构，避免把格内内容挤成一行。
- 🕓 **导出当前编辑内容。** 导出使用打开导出窗口时的最新快照，包含尚未保存的修改。无需先保存原文件，也不会为了导出而替用户执行保存。

## 改进

### 写作、公式与命令

- ⌨️ **两种插入方式。** 鼠标用户可以在空段落左侧点击出现的 **+**；键盘用户可以在空段落输入 **/**。两种入口共用插入能力，分别保持适合鼠标和键盘操作的组织方式。
- 🔎 **重新整理的斜杠菜单。** 提示块、表格、公式、图表、图片、链接、日期和待办等入口优先显示。继续输入名称可搜索，用上下方向键选择、Enter 确认、右方向键进入分类，Esc 关闭；标题、其他列表和清除格式仍可找到。
- ➕ **独立的加号菜单顺序。** **+** 菜单把文字与列表放在顶部，随后是内容块、图片、公式与图表。菜单高度随窗口可用空间调整，内容多时滚动查看，斜杠菜单的排序不会改变这里的分组。
- 🧯 **提示块输入辅助。** 输入 `[!`、`[!]` 或中文形式 `【！】` 可以选择 Note、Tip、Important、Warning、Caution。支持继续输入名称筛选，鼠标与键盘都可确认，完整的 Markdown 提示块写法继续可用。
- 🎨 **提示块外观。** 图标、标题、文字色、边框和背景可以分别调整。新建提示块默认保留标题，是否隐藏由用户明确选择；预设类型使用一致的标识，Caution 使用火焰图标。
- ∑ **更多公式定界符。** 支持 `$…$`、`$$…$$`、`\(…\)` 与 `\[…\]`，行内公式参与正文，独立公式可以左对齐、居中或右对齐。矩阵行距等 TeX 内容作为源码保留，不被当成 Markdown 标记拆开。
- ¥ **人民币符号快捷输入。** 可在可视化编辑中用成对的 `￥…￥` 或 `¥…¥` 建立行内公式，也可在独立一行输入 `￥￥` 或 `¥¥` 后按 Enter 建立公式块。常见金额如 `￥ 100`，以及带全角空格或不换行空格的金额继续保留为文字。
- ✍️ **新公式直接进入编辑。** 从工具栏、加号或命令菜单插入公式后，立即进入空源码输入，不再先放入一条示例公式。先输入一对定界符、再往中间写内容，也可以连续输入。
- 🪶 **随正文展开的行内源码。** 编辑时，源码像句中其他文字一样随输入增长，到段落边界后自然折行。定界符使用低对比显示，预览放在整段源码下方，可覆盖下一行，但不会伸进大纲或侧栏。
- ↔️ **明确的公式退出方式。** 行内公式写完后，可在末尾按右方向键、按 Enter，或点击外部回到正文。块公式中 Enter 换行，Ctrl+Enter 或 Escape 完成编辑，输入区、完成提示与预览保持紧凑而清楚的距离。
- 🧮 **公式错误保留原文。** 错误公式可以继续编辑，修正后恢复渲染。把全角 `｝` 用在半角 `{` 后面等可识别的错误，会指出对应字符；应用不擅自补括号或改写源码。
- 🔤 **行内代码的两种输入顺序。** 可以先输入一个反引号、写内容后再闭合，也可以先输入一对反引号、再在中间连续输入。转换后保留编辑位置，转义字符和代码围栏不会被当成同一种手势处理。
- 💻 **中点代码围栏。** 除标准反引号外，独立段落中的三个中点 `···` 也可建立代码块。写 `···python`、`···css` 等语言标记后按 Enter，会进入对应语言的代码块；普通句子中的中点不受影响。

### 编辑历史与容器

- ↩️ **连贯的撤销与重做。** 正文、公式源码、图表源码、图注和表注沿用文档历史。可以先撤销容器中的输入，再撤销新建容器，继续回到此前正文的编辑，不需要在几套互不相通的撤销链之间切换。
- 🧭 **保留正在编辑的位置。** 撤销公式内容时保留源码输入区、焦点与光标，不按渲染结果整块替换正在输入的界面。撤销到空公式时仍可继续编辑，再撤销创建动作才移除公式。
- 🧩 **容器里的连续书写。** 在提示块、折叠块、引用和表格单元格末尾插入图片、表格、公式或图示后，可以继续在容器内写下一段。已有续写段落会复用，避免反复产生多余空行。
- 🔲 **逐级全选的明确边界。** 在代码块、列表、引用、提示块、折叠块、表格和图片组合中，第一次 Ctrl+A 选择当前容器内容，再按一次选择全文。普通正文或已跨容器的选择仍一次全选全文。
- 🗑️ **空折叠块的删除。** 正文清空后，在空段落开头继续按 Backspace 可删除整个折叠块，标题随块一起移除。撤销恢复原块、标题与内容；有图片、公式或嵌套内容的块不会因为没有普通文字就被当成空块。
- ⌨️ **图表可由键盘选中。** 方向键可以从相邻正文进入公式和 Mermaid 等原子块的选择，再继续移动。选中图表与进入源码编辑是两个动作，拖动原本处于预览状态的 Mermaid 会保持预览状态。
- 🧑‍💻 **Mermaid 创建与编辑。** 新建 Mermaid 保留初始化模板并直接进入源码。编辑内容可先撤销，再沿历史退出编辑或撤销新建；全屏预览可以通过点击空白背景退出。
- 🖱️ **整块操作与文字操作分开。** 选中文字后的工具栏负责文字格式，内容左侧的把手负责块操作与拖动。表格自己的行列选择工具也保留独立范围，降低移动内容、选择文字和打开说明之间的误触。

### 代码、外观与桌面体验

- 🗂️ **更多代码文件按语言打开。** 代码块支持的常用语言识别扩展到独立文件。Python、C、C++、JavaScript、TypeScript、Java、C#、Go、Rust、SQL、PowerShell 等文件按后缀或文件名选择高亮，不再大量落入普通文本视图。
- 🔎 **面向阅读的代码工具。** 代码文件提供查找、跳转行和折叠等操作，文档代码块可以搜索并切换语言、复制、折叠或换行。这里以查看和轻量编辑为主，没有加入编译器、调试器或项目构建环境。
- 🟦 **一致的代码语言标识。** 代码块语言名称使用清晰的蓝色，和图表源码入口保持一致。语言名、折叠与内容区域各有位置，较窄窗口也能保留主要操作。
- 🌓 **三种主题的完整覆盖。** 晨光、琥珀、墨夜覆盖正文、菜单、公式源码和浮层，也可以跟随系统。配色按主题统一调整，公式编辑区不固定使用只适合黑白两种背景的颜色。
- 🔠 **分区域字体设置。** 界面、正文、代码和文件树可以分别选择字体，并调整相关字号和行距。字体列表提供预览，可使用本机安装字体或下载可选字体包，打印使用配置的文档字体。
- ⌨️ **可配置快捷键。** 支持搜索、修改、禁用和恢复默认快捷键。标题层级、恢复正文和下划线等编辑快捷键在源码与可视化模式中保持一致，中文输入状态下不抢占组词按键。
- 📐 **正文与侧栏布局。** 正文宽度、选区工具栏位置和侧栏宽度可以按阅读习惯调整。设置面板适应窄窗口和较大字号，较长菜单保留滚动空间，避免关键按钮落到窗口外。
- 🪟 **整理后的窗口外观。** 标题栏、标签页轮廓、工作区圆角和侧栏控制重新协调，侧栏切换集中到顶部。内容较少时减少空占位，标签较多时保持可滚动的几何范围。
- 🖊️ **新的桌面图标。** 应用图标使用实底纸页与白色笔形，补齐不同尺寸的清晰显示，并处理安装后快捷方式图标未及时刷新的情况。
- 📁 **统一的文件类型识别。** 文件树、标签页、新建、重命名和外部打开共用文件分类。修改扩展名后，图标与编辑方式随真实类型更新，NB 与 Markdown 使用可区分的文档图标。
- 📂 **直接打开本地路径。** 支持粘贴 Windows 文件或文件夹路径，文件树可单击打开文件。从外部打开文档时跟随到直接父目录，转换和另存为后及时定位新文件，减少手动寻找目录的步骤。
- 🔔 **重新整理的更新界面。** 新版本通知显示版本与说明入口，详情按标题、列表和链接排版。长说明单独滚动，“下载并安装”按钮保留在底部，下载进度与错误有对应状态；可以关闭本次提醒或忽略特定版本。
- 🧭 **明确的更新通道。** 正式版只接收正式更新，支持预发布通道的 RC 版本可以接收后续 RC 和正式版。更新来源固定为本分支，版本比较遵循正式版与预发布版本的先后关系。
- 🌱 **可直接编辑的功能示例。** 主页增加紧凑的示例入口，打开后可以在实际文档中尝试公式、表格、图集、轮播、提示块和折叠内容，不必先照着说明手动搭一整篇样例。

### 长文档与资源占用

- ⚡ **按需加载大型编辑器。** 画板、代码、公式与导出相关的较重依赖按使用场景加载，首屏不再提前带上全部编辑器。HTML 预览与源码切换时释放另一侧的编辑界面，避免长期同时保留两份大型内容。
- ∑ **可见公式优先。** 公式在后台渲染，相同内容复用结果；当前编辑和屏幕附近的公式优先处理。大文档使用有界的预览缓存和显示预算，滚动经过时不反复重建已经准备好的普通公式。
- 🧮 **大矩阵的显示范围。** 大型矩阵按可见范围准备内容，保留完整源码，避免把所有单元格同时加入页面。复杂度保护与视口显示分别处理，超限时给出明确提示，不用空白伪装成功。
- 💾 **减少输入中的整篇转换。** 普通输入暂存文档状态，在保存、切换、导出等需要完整内容的时机再生成文本。正文与样式共同参与历史，减少为了追踪颜色而反复扫描整篇文字的工作。
- 🔎 **复用查找与位置索引。** 查找、源码位置和大纲跳转减少重复建立索引，正则搜索与转换任务隔离处理。局部编辑优先更新受影响的内容，不在每次光标移动时重新扫描整篇文档。
- 💻 **可见代码及时高亮。** 代码滚入视野后即可显示高亮与行号，不依赖先点击编辑器。长代码按可见范围绘制，避免把全部行号和高亮节点同时加入页面。
- 🖼️ **大图按显示尺寸预览。** 文档中的大图使用适合当前显示尺寸的预览，复制、查看和编辑继续访问原图。轮播、图集与独立图片共用资源处理，减少重复解码和不必要的像素副本。
- 🧱 **表格拖动减少重复测量。** 选择、行列调整和拖动使用对应手势期间需要的几何信息，避免鼠标每移动一次就重算整张表。文字工具栏、表格工具栏与选择把手共用明确的层级关系。
- 🖨️ **导出任务可复用、可取消。** 文档转换放到后台执行，PDF 预览保留导出会话，局部页面选项变化不重复载入整篇内容。取消或关闭后清理相关任务和资源，旧结果不会覆盖后来一次导出。
- ✍️ **画板手势期间减少重复保存处理。** 画板拖动时合并场景序列化工作，减少同一手势中反复整理完整场景的成本，保留原有画板文件和操作方式。

## 修复

### 输入与选择

- ⌨️ **中文输入中途被打断。** 修复代码块高亮刷新打断组词、公式输入法确认丢失，以及同一次中文标点提交被处理两次的问题。组合输入期间保留原生输入状态，确认后再同步文档。
- ∑ **行内公式只允许输入一次。** 修复先输入成对定界符后，写入第一个字母或确认一次输入法就退出公式的情况；后续输入继续留在公式里，直到明确移出。
- 🔤 **公式源码首字与滚动异常。** 修复行内源码以小输入框显示时首字被横向滚走、长内容在内部滚动或换行不自然的问题。源码直接参与段落排版，预览单独限制在正文行宽内。
- 🧮 **公式预览拉动页面。** 修复高矩阵在连续输入、短暂语法错误或等待新渲染结果时收缩，导致输入区和滚动位置突然变化的问题；新结果准备期间保留稳定占位。
- ↩️ **容器中的撤销链断开。** 修复代码块无法正常撤销输入、公式按整块渲染结果撤销，以及命令创建内容后重做异常的问题。输入、结构创建与相邻正文编辑按文档历史衔接。
- 🧭 **撤销后菜单残留。** 修复命令触发内容被撤销后，命令面板仍停在界面上或保持旧选择的情况。
- 💻 **撤销后代码失去高亮。** 修复复杂的创建、编辑和撤销顺序后，代码块要再次点击并输入才恢复高亮与行号的问题。
- 🖱️ **表外点击跳到第一格。** 修复点击表格周围留白时，光标被强行放到第一格开头的问题。行列选择区域按点击位置工作，不借用表注或下一段正文的点击空间。
- 🏷️ **表注需要点击两次。** 修复第一次点击表注被表格选择逻辑截走、第二次才能编辑的情况，同时处理选列把手与表注之间的误触。
- 🧰 **选择把手盖住工具栏。** 修复表格行列把手显示在文字工具栏、表格工具栏上方并拦截点击的问题，包括编辑区形成独立层叠环境时的情况。
- 🔲 **容器内无法继续输入。** 修复容器末尾放入图片、公式、图示等块后难以继续写下一段，以及局部全选未包含首尾原子内容的问题。
- 🗑️ **空折叠块删除不完整。** 修复正文清空后不能退格删除容器，以及删除后标题残留在原位置的问题，撤销可恢复整块内容。
- 🧯 **提示块标题与外观异常。** 修复通用插入入口生成隐藏标题、部分图标不一致，以及加号菜单被斜杠菜单排序连带改变的问题。

### 图片、文件与窗口

- 🖼️ **图集粘贴到错误位置。** 修复向宫格或轮播粘贴图片时丢失目标槽位、重复产生图注入口，以及未聚焦的槽位无法按预期接收图片的问题。
- 📋 **外部富文本粘贴。** 改进对外部富文本与数学标记的识别，保留能识别的公式源码和结构。图片与文字按实际内容路由，避免把所有粘贴来源都当成一种格式。
- ✍️ **图注编辑干扰图片操作。** 修复图注焦点、选区工具栏和历史恢复中的问题，减少输入说明文字时误选或拖动图片的情况。
- 🔄 **图片修改后仍显示旧内容。** 修复保存图片后文档预览、查看和相关资源仍使用旧缓存的问题。删除与资源清理遵循文档保存状态，避免刚删除就破坏可撤销内容。
- 🏷️ **删除图片时保留文字。** 删除带图注的图片时，可以选择保留图注文字，并记住该选择；图集中的图注与槽位处理保持一致。
- 🔗 **关联文档未同步。** 修复 NB 成对保存后，已打开的干净 MD 标签仍显示旧内容，随后又被当作新输入写回的问题；正在编辑或输入法组合中的文档保留当前输入。
- 💾 **保存后仍误报未保存。** 修复磁盘原文、编辑器规范化内容和保存基线混用导致的错误状态，以及恢复标签后转换文档时的冲突判断问题。
- 📁 **转换后文件树未更新。** 修复 NB 已生成但文件树没有及时定位、关联 MD 未展开，以及目录监听缺少对应路径授权的情况。
- 🪟 **最小化与窗口恢复。** 修复最小化后重新启动时恢复了错误尺寸、正常窗口位置未正确保留，以及并发打开多个文件时窗口创建互相干扰的问题。
- 🗂️ **标签与侧栏状态。** 修复窗口间转移标签后的清理归属、侧栏像素宽度恢复和标签末端细小碎片显示问题，保留正确的滚动范围与当前工作位置。

### 导出与阅读

- ∑ **公式对齐与字体丢失。** 修复公式左右位置、部分块样式在导出中丢失，以及 HTML 依赖系统数学字体导致显示与应用不同的问题。独立 HTML 使用相同的 KaTeX 排版标记与内嵌字体。
- 📏 **普通公式被误判超宽。** 修复 KaTeX 隐藏支撑节点多出少量宽度，使正常居右公式被标红或出现多余滚动条的问题。实际超宽的内容仍保留诊断或局部滚动。
- 🧾 **分页后重复错误标记。** 修复错误公式随标题移动到下一页后，上一页留下空红框的问题。预览只保留实际内容所在位置，同时保留细小表格定位标记。
- 📊 **HTML 表格行高异常。** 修复正文段落间距覆盖单元格段距，导致每一行都被额外拉高的问题。单元格间距与编辑器协调，手动列宽和整表对齐继续保留。
- ↔️ **HTML 窄窗裁掉正文边缘。** 修复整篇文档横向滚动时提示块边框和正文左侧被裁掉的问题。宽表格与公式改为独立滚动区域，页面外框保持稳定。
- 🖼️ **本地图片无法内嵌。** 修复 HTML 导出读取本地图片时错误走入受限路径入口、报 `forbidden path` 的问题，沿用应用已有图片资源通道读取并内嵌原始字节。
- 🎞️ **HTML 阅读交互被降级。** 修复 HTML 将轮播展开成静态网格、把有锚点的说明全部移到文末，以及代码块缺少语言头与基本阅读操作的问题。
- 📤 **HTML 保存副本不可用。** 修复离线阅读页保存副本的路径与运行时内容处理，保存时保留完整文档并移除临时浮层，避免把打开中的说明留在错误位置。
- ☑️ **打印待办状态错误。** 修复待办勾选状态和图形在导出中未按实际内容显示的问题，未保存的勾选修改也会进入本次导出快照。
- 🔢 **页面数字输入被强行改值。** 修复全选原字号、准备输入两位数时，第一位立即被夹到最小值，第二位又被夹到最大值的问题。
- 🛡️ **导出中的内容保留。** 无法解析的原生记录继续按原文保留，缺失的说明正文会明确报错。复杂表格、图片组合与说明不会因为暂时未展开或未挂载而被静默跳过。

## 安装与格式说明

- **Windows 10 / 11 x64：** 下载 Assets 中的 `NoteBoard_1.0.2_x64-setup.exe`。已有本分支版本可以覆盖安装，也可以在应用更新页面选择“下载并安装”。缺少 WebView2 时，安装程序会联网下载所需运行时。
- **更新来源：** 本分支的已安装版本从 `ShallowDream724/NoteBoard` 检查更新。旧发布页的移除不影响它们检测和下载 1.0.2；原作者版本仍使用自己的更新来源，切换到本分支需要先安装这里的安装包。
- **文件校验：** 同一发布页提供 `SHA256SUMS.txt`。GitHub 自动附带的 Source code 是源码归档，不是安装程序。
- **NB 扩展名：** 默认使用 `.nb`，`.nbdoc` 是同一种格式的另一扩展名，可用于避免与 Wolfram Notebook 的 `.nb` 混淆；它不是把 NB 再导出成另一种文档格式。
- **图片与移动文档：** NB 源文档中的图片仍使用外部文件引用，移动或分享源文件时应一起携带图片目录。独立 HTML 会内嵌本地图片，适合交给没有安装 NoteBoard 的人阅读。
- **关联 Markdown：** 当前文字回传要求结构能够逐块对应。折叠和说明等内容降级后改变结构时，MD 回改可能进入冲突保护，需要手动处理这些结构的变化。
- **导出依赖：** PDF、HTML 和 Markdown 无需 Pandoc；Word 与 LaTeX 导出需要 Pandoc 3.0+，编译 LaTeX 另需 TeX 环境。不同目标软件的字体、分页与语法支持仍会影响最终呈现。
- **图片编辑输出：** 图片编辑面向普通 8 位图片输出，不能保留原图全部 HDR、色深与元数据。独立图片默认另存为，明确选择原路径后才覆盖；可处理的尺寸仍受设备容量限制。
- **图表网络需求：** PlantUML 当前使用在线渲染服务，Draw.io 从 diagrams.net 加载。Mermaid 和普通本地文档不依赖这两个在线服务。本次没有新增内置账号同步或多人实时协作。
- **大型内容：** HTML 不按纸张分页，可以纵向延伸并局部横向滚动，但仍受浏览器、硬件和公式复杂度上限约束。超限内容保留源码并给出提示，不承诺任意规模都能瞬时完成。
- **项目与许可：** 本项目基于 [CrazyFigure/NoteBoard](https://github.com/CrazyFigure/NoteBoard) 继续开发，采用 GPL-3.0-only 许可。感谢原项目以及 Excalidraw、Mermaid、KaTeX、CodeMirror、TipTap、diagrams.net 等开源项目。
