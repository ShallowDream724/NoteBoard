# 正文统计

状态栏在 Markdown、NoteBoard 文档和纯文本/代码文档中显示字符数与字词数。保存状态继续独立显示，统计计算不触发保存或全文序列化。

字符数按 Unicode 码点计算，排除空白，包含标点与符号。字词数中，汉字、假名和韩文每字计一词；其它文字按连续字母或数字计词，英文单词内部的直撇号或弯撇号保持连接。两项统计均针对全文，光标移动或选择文字不会改变计数。

富文档正文包括段落、标题、表格、列表、代码、图注、表注、折叠标题和自定义提示标题。代码中的标点计入字符，字母/数字仍按同一规则计词。图片地址、替代文本、链接目标、公式、图表源码、隐藏说明正文、文件元数据和损坏记录均不计入。带说明的正文锚点仍按正文计一次；图表注释优先采用结构化内容，避免与其兼容文本重复计数。NoteBoard 源码视图也统计文档内容，命令、文件头和 JSON 记录不会变成正文。

可视化编辑器初始化文档后调用 `bindRichDocumentStatistics(docKey, editor)`，并将其返回的清理函数绑定到实例生命周期。统计直接读取不可变编辑树，缓存未变化子树；内容更新后等待 120 毫秒合并连续输入，持续输入时最长每 500 毫秒更新一次。只移动光标不会遍历正文。卸载会清理订阅、计时器和该实例的统计快照，旧实例的清理不会删除新实例结果。

源码和纯文本采用相同的调度规则，通过独立 Worker 统计已确认的内容快照，界面线程不解析整篇源码。Worker 按消费组件生命周期释放，过时的异步结果不会覆盖新文档或新内容。Markdown 源码正文投影集中在 `documentSourceStatistics.ts`，惰性加载同一套 Markdown/声明式语法，避免统计另建一套不一致的解析规则；界面与调度不依赖编辑器内核。正文统计略晚于输入更新，并在下一次统计完成前保留同一文档的已有结果。
