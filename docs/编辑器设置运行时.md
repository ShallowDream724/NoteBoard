# 编辑器设置运行时

设置窗口使用已有 Radix Dialog primitives 管理 Escape、Tab/Shift+Tab 焦点范围及模态交互。内容带 `data-shortcuts-suspended`，全局快捷键分发不会将设置输入中的 Ctrl+W、Ctrl+H、Ctrl+F 交给背景文档。窗口打开时应用根节点设为 inert，关闭时恢复原状态与先前焦点。设置分类切换不关闭窗口。

存储层的 `saveError` 统一呈现在设置窗口的可复制提示中；各设置分类不另建保存错误处理流程。

代码编辑器和 Markdown 源码模式读取同一组设置，首次创建采用当前持久设置。`liveEditorSettings` 的订阅绑定 CodeMirror 实例生命周期；相关设置变化合并到微任务，通过 compartment 重配，不重建文档、选区或撤销历史。源码模式不再无条件启用软换行。

| 设置 | 实际作用 |
| --- | --- |
| Tab 缩进宽度 | CodeMirror 制表符显示宽度与空格缩进单位，范围 1–8 |
| 空格代替 Tab | `indentUnit` 使用相应数量的空格或真实制表符；Tab/Shift+Tab 继续使用 CodeMirror 的缩进命令 |
| 缩进参考导线 | 仅为 CodeMirror 可见行建立虚线背景，按配置的 Tab 列宽对齐；每行最多 64 条导线，不扫描全部文档 |
| 空白、行尾、行号、软换行 | 同时适用于代码编辑器和 Markdown 源码模式，修改后立即重配 |
| LaTeX 渲染 | 只控制预览工作。关闭时取消预览生命周期并按 `writeMath` 展示原分隔符和源码；点击后继续使用公式源码编辑器。节点、语法和保存内容不受开关改变 |
| Mermaid 渲染 | 关闭时显示可编辑源码，停止新渲染并取消尚未开始的排队任务。已进入 Mermaid 内部执行的工作只能丢弃结果；重新启用后按当前源码渲染 |
| 悬浮块把手 | 由可视化内核控制块把手组件的挂载；不改变正文与块节点 |

这些显示设置不删除 Markdown 扩展或修改已有文档。文档导出的独立渲染流程仍按导出选项工作。

缩进/热重配契约由 `test/editor-code/editorSettings.test.ts` 验证；设置存储与后端版本并发由设置存储模块负责。
