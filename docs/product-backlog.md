# 后续产品打磨

- [ ] 图片资产回收：1.0.1 的画布编辑历史只存内存语义操作，但每次保存不同结果会生成内容寻址图片；编辑替换 src 使用属性事务，不进入现有的节点移除回收候选。未命名文档恢复图片和旧版本缺少定期清理、磁盘容量提示与孤儿扫描入口，长期可能累积。补统一的资产引用/保留期管理，保护文档、撤销重做、暂存、会话及共享引用，再清理能够证明无引用的受管理资产；不能仅按文件年龄或退出编辑直接删除。此项尚未实现。
- [ ] 下一个版本：重做更新提示卡片。用户在本机 1.0.0 已成功收到 1.0.1 提示，但认为现有卡片过大、排版松散。缩小占用，统一图标、标题与版本信息的对齐，明确“查看更新”为主操作，将“此版本不再提醒”降为次要选项；保持关闭、不再提醒、键盘访问和更新检测行为。按用户要求留待下一版，不替换已发布的 1.0.1 安装包。
- [ ] 菜单图文帮助：为容易混淆的功能提供延迟悬停的说明卡片，包含小幅操作示意与一句用途说明。优先覆盖表头行/列、整表位置与单元格对齐、表格打印方案。键盘聚焦也可访问；鼠标快速经过不闪烁、不提前加载全部演示资源；卡片不得挤压正文或妨碍子菜单。
