# 后续产品打磨

桌面交互重点参考 [Winc](https://github.com/DEEIX-AI/Winc)。例如，外部文件发生变化时，Winc 根据当前文档是否有本地编辑、对应标签是否可见，分别处理重载和冲突提示。设计 NoteBoard 的文件操作时，同样要区分编辑器里的内容和磁盘版本，让用户看得出操作会保留哪一份。[Winc 的文件变更处理](https://github.com/DEEIX-AI/Winc/blob/d92e169e1ad59ee0512ce444d9adfd29a1ac541d/crates/winc-app/src/app/workspace/watch.rs#L322-L330)

## 工作区与阅读

- 「打开文件夹」设置工作区。通过「打开文件或文件夹」或将目录拖到标签栏时，已有工作区内的子目录在原树展开，外部资料目录可临时浏览。拖到文件树仍由落点决定复制或移动的目标目录。
- 启用「保留最近文件」后，切换工作区或关闭窗口会记录该目录内已命名文件的标签、阅读位置和编辑模式。首页的「继续工作区」恢复选中项目，已有的其他标签和草稿仍可使用。最近保留 24 个工作区，正文与未命名草稿由文档和暂存机制管理。
- 从大纲或书签跳转后，可按导航栏右侧返回箭头回到跳转前的选区和阅读位置。同一编辑器最多记住最近 16 处跳转，正文编辑会同步更新位置。
- 图片与 SVG 预览支持以指针为锚点滚轮缩放，聚焦图片后可用 Ctrl 加号、减号缩放，Ctrl+0 或双击重新适应窗口。

## 文件预览的后续格式

Word、Excel 与 EPUB 可优先评估 Winc 独立于窗口和标签的 Rust 解析模块。其 DOCX、EPUB 解析结果适合接入只读文档视图，XLSX 的工作表与单元格结果适合接入虚拟表格。后续接入时按格式验证图片引用、公式缓存值、空单元格及截断提示，并保留原文件。现有 PDF 阅读器与打印预览共用 PDF.js。[Winc 预览模块](https://github.com/DEEIX-AI/Winc/blob/d92e169e1ad59ee0512ce444d9adfd29a1ac541d/crates/winc-preview/src/lib.rs)

- [ ] 图片资产回收：1.0.1 的画布编辑历史只存内存语义操作，但每次保存不同结果会生成内容寻址图片；编辑替换 src 使用属性事务，不进入现有的节点移除回收候选。未命名文档恢复图片和旧版本缺少定期清理、磁盘容量提示与孤儿扫描入口，长期可能累积。补统一的资产引用/保留期管理，保护文档、撤销重做、暂存、会话及共享引用，再清理能够证明无引用的受管理资产；不能仅按文件年龄或退出编辑直接删除。此项尚未实现。
- [ ] 下一个版本：重做更新提示卡片。用户在本机 1.0.0 已成功收到 1.0.1 提示，但认为现有卡片过大、排版松散。缩小占用，统一图标、标题与版本信息的对齐，明确“查看更新”为主操作，将“此版本不再提醒”降为次要选项；保持关闭、不再提醒、键盘访问和更新检测行为。按用户要求留待下一版，不替换已发布的 1.0.1 安装包。
- [ ] 菜单图文帮助：为容易混淆的功能提供延迟悬停的说明卡片，包含小幅操作示意与一句用途说明。优先覆盖表头行/列、整表位置与单元格对齐、表格打印方案。键盘聚焦也可访问；鼠标快速经过不闪烁、不提前加载全部演示资源；卡片不得挤压正文或妨碍子菜单。
