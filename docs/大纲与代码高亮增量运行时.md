# 大纲与代码高亮运行时

## 大纲索引

`HeadingIndex` 属于当前挂载的大纲，初始化一次读取标题。后续按 ProseMirror 事务和附加事务映射已有标题位置，只重新提取修改范围。标题 ID 在同一索引的前文插入、标题改名和级别变化中保持稳定；删除/重新创建以及切换编辑器会重建对应身份。

普通光标位置的文本输入复用事务已经解析的选区路径，直接读取所在文本块，不调用整份文档的 `descendants` 或从开头跳过所有兄弟节点。每次文档变化仍有 O(H × M) 的标题位置映射与 O(H) 合并（H 为标题数，M 为事务映射数）。结构编辑需要读取实际变化子树；非选区位置的编辑还可能承担 ProseMirror 自身的兄弟节点定位成本。未知自定义步骤以及未连续收到事务时保守重建，不承诺常数时间。

大纲光标导航按文档位置二分。滚动导航独立缓存实际纵坐标并按 Y、文档位置排序，因此同一表格不同列内的标题不要求在文档顺序中纵坐标单调。缓存重建需要 O(H) 次几何读取和 O(H log H) 排序，普通滚动只二分缓存。文档更新、编辑区尺寸变化和影响布局的子树变化使缓存失效；观察器与动画帧在面板清理时释放。

## 代码高亮

`codeHighlighting` 的主线程只管理请求、缓存和结果；lowlight 与语言语法在独立 Worker 中加载和分词。普通正文不会加载分词引擎。编辑器与导出共用同一服务。

- 单个 Worker 同时处理一个请求；队列最多 64 个任务、估算源码内存最多 4 MiB。
- 相同语言与源码共享在途请求，消费者有独立 AbortSignal。最后一个消费者取消时删除排队任务；正在执行则终止 Worker，阻止旧源码继续占用 CPU。
- 结果 LRU 最多 256 项、估算 4 MiB，滚出视口再回来可复用。缓存估算包含源字符串、token 对象固定开销和样式字符串，不代表 JS 引擎精确堆占用。
- 单块最多 200,000 字符、16,384 个 token、估算 2 MiB token 数据；单次任务 5 秒 watchdog。越界、队列满、Worker 不可用或模块失败时保留纯文本，不在主线程补做同步分词。队列满的块在下一次请求时重试。
- Worker 空闲 30 秒后释放语法运行时；页面离开和开发热替换清空任务、结果缓存与 Worker。
- NodeView 的版本变化、离开附近视口及卸载会取消请求；结果发布前复核节点身份。装饰按帧合并，单帧预算约 4096 tokens，单个更大的块仍原子发布。发布时重新查询节点位置，避免前文编辑造成位置过期。编辑器销毁清理未发布帧。

这些上限约束分词和驻留量，不代表大型代码块的 ProseMirror 装饰创建、DOM 更新或所有编辑器行为均为常数时间。
