# NB 可视化编辑验收

## 从一份练习开始

在主界面点击「动手试一试」，或者点击标题栏的书本按钮，打开「公园观察练习」。这是一份可以自由修改、保存的普通 NB 文档。

练习包含 11 项：选中文字、加高亮、设置标题、提示块、折叠块、填写表格、三线表、行内公式、补充说明、移动段落、撤销重做。完成实际操作后才会显示「已完成」。可以跳过、收起面板、移动到左侧，或者随时退出。

切到其他文档后，练习暂停。再次点击书本按钮会回到原来的练习；「重新练习」会创建新副本。退出练习不会删除文档，关闭练习文档会清除本次进度。

## 建议再试的几条完整流程

1. **图注格式与撤销**：先选中正文，再进入图片图注，选中文字，点击顶部工具栏的加粗或高亮。只有图注应该改变。撤销、重做，然后保存、关闭、重新打开，确认格式仍在。
2. **补充说明**：选中文字后添加说明。在说明内输入中文，添加下划线、链接或列表。保存后重新打开说明；取消一次编辑，检查正文及已保存的说明没有改变。
3. **混合内容移动**：选中包含文字、公式、提示块、表格、图片图注、代码块的连续内容，复制到新 NB 文档。检查图片、注释和代码语言没有丢失，再撤销、重做、保存重开。
4. **中文输入**：在正文、图注和说明中连续输入中文。输入法候选阶段不要被工具栏更新打断；提交一次组合输入后，撤销应恢复此前内容。
5. **导出分享**：将含图注和说明的文档导出为 HTML 和 PDF。HTML 中的说明应可在原位置打开，代码应有语言标题；PDF 中的说明应有可读的编号和正文。检查图注格式、表格、代码着色、公式及折叠块正文。
6. **不同窗口与主题**：分别切换晨光、琥珀、墨夜，并尝试 200% 界面缩放。练习面板可以收起；鼠标在功能菜单上停留后，讲解卡片应出现在窗口内，鼠标移入卡片时仍可阅读，Esc 可关闭。

## NB 与 Markdown 的源码入口

NB 正常编辑只提供文档视图，不再把原始存储记录作为普通源码模式。若某条 NB 记录损坏，错误块仍有「修复原始记录」入口；修复后可「返回文档」。原始内容不会因切换视图被丢弃。

Markdown 文件仍保留源码与可视化模式的切换。

## 自动验证

以下命令在仓库根目录执行。浏览器脚本使用已安装的 Edge；环境没有本地 Playwright 包时，可通过 `PLAYWRIGHT_MODULE` 指定现有模块路径，无需重新下载浏览器。

```bash
npm run build
node scripts/check-budget.mjs --check
node scripts/check-interactive-practice.mjs
node scripts/measure-practice-memory.mjs
node scripts/check-visual-workflow.mjs
node scripts/check-board-loading.mjs --dist dist
```

- `check-interactive-practice`：生产构建内实际完成 11 项练习，检查三套主题的悬停讲解、窄窗口、200% 缩放和会话恢复。`NOTEBOARD_TEST_CDP` 可连接隔离的原生测试实例；该模式直接执行实际交互，不注入模拟 IPC。
- `measure-practice-memory`：连续 8 次创建及关闭练习，检查编辑器 DOM 释放、GC 后 JS 堆与监听器数量。浏览器模式仅模拟原生接口，不代表整个 Windows 进程的内存。
- `check-visual-workflow`：实际图注/说明工具栏、父子编辑作用范围、中文组合输入、撤销重做、原始记录修复、跨块复制粘贴、序列化重开及 HTML 导出。产物位于 `.tmp/visual-workflow/`，包含混合内容 NB、HTML、截图与原生 PDF 输入。
- `check-board-loading`：生产构建中自由画板创建、绘制、撤销重做、关闭回收，以及思维导图、多维表格和加载失败处理。

浏览器模拟不代替原生 PDF 打印、文件系统或系统输入法测试。发布前应使用隔离配置的原生构建补充验证，再安装到日常使用目录。
