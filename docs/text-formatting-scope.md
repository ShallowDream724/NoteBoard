# 清除文字样式与表格批量文字操作

入口共用 `textFormatting.ts`，清除对象为文字展示 Mark：粗体、斜体、下划线、删除线、文字色、高亮、行内代码及 Schema 支持的上下标。保留链接、说明、模糊语义、文字和公式内容。不会调用 `clearNodes` 将标题、列表或引用转换成段落。

块菜单按类型明确枚举：

| 类型 | 操作范围 |
| --- | --- |
| 正文、H1–H6 标题 | 当前块文字，保留标题级别、段落排版 |
| 无序、有序、待办列表和列表项 | 所选列表/列表项内部文字，保留编号、层级、待办状态 |
| 引用、折叠块 | 当前容器内部富文本，保留容器属性、嵌套结构；不扩展到折叠标题后的其他 Section |
| 提示块（Callout / Note 等） | 块菜单提供“取消提示块”：解除外层容器，保留内部文字样式、图片和嵌套结构；自定义标题转为段落，补充说明随首块保留。预设 Note/Tip 标签随外壳移除 |
| 表格 | 整表单元格文字；多选工具栏只处理选中格子 |
| 图片 | 仅在图注存在文字样式时提供“清除图注文字格式” |
| 宫格、轮播 | 清除组合内部图注文字样式；兼容真实图注段落和旧图片 captionContent |
| 表注 | 单独的“清除表注文字格式”，不会随单元格清除一起执行 |
| 代码块、公式块、Mermaid、分隔线、内部占位节点 | 无此块菜单操作；不触碰源码或把语法高亮当作可清除的格式 |

表格保留：表头语义（因此表头默认粗体仍存在）、合并、行列数量、尺寸、整表位置、边框、单元格底色、对齐与缩进。`CellSelection` 的离散范围逐格处理，不能使用整体 from/to 跨过未选格子。批量样式由 `CellTextStyleStep` 在一次事务中更新表格，保持选区和一次撤销，不为每个 Mark 重复复制整棵表。

块级操作由 `clearBlockFormatting` 分派。顶栏清除时，完整选中的 Callout 同样解除外壳；在 Callout 内手动选中文字，仍按文字选区清除文字样式。两者均支持一次撤销，命令不请求滚动。

撤销定位使用实际 Step 的编辑位置。纯 Mark、属性和批量单元格 Step 的位置映射可能为空，必须读取它们的目标位置；不能退回到之前无关的输入光标。命令本身不主动滚动视口。

覆盖：`test/editor-md/textFormatting.test.ts` 的矩形选区、合并格、表头、链接、独立图注及一次撤销。

图注编辑拥有独立的单段行内 Editor，通过 `editingScope.ts` 显式绑定父文档的 ProseMirror View。顶栏以该父 View 的当前作用域选择命令目标：图注获得粗体、斜体、下划线、删除线、代码、文字色、高亮、清除、链接和日期时间；标题、列表、排版、表格、公式、图片及其他块插入禁用。图注链接沿用链接弹窗并绑定图注选区，图注撤销/重做仍操作父文档元数据历史，完成后将焦点还给图注。清除图注文字格式保留链接语义。

作用域注册和注销按身份比对，旧编辑器的延迟清理不能撤销新作用域。顶栏命令执行前再次检查父 View、作用域身份、目标生命周期和输入法组合状态；关闭或快速切换期间的旧回调不得退回正文旧选区。顶栏、其下拉/overflow、颜色 portal 及图注工具栏交互保留图注和选区。图注异步加载时先注册临时外部作用域，禁止旧正文操作；加载成功后由真实图注作用域接管，取消或失败时释放。外部原生 ProseMirror 子编辑器可通过 `registerExternalEditingScope(parentView)` 明确占有目标；它使用自己的局部工具栏，顶栏正文编辑命令和历史暂时禁用。用户明确聚焦父正文时释放外部作用域，再聚焦子编辑器时重新注册；浮层仍可保持打开。

该注册表仅持有 View/Editor 引用，使用 WeakMap 和父文档级订阅；不复制文档 JSON、不扫描页面，输入时仍只发布图注元数据步骤。`test/editor-md/editingScope.test.tsx` 覆盖正文旧选区隔离、所有行内 Mark、颜色/清除、父历史与焦点、链接弹窗、portal 焦点、结构入口禁用、跨文档隔离、外部作用域和旧注销竞态。真实输入法行为与浏览器 overflow 布局由浏览器验收补充。
