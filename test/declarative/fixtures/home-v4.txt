# 欢迎使用 NoteBoard

把想法写下来，把关系画出来。

这是一份可以直接编辑的功能示例。文字、图片和公式都能调整，按 **Ctrl+S** 可以保存为自己的笔记。

\b{添加与整理：}空行左侧的 + 可以插入表格、图片、公式等内容；段落左侧的六点把手可以拖动整块。

\b{键盘操作：}空行输入 / 可以按名称找功能，例如 /note 提示块、/table 表格和 /fold 折叠块。↑ / ↓ 选择，Enter 插入。

::: note
提示块可以用来放备注、提醒或补充信息。右上角的问号还附了一条说明。
:::

::: explain
补充说明可以记录背景、出处或批注，和对应的内容一起保存。

选中文字后，工具栏的“添加说明”可以新增一条；图片、公式和代码块也能附加说明。
:::

## 把补充说明留在文字身边

点击这段\note[ref=scene]{带说明的文字}，再点图钉固定浮窗，拖动顶部即可换位置。选中文字后点“添加说明”，就能留下背景、出处或下一步想法。

::: annotation scene
同一处景色，也有不同的光线与情绪。晨光记轮廓，林间记发现，暮色回看一天的变化。

点击图钉固定这份说明，再拖动浮窗顶部调整位置。你可以改写正文、添加列表或图片；说明随文档一起保存。

图片、公式和代码块也能附上说明。长解释跟着正文中的锚点保存，随时可以展开细看。

## 展开细节，或者暂时藏起答案

点击“旅程记录清单”展开下面的折叠块。收起后，详细内容仍会随文档保留。

::: fold "旅程记录清单"

- 给每张图片写一句简短图注。
- 记下当时的时间、天气和观察位置。
- 把不确定的问题留在说明里，下次继续验证。

## 写作，不必来回切换工具

普通段落、**重点**、*强调*、~~删改~~、\u{下划线}，以及值得回看的句子，都能放在同一份文档中。原生文档会保存文字样式、图片布局与补充说明；Markdown 文件也可以在正文与源码之间切换。

::: bg #eff6ff
浅蓝底色让整段记录更醒目，\bg[#fef08a]{黄色高亮留下重点}，\color[#2563eb]{蓝色文字}与\color[#9a3412]{\bg[#ffedd5]{叠加配色}}让关键词各有层次。段落底色和文字高亮可以分别调整。
:::

- 用标题整理长文，右侧大纲帮助你快速跳转。
- 文件保存在自己的目录里，左侧资源管理器负责浏览和定位。
- 打开多个标签页，继续写作时不必反复寻找文件。

## 公式，留在论述中

行内公式可以像文字一样参与叙述：若 $a^2+b^2=c^2$，三条边组成一个直角三角形。点击公式可以修改它的 LaTeX 源码。

独立公式可以靠左、居中或靠右。下面的损失函数靠左排列，兼顾拟合误差与参数约束：

::: left
\[
\mathcal{L}(\theta)=\frac{1}{n}\sum_{i=1}^{n}\left(y_i-f_{\theta}(x_i)\right)^2+\lambda\lVert\theta\rVert_2^2
\]
:::

这个靠右的分段函数把数值从 0 平滑过渡到 1，常用于动画与插值；两端斜率为零，曲线下的面积恰好为一半：

::: right
\[
\begin{aligned}
s(t)&=\begin{cases}
0, & t\le 0,\\[2pt]
3t^2-2t^3, & 0<t<1,\\[2pt]
1, & t\ge 1,
\end{cases}\\[6pt]
s'(0)&=s'(1)=0,\qquad \int_0^1 s(t)\,\mathrm{d}t=\frac12.
\end{aligned}
\]
:::

支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`。公式有语法错误时，源码会保留下来，方便继续修正。

| NoteBoard 文档 | 写作、图集与补充材料 | 图片宫格、轮播、文字说明 |
| Markdown | 笔记、文章、研究记录 | 标题、公式、提示块 |

| 多维表格 | 项目、资料与结构化记录 | 表格与看板 |

居中的表格：按内容选择记录方式。

把鼠标移到表格外沿，用小把手选中整行、整列或整张表。选区可以填底色、调整水平与垂直对齐，也可以合并单元格；选中合并过的格子时，“拆分”才会启用。首行和首列可以设为表头。

这张表整体居中，后面的快捷键表靠右。块菜单可调整整表对齐；列宽、行高可拖动或均分。标准表可填色，三线表保留简洁线条。

## 代码与图示

```python
def summarize(values):
    count = len(values)
    return {"count": count, "mean": sum(values) / count if count else 0}

print(summarize([2, 3, 5, 8]))
```

::: explain
这段函数统计数量与平均值；空列表返回 0，避免除以零。说明可以附在整个代码块上，把用途、边界或待改进之处留在代码旁边。
:::

点代码块右上角的说明图标，查看函数注释。在空行输入 `···` 再按 Enter，也能创建代码块。

## 保存、导出，然后分享

按 **Ctrl+O** 打开文件或文件夹，也可以直接粘贴路径。刷新目录时，已经展开的文件夹会保持展开。

按 **Ctrl+P** 进入 PDF 排版预览，调整纸张、页边距、字号和页码。导出完成后，PDF 会在新标签页打开，原来的工作目录保持不变。

导出会包含此刻尚未保存的修改，不必先保存，也不会替你保存原文件。页面配置会记住上次选择。

在导出窗口切换为 HTML，可以保留轮播、折叠和公式，用默认浏览器打开或定位文件后分享。Word 与 LaTeX 转换需要本机 Pandoc，可在设置的“导出”页查看或指定路径。

### 几个顺手的快捷键

::: table right widths=[220,180]
| 按键 | 操作 |
| --- | --- |
| Ctrl+S | 保存 |
| Ctrl+O | 打开文件或文件夹 |
| Ctrl+Shift+O | 浏览文件夹 |
| Ctrl+1 … Ctrl+6 | 一级至六级标题 |
| Ctrl+0 | 恢复普通段落 |
| Ctrl+B / Ctrl+I / Ctrl+U | 加粗 / 斜体 / 下划线 |
| Ctrl+Z | 撤销 |
| Ctrl+F | 查找 |
| Ctrl+P | PDF 排版预览 |
:::

这些是默认按键。在设置的“快捷键”页可以搜索命令、录入新组合、禁用或恢复默认。遇到截图软件等程序占用按键时，检测结果会提示冲突，换一组顺手的组合即可。
